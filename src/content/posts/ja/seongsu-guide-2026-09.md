聖水洞（ソンスドン）は、**工場の町にカフェが入ってきた場所**です。どちらか一方になったのではなく、まだ両方あります。

韓国観光公社が「聖水洞カフェ通り」を「**韓国観光100選**」（2025~2026）に選んだとき、こう書いています。

> **今も自動車整備工場と印刷工場、手製靴通りの活気は変わらずにあるが**、けたたましく回る工場の間にグローバルな外食企業やセレクトショップのカフェが入り、聖水洞ならではの独特な雰囲気ができあがった。

この記事は、はじめて行かれる方のための総まとめです。

![赤レンガの住宅の間を抜ける細い路地、その先に明かりのついた新しい高層マンションが立っている](/images/seongsu-guide-2026-09/03.webp)

## 聖水洞はどこにあるのか

ソウルの東側、漢江（ハンガン）の北岸です。行政区は城東区（ソンドング）になります。

覚えておくとよい軸が三つあります。

- **練武場通り（ヨンムジャンギル）** — カフェ通り。聖水駅の南側です
- **峨嵯山路（アチャサンノ）** — 手製靴通り。聖水駅とットゥクソム駅を結ぶ道です
- **ットゥクソム路** — ソウルの森と水道博物館

城東区の観光ガイドブックは、カフェ通りをこう説明しています。

> 聖水洞の練武場通りは、赤レンガならではのヴィンテージな雰囲気に満ちた通りで、**古い工場や倉庫を改装した空間**が新しい顔に生まれ変わった場所です。

ここにもう一つ、**アトリエ通り**があります。赤レンガの住宅街に工房とカフェが入った路地です。

ちなみに城東区は、赤レンガ政策を説明する際の海外の事例として**ニューヨークのブルックリンと横浜の赤レンガ**を挙げています。「韓国のブルックリン」はブログが考え出した言葉ではなく、区庁の用語です。

## 空港からの行き方

仁川空港リムジンバス [[bus:6013]] が、**聖水洞の中に停まります。**

- 公式の路線表記が「面木（ミョンモク） / 軍子（クンジャ）駅 / 建大入口（コンデイプク） / **聖水洞**」
- 聖水洞の停留所は**聖水119センター、聖水イーマート、京一小学校**
- **大人17,000ウォン、子ども12,000ウォン**

他のソウル旅行の記事によく出てくる**6001番と6002番は、城東区には停まりません。** ここを取り違えると、まったく別の場所で降りることになります。

鉄道で来られるなら、[[line:arex]] で**弘大入口（ホンデイプク）駅まで出て、[[line:2]] に乗り換えるほうが楽です。** 聖水駅までは乗り換え一回です。

## どの出口から出るか

聖水洞でいちばん迷いやすいところです。**駅が三つあって、それぞれ別の町につながります。**

| 目的地 | 駅と出口 |
| --- | --- |
| **カフェ通り**（練武場通り） | [[line:2]] 聖水駅 **3番出口** |
| 手製靴通り | [[line:2]] 聖水駅 1・2番出口 |
| 靴テーマ公園 | [[line:2]] 聖水駅 4番出口 |
| ットゥクト市場 | [[line:2]] 聖水駅 3番出口から徒歩15分 |
| **ソウルの森** | [[line:2]] ットゥクソム駅 **8番出口** |
| ソウルの森・水道博物館 | [[line:suinbundang]] ソウルの森駅 3番または4番出口 |

ソウルの森駅の出口は**公式の出典どうしで表記が違います。** ソウル市は4番、城東区は3番、ソウル観光財団は3・4番と書いています。

## いつ行くのがよいか

![革工場の看板の隣に並ぶ、小さなカフェのオレンジ色の入口](/images/seongsu-guide-2026-09/02.webp)

聖水洞はかなり混みます。城東区の公式の数字です。

- 訪問者 **2020年およそ4,600万人 → 2024年およそ7,000万人**（52%増）
- **2025年のポップアップストアは883回**の開催

区庁が人出感知CCTV100台のうち**96台を聖水洞に集中配置**し、24時間体制で監視しているほどです。

そこで、三つお伝えしておきます。

**一つ、週末の午後1時から5時がいちばん歩きやすいです。** 城東区が「城東型 歩行安全通り」を運営していて、その時間帯は**練武場通りへの車の進入を止めます。** 2026年は年78回に増やす計画です。

**二つ、出発前に混雑度を見られます。** 城東区がYouTubeの「**聖水ライブ**」と、現地のキオスクや電光掲示板でリアルタイムの情報を出しています。

**三つ、月曜は避けてください。** ソウルの森の屋内施設（昆虫植物園・蝶の庭）と水道博物館が**すべて月曜休館**です。カフェだけを見るなら関係ありませんが、それだと見どころの半分が抜け落ちます。

**ハロウィンとクリスマスは、城東区が公式に「人出の集中する時期」に分類しています。**

## 一日コース

城東区の公式テーマ旅行コースが二つあります。そのまま載せます。

「**聖水ブルックリン**」 — カルビ横丁 → アトリエ通り → ソウルの森 → アンダースタンドアベニュー → 水道博物館

「**聖水カフェ**」 — 練武場通りに沿ってカフェ11か所を結ぶコース。各地点の間は徒歩3~10分

はじめて来られる方には、この二つを混ぜる形をおすすめします。

1. [[line:2]] **聖水駅3番出口** — 練武場通りのカフェ通り（1~2時間）
2. **峨嵯山路の側へ渡って**、手製靴の共同販売場とシュースポット聖水（30分、無料）
3. **ソウルの森まで歩く** — カフェ通りから徒歩圏です
4. **水道博物館** — ソウルの森と隣り合っていて無料、09:00~18:00
5. 夕食は上院通り（サンウォンギル）の側の**焼肉の路地**で

**ソウルの森と水道博物館は、もともと同じ浄水場の敷地**でした。ソウルの森の昆虫植物園が旧・急速ろ過池の建物で、ギャラリー庭園が旧・沈殿槽です。工場がカフェになった町らしく、浄水場が公園と博物館になりました。

## お金はどれくらいかかるか

**見どころはほとんど無料です。**

- ソウルの森 — 無料
- 水道博物館 — 無料
- 手製靴の公共施設5か所 — すべて無料

お金がかかるのは、実質**食べることと飲むこと**だけです。行政安全部の「着実な価格の店」制度の公式一覧を基準にすると、聖水洞の昼食の下限は**5,500~9,000ウォン**で、アメリカーノ3,000ウォンのカフェもその一覧に載っています。詳しくは[グルメの記事](/ja/posts/seongsu-food-2026-09/)にまとめてあります。

## 先に知っておいていただきたいこと

![塗装のはがれた古い建物の外壁に、ピンクの文字でCLOSEDの表示が貼られている](/images/seongsu-guide-2026-09/04.webp)

**店がよく入れ替わります。** これは聖水洞の構造的な特徴です。

城東区の公式「聖水カフェ」コースのページには店が11か所、順番に載っているのですが、**住所も営業時間もなく、最終更新日も表示されていません。** 区庁が、その店が今も営業しているかどうかを保証していない、ということです。

**ですから、特定の店を目標に行かないでください。** 通りを目標に行って、その日に開いているところに入るのが正解です。この記事に店の名前をほとんど書いていないのも、同じ理由です。

**ポップアップストアも同じです。** 年に883回開かれて、ほとんどが数日から数週間だけの営業です。行かれる直前に確認してください。

### 観光案内は手薄です

正直に書きます。

- **ソウル市の徒歩解説観光に、聖水洞のコースがありません**
- **聖水駅の中の「マイストアSS」は無人のタッチスクリーン**で、営業時間が公式資料にありません
- **城東区ホームページの英語・日本語は、グーグルの自動翻訳ウィジェット**です

人に尋ねられる場所は、**ソウルの森ビジターセンター**（09:00~18:00、年中無休）と**観光通訳案内1330**くらいです。

### キックボードでソウルの森に入らないでください

**電動キックボードとセグウェイはソウルの森への乗り入れが禁止**で、**過料5万ウォン**です。最近は乗って移動される方が多いのですが、公園の中は認められていません。テントとドローンも禁止です。

## どこに泊まるか

**聖水洞には、登録された観光ホテルが一軒もありません。** 城東区の公式に登載された観光宿泊業5か所は、すべて往十里（ワンシムニ）と龍踏洞（ヨンダプトン）にあります。

ですから聖水洞に泊まると、実質的に外国人観光都市民泊業、つまり一般の住宅になります。**無届けの宿泊営業という問題がついて回ります。** 予約の前に[宿の記事](/ja/posts/seongsu-hotels-2026-09/)を一度ご覧ください。

## こういう方に向いています

![解体と工事が進む空き地の向こうに、ガラス張りの高層ビルが見える](/images/seongsu-guide-2026-09/05.webp)

**向いている場合です。**

- カフェとベーカリーが好きな方
- 古い建物を直して使った空間に関心のある方
- 歩くのが好きな方。見どころが徒歩圏に集まっています
- 江南と弘大の**どちらへも乗り換えなしで**行ける立地が必要な方

**向いていない場合です。**

- 王宮や韓屋を見に来られたのなら、[鍾路（チョンノ）](/ja/posts/jongno-guide-2026-09/)のほうが合います
- 人の多い場所が苦手なら、週末は避けてください
- 案内や通訳が整った場所を望まれるなら、ここは手薄です

## まとめ

- **空港バスは[[bus:6013]]**。6001・6002番は城東区に停まりません。
- **聖水駅3番はカフェ通り、ットゥクソム駅8番はソウルの森**です。
- **週末の午後1時~5時は練武場通りが車両通行止め** — この時間がいちばん歩きやすいです。
- **月曜はソウルの森の屋内施設と水道博物館がすべて休館**です。
- **見どころはほとんど無料**で、お金がかかるのは食べるところだけです。
- **区庁の公式コースに載っている店でも、なくなることがあります。** 店ではなく通りを目標に行ってください。
- **聖水洞に観光ホテルは0か所**です。

一行にまとめると、こうなります。**聖水洞はカフェを見に行く町なのに、記憶に残るのはカフェの隣でまだ回っている工場のほうだと思います。**
