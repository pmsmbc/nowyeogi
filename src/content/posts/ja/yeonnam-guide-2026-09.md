延南洞（ヨンナムドン）と望遠洞（マンウォンドン）は、このブログで取り上げてきたソウルの町のなかで**規制ではなく土木工事が形を決めた町**です。

ほかの町は、建物の高さを抑えたり、家賃を抑えたり、観光客が入れる時間を決めたりしてきました。延南洞は**線路を地下に入れ、その上に公園を敷いたことで**変わりました。望遠洞は**漢江の堤防の水門がひとつ崩れたことで**、判決文に町の名前が残りました。

![晴れた夏の日のヨントラルパーク。芝生の横の浅い水路の底に古いレールが2本そのまま残り、遊歩道を人が歩いている。遠くに弘大入口駅側の高層ビル](/images/yeonnam-guide-2026-09/10.webp)

写真の水路の底にあるのが**旧京義線のレール**です。その上を流れる水は、いま**足もとを走る空港鉄道のトンネルから湧き出た地下水**です。

## 延南洞：線路を地下に埋めた場所

### 京義線スッキルができるまで

ソウル市の報道資料3本を突き合わせると、順番はこうなります。

- **1906年** 旧京義線が開通
- **2005年** 龍山〜加佐（カジャ）区間の地下化が始まる
- 残った地上の線路用地は**韓国鉄道施設公団が無償で提供**し、公園の工事費**457億ウォンはソウル市**が負担
- **2011年** 公園の工事開始、**2016年5月21日** 全区間開放

| 項目 | 内容 |
| --- | --- |
| 全区間 | 龍山区文化体育センター〜麻浦区**加佐駅** |
| 全長 | **6.3km**、幅10〜60m |
| 面積 | 10万2,008㎡ |
| 第1段階 | 2012年4月、大興洞 760m |
| **第2段階** | **2015年6月27日**、**延南洞**・セチャンコゲ・塩里洞 計2km |
| 第3段階 | 2016年5月21日、臥牛橋・新水洞・元暁路 1,446m |

**「ヨントラルパーク」は、この6.3kmのうち延南洞区間だけを指す愛称**です。延南洞とニューヨークのセントラルパークを掛けた呼び名で、ソウル市も2016年の全区間開放の資料で「昨年6月に開場した延南洞区間は『ヨントラルパーク』と呼ばれ、ソウルの新たな名所になった」と書いています。

### 延南洞区間にあるもの

ソウル市の説明をまとめるとこうです。

- **起点**：弘大入口駅**3番出口前の大きな松**
- **イチョウ並木**：廃線跡に沿って約**1km**。秋がいちばんの見どころと紹介されています
- **小川**：延南洞治安センターから**弘済川**（ホンジェチョン）の方へ流れる水路

この小川にはもうひとつ話があります。

> この小川は、地下区間の**空港鉄道から湧き上がる地下水を活用してつくったもので**、いまはなくなった延南洞一帯の**細橋川（セギョチョン）を形にした**ものである。

細橋川は、ソウル市の資料によると**1977年の蘭芝島（ナンジド）堤防工事で地上から消えた川**です。線路を地下に埋めたことで出てきた水で、数十年前に埋められた川をもう一度描いたことになります。

### 2015年の報道資料にすでに「ジェントリフィケーション」

延南洞区間を開放した2015年のソウル市の報道資料の一文です。

> 弘大など巨大商圏に押し出された芸術家が多い延南洞は、**「ジェントリフィケーション」解決のために**、新たに移り住んだ芸術家とコミュニティが地域住民と力を合わせ、フリーマーケットや芸術教室を開いて町の経済をともにつくっている地域である。

つまり**公園が開いたその日から、延南洞は「弘大から押し出された人たちが来た町」として紹介されていた**ということです。同じ資料には運営方法も書かれていて、2015年2月に発足した非営利団体**京義線スッキルジキ**（スッキルの番人）が、ニューヨークのハイラインを運営する「フレンズ・オブ・ザ・ハイライン」のような市民主導の運営を目指すとあります。構成単位の最初に挙がっているのが**延南洞ジキ**です。

## 望遠洞：水門が崩れた町

### 1984年9月2日午前10時30分

望遠洞を語るうえで外せないのが**1984年の望遠洞水害**です。判決文が国家法令情報センターで公開されています。ソウル民事地方法院**84가합5010**、事件名にそのまま「いわゆる望遠洞集団水害事件」と書かれています。

判決が認めた事実をまとめました。

| 項目 | 判決文の内容 |
| --- | --- |
| 背景 | 1972年8月19日の望遠洞水害のあと、ソウル市が**1973年ごろ望遠洞450番地一帯に望遠遊水池**を設置（面積54,000㎡） |
| 雨 | 1984年8月31日午後から3日間、中部地方に集中豪雨 |
| 事故 | **1984年9月2日10時30分ごろ**、漢江と望遠遊水池をつなぐ排水管路の**水門ボックスが崩壊** |
| 結果 | 漢江の水が逆流して遊水池をあふれ、望遠洞一帯が**9月4日午前まで地上1m以上浸水** |
| 規模 | ソウル市が救護品を配ったこの事件の被災者は**11,942世帯49,358人** |
| 判決 | 1987年8月26日、**ソウル市の賠償責任を認定**。施工した現代建設への請求は棄却 |

判決要旨でいちばん大事な一文です。

> この事件の望遠洞集団水害事故は、**自然公物としての未改修の河川が氾濫して発生したものではなく**、すでに設置された人工公物である望遠遊水池の水門ボックスに内在する瑕疵、すなわち通常備えるべき安全性を備えていない瑕疵によって発生したものである。

**川があふれたのではなく、川を防ぐためにつくった施設が壊れた事故**だったということです。判決文は、当時の洪水位が「わずか12年前の洪水位にも満たない」ものだったとも書いています。

### 望遠亭は望遠洞にありません

望遠洞という名前は、漢江沿いのあずまや**望遠亭**（マンウォンジョン）から来ています。ソウル市と韓国観光公社の説明を合わせるとこうです。

- **1424年** 孝寧大君が建て、世宗が立ち寄ったときに雨が降ったので**喜雨亭**
- **1484年（成宗15年）** 月山大君が大きく改修して**望遠亭**
- **1925年** 乙丑年の大洪水で消失
- **1988年6月着工、1989年10月復元**

ところが韓国観光公社に登録された**望遠亭跡の住所は麻浦区東橋路8アンギル23、合井洞**（ハプチョンドン）です。**町に名前を与えたあずまやが、いまは隣町の住所に建っています。**

## わたしが間違えていたこと

この記事を準備するなかで、知っているつもりだったことが4つ間違っていました。

**1つめ、ヨントラルパークは2kmではありません。** 「京義線スッキル2km」というのは、**2015年6月にまとめて開いた3区間（延南洞・セチャンコゲ・塩里洞）の合計**です。延南洞区間だけなら約1.27km、京義線スッキル全体は6.3kmです。しかも**ソウル市の報道資料2本が延南洞区間の長さを1,268mと1,266mで食い違えて**いるので、この記事では約1.27kmと書きました。

**2つめ、延南洞はもともと麻浦区ではありませんでした。** 韓国民族文化大百科事典によると、**1975年に西大門区延禧洞（ヨニドン）の一部が麻浦区に編入されて**できた洞で、名前も「延禧洞の南」という意味です。いまも京義線スッキルを挟んだ北東側が延禧洞です。

**3つめ、望遠洞水害は「雨が多かったから」ではありません。** 上の判決のとおり**水門ボックスの瑕疵**が原因と認められ、ソウル市が賠償しました。

**4つめ、望遠洞は行政上2つあります。** 麻浦区の行政区域表を見ると、**法定洞の望遠洞ひとつを、行政洞の望遠第1洞・望遠第2洞が分けて受け持っています。** 延南洞は法定洞と行政洞が同じ名前ひとつです。

## 延南洞と望遠洞はどこまでか

| 名前 | 実体 | 旅行者にとって |
| --- | --- | --- |
| **延南洞** | 法定洞＝行政洞。1975年に延禧洞から分離 | 京義線スッキル延南洞区間とその両側の路地 |
| **ヨントラルパーク** | 京義線スッキル延南洞区間（約1.27km） | 弘大入口駅3番出口から始まる |
| **望遠洞** | 法定洞ひとつ、行政洞は望遠1洞・望遠2洞 | 望遠市場、望遠漢江公園 |
| **望遠亭** | ソウル市記念物、住所は**合井洞** | 漢江沿い、望遠漢江公園のそば |
| **弘大** | 行政区域の名前ではない | [弘大旅行まとめ](/ja/posts/hongdae-guide-2026-09/)を参照 |

**延南洞と望遠洞は歩いてつながっていますが、ひとつの町ではありません。** 地下鉄だと延南洞は[[line:2]]・[[line:gyeongui]]・[[line:arex]]の**弘大入口駅**、望遠洞は[[line:6]]の**望遠駅**です。弘大入口駅から[[line:2]]で合井駅まで行き、[[line:6]]に乗り換えれば望遠駅はひと駅です。

**仁川空港からは[[line:arex]]の空港鉄道一般列車が弘大入口駅に直接止まります。** 直通列車はソウル駅までノンストップなので、一般列車に乗ってください。運賃と所要時間は[仁川空港からソウルへ](/ja/posts/incheon-airport-to-seoul-2026-09/)の記事にあります。

**漢江バス**に乗ってみたい方は、望遠漢江公園に**望遠船着場**があります。ソウル市の2026年8月の記事では大人3,000ウォンです。

## こう歩いてください

2つの町を一度に見るなら、**延南洞から始めて漢江で終える**向きが自然です。

1. **午前** — 弘大入口駅3番出口 → ヨントラルパークに沿って北へ。中央の小川とイチョウ並木がこの区間の中心です。
2. **昼** — 延南洞の路地の食堂やカフェへ。選び方は[延南洞・望遠洞のグルメ・カフェ](/ja/posts/yeonnam-food-2026-09/)の記事にまとめました。
3. **午後** — 望遠洞に移って**望遠市場**へ。ソウル市の記事も、漢江公園に行く前にここで食べ物を買っていく方法を勧めています。
4. **夕方** — **望遠漢江公園**。元暁大橋と城山大橋のあいだの漢江北岸にあり、長さ7.4km、面積422,347㎡です。

![丘の上から見下ろした望遠漢江公園。松のあいだの階段状の遊歩道の先に漢江と、赤いアーチが連なる城山大橋が見える](/images/yeonnam-guide-2026-09/15.webp)

公園の中には、退役した軍艦3隻でつくった**ソウル艦公園**（城山大橋北端の下流）もあります。2つの町の見どころは[延南洞・望遠洞の見どころ](/ja/posts/yeonnam-things-to-do-2026-09/)の記事にまとめています。

### 漢江公園で守ること

未来漢江本部の公式案内のうち、旅行者がいちばん引っかかりやすい2つです。

- **ごみは持ち帰る**。違反すると**過料10万ウォン**
- **指定場所以外に駐車しない**。過料5万ウォン。週末・祝日は公共交通機関が勧められています

![緑色の外壁にハングルで「望遠市場」と掲げた市場の入口。両脇にコーヒー店と餅屋があり、奥のアーケードへ人が入っていく](/images/yeonnam-guide-2026-09/08.webp)

**望遠市場**の住所は麻浦区浦恩路6キル27で、韓国観光公社の案内では**営業時間は店ごとに異なります**。遅い時間に行くなら、目当ての店を事前に確認してください。

## どこに泊まるか

延南洞は**空港鉄道1本で来られる住宅地**です。[弘大の宿](/ja/posts/hongdae-hotels-2026-09/)の記事でも、眠りが浅い方には大通りより延南洞側をおすすめしました。ゲストハウスや小さなホテル、望遠洞側の選択肢は[延南洞・望遠洞の宿](/ja/posts/yeonnam-hotels-2026-09/)の記事で比べています。

## こんな方に向いています

**向いている方です。**

- 歩く旅が好きな方。弘大入口駅から漢江まで、公園と路地でつながっています
- 仁川空港から乗り換えなしで来たい方
- 古宮より**町の市場と漢江ピクニック**に興味がある方
- 廃線跡が公園になる過程や、都市の水の管理のような**目に見えないインフラの話**が好きな方

**向いていない方です。**

- 古宮・博物館が主な目的なら、鍾路・北村のほうが近いです。[北村旅行まとめ](/ja/posts/bukchon-guide-2026-09/)をどうぞ
- 夜遅くまでクラブやライブを楽しみたいなら、延南洞より**弘大のメインストリート**が合っています

## まとめ

- **ヨントラルパークは6.3kmの京義線スッキルのうち延南洞区間**（約1.27km）で、**2015年6月27日**に開きました。
- **2005年の京義線地下化**で残った土地を韓国鉄道施設公団が無償で提供し、ソウル市が**457億ウォン**をかけました。
- 公園の小川は**空港鉄道トンネルの地下水**でつくった、消えた**細橋川**の再現です。
- **延南洞は1975年に西大門区延禧洞から分かれた町**です。
- **1984年9月2日、望遠遊水池の水門ボックスが崩れ**、望遠洞が1m以上浸水しました。**1987年に裁判所はソウル市の責任を認めました**。
- **望遠洞に名前を与えた望遠亭は、いま合井洞の住所**です。
- **弘大入口駅3番出口はヨントラルパーク、望遠駅1番出口は漢江公園行きの村バス。**

ひと言でいえば、**延南洞は線路を地下に埋めて公園を手に入れ、望遠洞は川を防ぐ施設が崩れた日を覚えている町**です。
