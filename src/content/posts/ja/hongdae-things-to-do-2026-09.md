弘大（ホンデ）には「観光名所がない」とよく言われます。半分は本当で、王宮も大きな博物館もありません。そのかわりこの街には**通りを使うためのルール**があります。路上ライブはどこで何時までできるのか、電動キックボードは何時から入れないのか、聖地と墓園はそれぞれ何曜日に休むのか。先に結論を言うと、そのルールさえ知っておけば、弘大での1日はぐっと迷いにくくなります。

街の成り立ちは[弘大まとめ](/ja/posts/hongdae-guide-2026-09/)で扱ったので、ここでは**見る・遊ぶ**に絞って深掘りします。京義線の森公園の延南洞区間（ヨントラルパーク）、望遠市場、望遠漢江公園は[延南洞・望遠洞の見どころ](/ja/posts/yeonnam-things-to-do-2026-09/)にまとめてあるので、ここでは繰り返しません。時間と料金はすべて**2026年9月末の執筆時点**のものです。

## レッドロード — 2kmを7つの区間に

![夜の弘大の路地。赤いラインが塗られた道を人々が歩き、正面の建物の屋上にピンクのネオン看板PINK'Sが光り、1階のみやげ物店が明るく灯っている](/images/hongdae-things-to-do-2026-09/13.webp)

弘大の路面に塗られた赤いラインが**レッドロード**です。麻浦区が2023年に整備した観光特化ストリートで、ソウル市のメディアによると**京義線の森公園から弘大前を通ってタンインリ発電所まで約2km**、始点（R1）から終点（R7）まで**歩いて25分ほど**です。[[line:2]] 弘大入口駅と[[line:6]] 上水（サンス）駅を1本で結ぶ道と考えればわかりやすいでしょう。

この道が通る西橋洞・東橋洞・合井洞・上水洞一帯の約1.13㎢は、**2021年12月に弘大文化芸術観光特区**に指定されました。

区間ごとに役割が違います。麻浦区がレッドロードを発表したときの紹介を表にするとこうなります。

| 区間 | 役割 | メモ |
| --- | --- | --- |
| R1〜R2 | 路上ライブなどの公演 | R1は弘大入口駅7番出口側。路面にチュ・ミリム作の300㎡のストリートアート「ピクセル・トラベル」 |
| R2 | 歩きたい通り | 麻浦区が定めたバスキングゾーンがある場所 |
| R3〜R4 | 商店街 | 2023年の発表時、R4は商店のライブコマース空間として紹介。ハロウィンにはR4に現場対策本部が置かれたことも |
| R5 | ロードギャラリー | 2023年に作られた屋外展示スペース |
| R6 | フェスティバル広場 | エアドームが設置され年越しカウントダウンが開かれた場所 |
| R7 | タンインリ交差点〜発電所 | 漢江方面へ続く歩行路 |

### R5 ロードギャラリー

歩きながらそのまま見られる**屋外展示スペース**です。文化日報によると、今春は麻浦美術協会と組んで作家24人の作品72点を4月30日まで展示し、今後は作品を入れ替えながら毎月テーマ展を開く計画だと紹介されました。今の展示のテーマと会期は公式資料で見つけられませんでした。

### キックボードのない通り — 昼12時から夜11時

レッドロードR1〜R6は、韓国初の**キックボードのない通り**です。2025年5月16日から施行されています。

- 禁止時間は**12:00〜23:00**、対象は電動キックボードなどのパーソナルモビリティ
- 違反すると一般道路の場合**反則金3万ウォンと罰点15点**
- シェア型キックボードで弘大に来るなら、レッドロードの外で返却しましょう。

## 歩きたい通りの路上ライブ — 9月から変わった仕組み

![曇りの日の弘大の歩行者通り。赤い模様の舗道を傘を持った若者たちが歩き、両側にハングルの看板がびっしり並ぶ服屋や飲食店が続く](/images/hongdae-things-to-do-2026-09/16.webp)

**歩きたい通り**（レッドロードR2）は、[[line:2]] [[line:arex]] [[line:gyeongui]] 弘大入口駅の**8・9番出口**から弘益大学方面へ歩くと出てきます。韓国観光公社の資料によると、ソウル市が2016年10月から2017年7月にかけてオウルマダン路の約500mを整備して作った通りで、片側に**バスキングゾーン**、反対側に広場ステージ・旅行ステージ・待ち合わせ広場があります。赤いベストを着た観光案内員も歩いています。

### 申請の仕組みが変わりました

マネートゥデイの報道（2026年8月9日）によると、麻浦区は**2026年9月から路上ライブの運営を「登録制」から「申請制」に**切り替えました。

| 時期 | 仕組み |
| --- | --- |
| 2010年代 | 騒音の通報などを理由に過料 |
| 2018年 | 申請制を導入 |
| 2024年 | 事前登録した個人・チームだけが申請可能（報道時点で個人285組、団体382組が登録） |
| 2026年9月 | 事前登録なしで申請。平日は先着順の予約、週末・祝日は申請後に抽選 |

新しい仕組みでは事前の動画提出や内容の審査がなく、**外国人や小学生のチームにも参加制限を設けない**と報じられています。旅行中に自分で演奏してみたい人にも道が開けたわけです。申請は麻浦区文化観光サイトの「野外公演場使用申請」から行います。

### 見る側も知っておきたいルール

麻浦区の申請ページにある注意事項は出演者向けですが、観客が知っておくと通りの事情が見えてきます。

- **予約した場所以外での公演、夜10時以降の公演はできません**。歩きたい通りの周辺は住宅地であり商店が密集する地域だから、と書かれています。
- 1回の公演は**1時間50分**、次の出演者のために10分前に終える
- 出演者は観客が**店の入口をふさいだり通行を妨げたりしないよう**整理する必要があります。囲んで見るときは店の前を空けておきましょう。
- 過度な音響や照明、撮影用の照明機材で周りに迷惑をかけることも制限されています。

つまり**夜10時を過ぎたら、歩きたい通りのバスキングゾーンの公式公演はおしまい**です。延南洞側の京義線の森公園には公園が別に許可する路上ライブの時間があり、夕方7時に終わります。こちらは[延南洞・望遠洞の見どころ](/ja/posts/yeonnam-things-to-do-2026-09/)にまとめました。

## ライブハウス — チケット1枚で何か所も

弘大の名前を作ったのは地下のライブハウスです。その文化にいちばん手軽に触れられるのが**ライブクラブデー**です。

ニューシスの報道（2025年2月）によると、こんな流れです。

- **2001年**に始まった元祖クラブデーはダンスクラブも参加していましたが、**2011年1月**に途切れました。
- **2015年**、ライブ音楽に絞った「ライブクラブデー」として再開
- **チケット1枚で複数のライブハウス**を行き来して、いろいろなバンドを見られる仕組み
- 2025年2月28日の第71回（10周年）はチケット**35,000ウォン**で、ブラインドチケットから先に売り切れたそうです。

確認できた最新の回は**2026年3月27日**、CJ文化財団20周年とのコラボ公演です。ニュースピムによると、CJアジト、クラブ・エバンス、ベロジュ、ムシンサ・ガレージ、KT&Gサンサンマダン、プリズムホールの**6か所**に20組が出演しました。2025年2月28日も2026年3月27日も、その月の最後の金曜日でした。**10月の回の日程と出演者は確認できなかった**ので、公式SNSをご覧ください。

### ローリングホール — 30年続くステージ

**ローリングホール**（オウルマダン路35）は、弘大のライブハウスの中でも歴史の長い場所です。

- **1995年6月**、新村の「ローリングストーンズ」として出発
- 韓国観光公社の資料では**座席約200席、スタンディング最大400人**
- ニューシスのインタビューによると年に100回前後の企画公演を開き、2022年12月にはRM（BTS）が200人規模の公演を行った場所でもあります。
- 休みと料金は公演ごとに異なります。問い合わせ 02-325-6071

## 上水側 — 発電所の上の公園

レッドロードの終点（R7）をたどって漢江の方へ下りると、**タンインリ発電所**の跡地に出ます。

### 麻浦セビッ文化の森

ソウル＆（2022年1月）によると、韓国初の石炭火力発電所だったタンインリ発電所を**LNG複合火力発電所に替えて地下に収め**、その上に作った公園です。

- 面積**78,867㎡**、**2021年4月9日**開園
- 住所は土亭路56、**24時間・年中無休**
- [[line:6]] 上水駅4番出口から約**890m**
- 遊歩道から漢江が見え、旧「唐人線」の線路の跡をベンチとして生かしているそうです。
- 望遠漢江公園側へ**幅3mの連絡路と21人乗りエレベーター**が設けられました。以前は擁壁のせいで約700m遠回りしなければならなかったとソウル市は説明しています。

### タンインリ文化創作発電所 — 開館は2027年下半期が目標

公園の隣で止まった発電所の**4・5号機**を複合文化施設に変える工事が進んでいます。ニュースピム（2026年6月1日）によると**延床面積25,532㎡、地下2階・地上6階**の規模で、2023年5月に着工し当初は2025年開館の予定でしたが、**今の目標は2027年下半期**です。**まだ中には入れません**。

### 切頭山（チョルトゥサン）殉教聖地

![切頭山殉教聖地の岩の洞窟に白いマリア像が立ち、手前の緑色のガラスのブースの中に奉献ろうそくが並ぶ。周りは松と庭木](/images/hongdae-things-to-do-2026-09/11.webp)

もとの名前は、蚕の頭に似ているという**蚕頭峰（チャムドゥボン）**です。韓国観光公社の資料によると、1866年の丙寅迫害でここで多くのカトリック信者が処刑され、その後「首を切った山」という意味の**切頭山**と呼ばれるようになりました。殉教100周年を記念して1967年10月に記念館が開館しています。

公式サイトの訪問時間です。

| 場所 | 時間 |

| 丙寅殉教100周年記念聖堂 | 07:00〜17:00（月曜は13:00まで） |
| 聖人遺骸室 | 07:00〜17:00、**ミサ中は入室不可** |
| 韓国天主教殉教者博物館 | 火〜日 09:30〜17:00。月曜、1月1日、旧正月・秋夕連休は休館 |

- 博物館の観覧料は**任意の献金**です。

- 博物館内はフラッシュ・三脚を使った撮影が禁止、屋外展示スペースでは自転車やキックボードに乗れません。
- 合井駅7番出口から**約450m、徒歩10分**。土・日・祝日はなるべく公共交通機関で、と案内されています。

### 楊花津（ヤンファジン）外国人宣教師墓園

切頭山のすぐ隣です。韓国観光公社の資料によると**15か国417人の宣教師**が眠り、代表的な人物としてベセル（裵説）、ハルバート、アンダーウッド、アペンゼラーらが紹介されています。ソウル市のメディアは、1890年7月28日にヘロンが最初に埋葬されたと伝えています。現在は100周年記念教会が管理しています。

- **月〜土 10:00〜17:00、日曜休み**、無料
- **無料案内の予約**：訪問前日の**18時まで**にオンライン申込、**当日予約はできません**。
  - 案内時刻：月〜金 10:00・11:30・14:00、土 10:00・11:30・13:30・15:00
  - 宣教師紹介映像、墓園案内、楊花津ホール見学がそれぞれ30分
  - 外国語の案内が必要なら、申込書の地域欄で日本語圏などを選びます。韓国の電話番号がない外国人はメールアドレスで代用できます。QRコードの非対面案内もあります。
  - 1月1日、旧正月・秋夕連休、クリスマスは案内がありません。

訪問のルールは厳しめです。**墓域内での飲食、ごみ捨て、拡声器は一切禁止**、**写真は墓域の間の道からだけ**撮るよう案内されています。参拝路は一列で歩いてほしいとのことです。

麻浦区はこの2か所と麻浦セビッ文化の森まで観光特区を広げる案を検討していると2023年末に報じられましたが、実際に広がったかは確認できていません。

## まとめ

- **レッドロード**は弘大入口駅〜タンインリ発電所の約2km、R1〜R7。R1〜R6は**12〜23時キックボード禁止**。
- **歩きたい通りの路上ライブ**は9月から事前登録なしの申請制、**夜10時まで**、予約場所のみ。
- **ライブクラブデー**はチケット1枚で複数のライブハウスへ。最近の回は月の最後の金曜でした。
- **サンサンマダン弘大**は11〜21時、無料のベーシック館内ツアーは電話で申込。
- **京義線ブックストリート**は11〜20時、**月曜休み**。
- **切頭山の博物館は月曜**、**楊花津墓園は日曜**が休み。楊花津の案内は前日18時までに予約。
- **ワウブックフェスティバル**は10月16〜18日、レッドロードR1とサヌリム小劇場一帯。
