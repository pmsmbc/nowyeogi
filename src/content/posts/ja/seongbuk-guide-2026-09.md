城北洞は、このブログが扱ったソウルの町のなかで**唯一、守ると決めたあとで覆された場所**です。

2019年にソウル市が、北亭マウルの371棟のうち**279棟を残すと決めました**。そして**2026年2月26日の告示で、その決定が破棄されました**。存置の279棟が**0棟**になりました。

![「尋牛荘へ行く道」の横断幕が掛かった急な階段。その向こうの丘に家々がびっしりと建ち並んでいる](/images/seongbuk-things-to-do-2026-09/02.webp)

## 二つの告示

城北洞をもっとも正確に説明する方法は、**同じ町に下された二つの告示を並べて置くこと**です。

> **ソウル特別市告示 第2022-366号** （2022年8月25日）— 塀の許容の高さを1.5mから**2.0m**に上げる。理由：「**多数の大使館の公邸が位置する城北洞の現況の反映**」

> **ソウル特別市告示 第2026-96号** （2026年2月26日）— 城壁の外の**371棟をすべて取り壊し**、4階以下の474世帯を建てる。

同じ自治体が、**同じ町の二つの斜面**に下した決定です。一方は塀を高くしてやり、もう一方は家を取り壊します。

城北区には**大使館の公邸が40か所**あり、道の名前がそのまま**大使館路**です。

## 私が間違っていたこと

この記事を準備しながら、前提が二つ崩れました。そのまま書きます。

**一つ、北亭マウルはバラック村ではありません。** ソウル市の文書はこう書いています。

> **1960〜70年代に建てられた500軒ほどの瓦屋根の家**

371棟509世帯で、瓦屋根の家です。バラック村からはじまった町は**長寿マウル**ですが、それは城北洞ではなく三仙洞です。

**二つ、再開発を望んだのは住民の側でした。** ソウル市の報道資料の原文です。

> **2009年から大多数の住民の念願の事業として**住宅の再開発を進めてきた地域

「住民は保存を望んでいるのに、市が開発を押し進めている」という構図ではありませんでした。**再開発を望んだのが住民で、保存の仕組みを差し込んだのがソウル市**でした。

## 年表

| 時点 | 起きたこと |
| --- | --- |
| 2009年 | 住民が再開発の推進をはじめる |
| 2011年8月18日 | 整備区域の指定 |
| 2015年6月 | 修復型へ転換 |
| **2019年3月14日** | **371棟のうち279棟の存置を決定** |
| 2024年9月5日 | 事業施行の認可 |
| **2026年2月26日** | **個別整備地区の廃止、371棟の全量撤去へ変更** |

2019年のやり方は変わっていました。**3km離れた新月谷1区域に容積率80%を渡し**、その開発の利益で城北2区域を低層で整備する「結合整備事業」でした。ソウル市の説明です。

> ソウル市は城郭マウルの一つである北亭マウルを生かすために、その地域の歴史と文化を消してしまう**全面撤去方式の再開発から、新しい試み**をしている。

その試みが7年後にたたまれました。**残る建物は尋牛荘の一棟**だけで、その場所に474世帯と歴史公園5,571.1㎡、緩衝緑地5,487.7㎡が入ります。**賃貸住宅は建てません**。

### ソウル未来遺産なのに撤去されます

**北亭マウルはソウル未来遺産 2015-016**で、2026年1月1日時点の現況の一覧にいまも載っています。その一か月後に撤去が告示されました。

矛盾のようですが、制度の性質です。ソウル市が自ら明らかにしています。

> ソウル未来遺産の保全事業は、文化遺産の**画一的な保全のための規制の仕組みを設けるものではありません**。

益善洞の記事でも西村の記事でも同じ話をしましたが、**ここでその限界がもっともはっきり表れます**。

### ユネスコの申請と撤去の告示

時点が目を引きます。

- **2026年1月16日** — ソウル市が「漢陽の首都城郭」の世界遺産の登録申請書を提出
- **2026年2月26日** — 北亭マウルの撤去の告示

そして、その告示の緩衝緑地を新設する理由が「**漢陽都城の文化財の保護のため**」です。二つの決定は矛盾ではなく、**一つの政策**です。

## 高級住宅地と斜面は、同じ開発の結果です

この部分が、今回の調べもので一番意外でした。

ソウル未来遺産の選定の理由の原文を見ると、こうです。

- 李泰俊の「月夜（タルバム）」 — 「東小門の外の城北洞が**住宅難を解消するために遅れて京城の一部に編入**された」
- 金光燮の「城北洞の鳩」 — 「**1960年代の城北洞一帯の宅地開発事業**を背景に」

そして北亭マウルの瓦屋根の家500軒あまりも、**1960〜70年代**に建てられています。

**城北洞の高級住宅地と北亭マウルは、同じ時期の同じ開発の二つの結果**です。別々にできたものではありません。

## 四つの町と並べて置くと

| 町 | 処方 |
| --- | --- |
| 乙支路 | 撤去の決定 |
| 益善洞 | 2018年の解除＋保全の仕組み |
| 西村 | 1977年の高さ規制 → 2016年の保存 |
| 聖水洞 | 2015年の賃料抑制の条例 |
| **城北洞** | **2019年の保存 → 2026年の撤去へ反転** |

**決定が覆されたのは城北洞だけ**です。

## 行き方

![渓谷の上に建つ吉祥寺の木造の堂。石橋と瓦屋根が木々に囲まれている](/images/seongbuk-guide-2026-09/11.webp)

[[line:4]] の**漢城大入口駅**です。出口とバスを覚えておかれると楽です。

| 目的地 | 行き方 |
| --- | --- |
| **食事の店** | **5番出口** |
| **吉祥寺** | **6番出口**から村バスの**城北02番** |
| **北亭マウル・尋牛荘** | **6番出口**から村バスの**城北03番** |

どちらも「**漢城大入口駅6番出口・三仙橋**」の停留所から乗ります。村バスは1,200ウォンです。

**城北洞は急です。** 地図の上で近く見えても、歩いて上がると大変です。村バスが答えです。

**ごはんは坂の下、見どころは坂の上**だと覚えておかれると、回り方が楽になります。

## 北亭マウルについて

**観光地ではありません。** 509世帯が暮らす住宅地で、いまは撤去を控えた状態です。

城北洞には、益善洞の「お約束1〜4」のような**公式の静粛のお願いがありません**。近くの長寿マウルにはありますが、北亭マウルにはありません。規定がないからといって、のぞいてよいという意味ではありません。

**尋牛荘へ行かれるなら、マウルのなかを通ることになります。** 前もって知ったうえで、静かに通り過ぎられるほうがよいです。

## こういう方に向いています

**向いている場合です。**

- 都市が何を残し、何を消すのかに関心がおありの方
- 漢陽都城を歩いてみたい方
- 寺と古い家を静かに見たい方
- **いまでなければ見られないもの**を見たい方

**向いていない場合です。**

- 坂がつらい方は、必ず村バスに乗ってください
- 買い物やカフェ通りを期待されるなら、益善洞か聖水洞が合います
- 見どころのかなりが**月曜休み**です

## まとめ

- **2019年に279棟を残すと決めたあと、2026年2月26日の告示で全量の撤去**になりました。
- **残るのは尋牛荘の一棟**だけです。
- **北亭マウルはソウル未来遺産なのに撤去**されます。未来遺産は規制の仕組みではありません。
- **住民が2009年から再開発を望んでいました。** 保存を差し込んだのがソウル市の側でした。
- **大使館の公邸40か所と北亭マウルは同じ町**で、同じ時期の開発の二つの結果です。
- **漢城大入口駅の5番はごはん、6番はバス。** 吉祥寺は城北02番、北亭マウルは城北03番です。

一行に縮めると、こうです。**城北洞は、ソウルが何を残すかを決めて、また決め直した町**です。
