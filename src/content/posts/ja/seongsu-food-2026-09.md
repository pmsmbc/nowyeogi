聖水洞（ソンスドン）は高い町として知られています。合っているとも言えるし、合っていないとも言えます。

行政安全部が運営する公式の一覧に、**聖水洞でアメリカーノを3,000ウォンで出すカフェが二軒**載っています。同じ町にです。この記事は、その公式資料を整理したものです。

![古いトタン屋根の工場と看板の後ろに、新しい高層マンションがそびえる聖水洞の街角](/images/seongsu-food-2026-09/02.webp)

## まず、この町がどうしてこういう姿なのか

聖水洞は工場の町でした。今もそうです。

韓国観光公社が「聖水洞カフェ通り」を「**韓国観光100選**」（2025~2026）に選んだときの、公式の紹介文です。

> 古い工場地帯、靴工房の路地に代表されていた聖水洞の練武場通りが、トレンディなカフェと文化空間に生まれ変わった。**今も自動車整備工場と印刷工場、手製靴通りの活気は変わらずにあるが**、けたたましく回る工場の間にグローバルな外食企業やセレクトショップのカフェが入り、聖水洞ならではの独特な雰囲気ができあがった。

国の観光機関が「今も工場が回っている」と公式文書に書いているわけです。カフェの路地だけの町ではありません。**整備工場の隣にカフェがあり、印刷所の隣にベーカリーがあります。** その対比がこの町のすべてです。

## 聖水洞は本当に高いのか

ここがこの記事の中心です。

行政安全部には、周辺の商圏より安く売る店を指定する「着実な価格の店（착한가격업소）」という制度があり、**指定された店のメニュー価格を公式のデータベースで公表**しています。2026年9月21日時点で、聖水洞1街・2街に登録されている店の公表価格です。

| 店 | 公表価格 |
| --- | --- |
| チャンチャンコーヒー（창창커피） | アメリカーノ 3,000ウォン |
| コピロ・クリヌンクム協同組合（커피로 그리는 꿈 협동조합） | アメリカーノ 3,000ウォン |
| チャッカンチャジャン（착한짜장） | ジャージャー麺 5,500ウォン・チャンポン 7,000ウォン |
| ットゥクトグクス（뚝도국수） | チャンチグクス 6,000ウォン・ビビングクス 6,500ウォン |
| チャムセワパンアッカン（참새와방앗간） | プデチゲ 6,000ウォン・スンドゥブチゲ 6,000ウォン |
| ットワ（또와） | ランチビュッフェ 7,000ウォン・サムギョプサル 15,000ウォン |
| キチノヤ（키치노야） | 牛丼レギュラー 7,800ウォン |
| タルニミネ（달님이네） | 定食（ペッパン） 8,000ウォン |
| ソンス食堂（성수식당） | 定食 8,000ウォン・サムギョプサル 16,000ウォン |
| ランカルグクス（란칼국수） | カルグクス 9,000ウォン・ヨルムビビンバ 8,000ウォン |
| エルダッ（엘닷） | 握り寿司の盛り合わせ8貫 6,900ウォン・サーモンの握り 10,900ウォン |

**昼食一食の下限が5,500ウォンから9,000ウォンの間**にある、ということです。

### ただしこれは平均ではなく下限です

大事な但し書きです。この制度は定義上、**周辺の商圏の平均より安い店**を指定するものです。それが指定の要件だからです。

ですから「聖水洞でもこのくらいで食べられる」は正しく、「聖水洞の平均がこのくらいだ」は**誤りです**。練武場通りの真ん中にある倉庫型のカフェは、この価格ではないはずです。

### 物価は実際に上がりました

同じ公式データベースの2024年6月の公表価格と今を比べると、こうなります。

- **ランカルグクスのカルグクス — 8,000ウォン → 9,000ウォン**（12.5%の値上げ）
- **ソンス食堂の定食 — 7,000ウォン → 8,000ウォン**（14.3%の値上げ）
- **ソンス食堂のサムギョプサル — 15,000ウォン → 16,000ウォン**（6.7%の値上げ）
- **チャッカンチャジャンのジャージャー麺 — 5,500ウォンのまま**

体感ではなく、公表された数字です。

## カフェだけの町ではありません

![小さなコーヒー店の中、黄色い焙煎機の横に本と写真がびっしりと貼られている](/images/seongsu-food-2026-09/13.webp)

城東区（ソンドング）が2025年に、区が公式に選定したグルメ店「성동맛집」として**65か所**を発表しました。外食産業の活性化と食文化の改善が目的です。

その一覧のうち**聖水洞とソウルの森の一帯が19か所ほど**で、ほぼ3分の1を占めます。ところが主なメニューを見ると、想像とは違います。

- **洋食** — ハンバーガー、ニョッキ、ラザニア、パスタ
- **韓国料理** — カルグクス、豚足（チョッパル）、スンデクク、定食、チムタク、きのこ入り生プルコギの鍋
- **日本料理・中華** — そば、クァバロウ、チャンポン、ヒレ肉の酢豚
- **そのほか** — ヘチョンタン、ムルフェ、馬肉のユッケ、キンパ

特に**上院通り（サンウォンギル）と上院10通りに、肉と海鮮の店が集まっています。** 豚足の店が三軒、豚カルビ、豚の肩ロース、ムルフェ、済州の料理までが一つの軸にあります。城東区の公式一覧を見るだけでも、この町がカフェ通りではないことが分かります。

**カフェ通りから二、三ブロック外れるだけです。** そちらが元からの町です。

## 賃料を抑える条例があります

聖水洞の話でここが抜けると、半分しか伝わりません。

城東区は**2015年9月**に「地域共同体の相互協力および持続可能発展区域の指定に関する条例」をつくりました。区庁はこれを「**全国初のジェントリフィケーション防止条例の制定**」だと説明しています。

中心にあるのが**相生協約**です。建物の所有者と借り手が、賃料を過度に上げないと自主的に約束する制度です。**法的な拘束力のない自主協約**であるにもかかわらず、城東区の実態調査ではこういう差が出ました。

| | 協約あり | 協約なし |
| --- | --- | --- |
| 平均営業期間 | **79か月**（6年7か月） | **52か月**（4年4か月） |
| 賃料の上昇率 | 2.49% | 2.85% |

**27か月の差**です。店が2年以上長く続く、ということです。

2021年末の時点で、区域内の**建物所有者の73.3%が協約に参加**し、**501棟**が締結しています。

### 訪問者にも見える印があります

協約を結んだ店には「**相生城東**」のステッカーが貼られます。ドアか窓に貼ってあります。

その店がおいしいという保証ではありません。ただ、**その場所で長く商売をしてきた店である可能性が高い**という合図ではあります。面白半分に探してみてください。

ただし上の数字は**2021年末の時点**のもので、それ以降に更新された数字は確認できませんでした。

## 週末に行かれるなら

![玉ねぎと唐辛子、ごまをのせて炒めたトッポッキを近くから撮った写真](/images/seongsu-food-2026-09/10.webp)

聖水洞はかなり混みます。城東区の公式の数字です。

- 聖水洞の訪問者 **2020年およそ4,600万人 → 2024年およそ7,000万人**（52%増）
- **2025年のポップアップストアは883回**の開催

区庁が人出感知CCTV100台のうち**96台を聖水洞に集中配置**し、24時間体制で監視しているほどです。

そこで、訪問者に実際に役立つことが二つあります。

**一つ、練武場通りは週末に車が通行止めになります。** 城東区が「城東型 歩行安全通り」を運営していて、**週末の午後1時から5時まで車の進入を止めます**。2026年は年78回に増やす計画です。この時間帯がいちばん歩きやすいです。

**二つ、リアルタイムの混雑度を見られます。** 城東区がYouTubeの「**聖水ライブ**」（성수라이브）と、現地のキオスクや電光掲示板で混雑情報を出しています。出発前に一度見ておけば十分です。

**ハロウィンとクリスマスは、城東区が公式に「人出の集中する時期」に分類しています。** その時期は現地対策室まで設置します。

### ポップアップストアの名前は書けません

聖水洞のポップアップは、ほとんどが**数日から数週間だけ開きます**。883回という数字が出るのはそのためです。この記事に名前を書いておいても、行かれるころには消えています。行く直前に確認してください。

## どの出口から出るか

聖水洞は三つの駅が、それぞれ別の場所につながります。ここで迷う人が多いところです。

| 目的地 | 駅と出口 |
| --- | --- |
| **カフェ通り**（練武場通り） | [[line:2]] 聖水（ソンス）駅 **3番出口** |
| 手製靴通り | [[line:2]] 聖水駅 1・2番出口 |
| 靴テーマ公園 | [[line:2]] 聖水駅 4番出口 |
| **ソウルの森** | [[line:2]] ットゥクソム駅 **8番出口** |
| ソウルの森（盆唐線の側） | [[line:suinbundang]] ソウルの森駅 **3番または4番出口** |

ソウルの森駅の出口は**公式の出典どうしで表記が違います**。ソウル市は4番、城東区は3番、ソウル観光財団は3・4番と書いています。ですからこの記事では「3番または4番」としました。

通りの軸で覚えると楽です。**手製靴は峨嵯山路、カフェは練武場通り、森はットゥクソム路**です。

## ソウルの森

![ソウルの森の旧浄水場のコンクリート構造物の上下に、草花が生い茂っている](/images/seongsu-food-2026-09/07.webp)

カフェの路地から歩いて行けて、**入場料がありません**。常時開放で、屋内施設だけが月曜に休みます。

韓国観光公社の紹介文に、こういう一節があります。

> ソウルの森は**1908年に設置されたソウル初の上水源の水源地**であり、2005年にットゥクソム体育公園一帯を大規模な都市の森にするため、新たに開園した。

上の写真のコンクリートの構造物が、その跡です。工場がカフェになった町らしく、**浄水場が公園になった**わけです。ソウルの森も「韓国観光100選」に一緒に載っています。

![漢江の対岸から見たソウルの森と、その後ろに並ぶ高層の複合住宅](/images/seongsu-food-2026-09/09.webp)

## 知っておくと便利なこと

カフェで出会うことですが、公式の根拠があるものだけを書きます。

**座って飲む場合、使い捨てカップはもらえません。** 「資源の節約と再活用の促進に関する法律」が、店内での使い捨て品の使用を禁じています。規制の対象は客ではなく店です。マグカップで出てくるのが正常です。

**使い捨てカップの保証金300ウォンは、済州と世宗でのみ実施中です。** ソウルは対象外です。廃止されたわけでも、全国実施でもありません。

**すべてのカフェと飲食店は全面禁煙です。** 2015年1月1日から、面積に関係なくそうなっています。喫煙者の過料は10万ウォンです。

**チップはありません。** そしてメニューの価格は**付加価値税を含んだ最終金額**でなければなりません。会計のときに足されることはありません。

**カード決済を断るのは違法です。** 「与信専門金融業法」により、1年以下の懲役または1,000万ウォン以下の罰金の対象です。ただし、海外発行のカードが通らない端末があるのは、別の問題です。

**ノートパソコンを長く使うことについての規制はありません。** すべて店が決めます。公正取引委員会の標準約款にもコーヒー専門店向けのものはなく、消費者紛争解決基準にも座席の利用時間の規定はありません。貼ってある案内に従ってください。

## 確認できなかったこと

正直に書きます。

**聖水洞のカフェの平均価格は、公式の資料がありません。** 上に書いたのは「着実な価格の店」、つまり下限です。ポップアップストアの入場料やグッズの価格も、公式の資料がありません。

**カフェ通りの公式の境界線もありません。** 告示された区域ではなく、観光機関が名前をつけた通りです。

**相生協約の数字は2021年末の時点**のもので、それ以降に更新された数字は入手できていません。

**一般の飲食店や個人経営のカフェには、アレルギー表示の義務がありません。** 義務があるのは包装食品と、店舗50か所以上のフランチャイズだけです。アレルギーがある方は、直接聞く必要があります。

## まとめ

- **聖水洞カフェ通りは「韓国観光100選」（2025~2026）の公式選定**を受けた旅行先です。
- **アメリカーノ3,000ウォンのカフェが、行政安全部の公式一覧に二軒**あります。ただしこれは平均ではなく下限です。
- **昼食の下限は5,500~9,000ウォン**で、2年の間に実際に上がりました。
- **城東区の公式グルメ一覧の3分の1が聖水洞**で、その多くはカフェではありません。上院通りのほうに肉の店が集まっています。
- **2015年、全国初のジェントリフィケーション防止条例**があり、協約を結んだ店は27か月長く続きます。「相生城東」のステッカーを探してみてください。
- **週末の午後1時~5時は練武場通りが車両通行止め**、リアルタイムの混雑度はYouTubeの「聖水ライブ」です。
- **聖水駅3番はカフェ、ットゥクソム駅8番はソウルの森**です。

聖水洞に行かれたら、カフェ通りだけ見て帰らないでください。**二ブロック歩いて出れば、今も工場が回っていて、その隣で8,000ウォンの定食を出しています。** それがこの町の本当の姿です。
