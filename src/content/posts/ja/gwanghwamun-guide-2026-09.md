光化門（クァンファムン）から鍾閣（チョンガク）まで歩くと、広場を4つ通り抜けます。**光化門広場、ソウル広場、清渓（チョンゲ）広場、そして普信閣（ポシンガク）の前庭**です。

この4か所には共通点がひとつあります。**2004年から2023年のあいだに、ソウル市が車道や高架道路をはがしてつくった場所**だということです。光化門広場は16車線の道路の真ん中に、ソウル広場は車が回るロータリーに、清渓川は高架道路の下にありました。光化門前の月台（ウォルデ）は1923年に電車の線路のために壊され、100年ぶりに戻ってきました。

景福宮などの王宮と北村の話は、先に書いた[鍾路まとめ](/ja/posts/jongno-guide-2026-09/)にあります。この記事はその南、**世宗大路（セジョンデロ）沿いに続く広場を、公式の記録で**読んでいきます。

![青空と白い雲の下に光化門と景福宮の塀が立ち、手前の芝生に赤い服の人が座っている。門の前の石の欄干に沿って見学客が並んでいる](/images/gwanghwamun-guide-2026-09/04.webp)

## ひと目でわかる4つの広場

| 広場 | 以前は | いま | 区 |
| --- | --- | --- | --- |
| **光化門広場** | 往復16車線の世宗路 | 2009年開場、2022年に西側車道を取り込んで再開場 | 鍾路区 |
| **ソウル広場** | 噴水台を車が回る市庁前の交通広場 | 2004年5月1日から芝生広場 | 中区 |
| **清渓広場・清渓川** | 覆蓋道路と清渓高架道路 | 2005年10月1日に復元 | 中区・鍾路区の境 |
| **普信閣一帯** | 朝鮮時代の鐘楼跡、再開発用地 | 1979年にいまの楼閣、2018年に地下遺跡展示館 | 鍾路区 |

住所も2つの区に分かれます。韓国観光公社によると光化門広場は**鍾路区世宗大路172**、ソウル市の案内ではソウル広場は**中区世宗大路110**、清渓広場は**中区太平路1街**、普信閣跡は**鍾路区鍾路54**です。同じ世宗大路の上にあっても、光化門広場とソウル広場は管轄の区が違います。

## 光化門広場：16車線から幅60mの広場へ

### 2009年、道路の真ん中の島

ソウル市情報疎通広場の「光化門広場の変遷史」によると、1960年代以降、世宗大路は拡幅されて**車中心の空間**になりました。2004年にソウル広場、2005年に南大門広場を先につくったソウル市は、2006年に光化門広場の計画を立てます。

- **2009年8月1日** 開場。幅34m、長さ557m、面積1万8,014㎡
- 道路は**往復16車線から10車線**に
- **2009年10月9日** ハングルの日に世宗大王像を除幕

広場南側の李舜臣（イ・スンシン）将軍像はずっと古く、**1968年4月27日**に建てられました。

このころの広場は、**両側を車道に挟まれた道路の真ん中の島**でした。像の前まで行くには横断歩道を渡る必要がありました。

### 2021〜2022年、西側車道を広場に

2回目の工事は**2020年11月16日**に始まりました。順番が興味深いです。

| 時点 | 出来事 |
| --- | --- |
| 2020年11月16日 | 光化門広場の再構造化工事に着工 |
| **2021年3月6日0時** | 東側道路（従来5車線）を7〜9車線に広げて**双方向通行**を開始。西側道路（世宗文化会館前）の車両通行を中止 |
| 2021年5月 | 世宗大路サラムスッキル完成 |
| **2022年8月6日** | 光化門広場が再開場 |

ソウル市の2022年7月の報道資料による数字です。

| 項目 | 以前 | 再開場後 |
| --- | --- | --- |
| 面積 | 18,840㎡ | **40,300㎡**（2.1倍） |
| 幅 | 35m | **60m** |
| 緑地 | 2,830㎡ | **9,367㎡**（3.3倍） |
| 植えた木 | — | 約5,000本 |

世宗文化会館側の車道がまるごと広場になり、広場が建物の前まで続くようになりました。同じ資料には、朝鮮建国の1392年から2022年までの年表を刻んだ長さ212mの「**歴史水路**」と、工事中に見つかった**司憲府（サホンブ）の門跡**の遺構をその場で見せるという内容もあります。

### 2023年、月台

光化門のすぐ前にある広い基壇が**月台**です。京郷新聞（2023年10月12日）によると、発掘された月台は**南北約48.7m、東西約29.7m**で、中央の幅約7mの御道が光化門の真ん中の門につながります。

- **1923年** 日本統治下で電車の線路を敷く際に取り壊されました
- **2023年10月15日** 復元記念行事。2006年に始まった「光化門の元の姿を取り戻す」事業の締めくくりでした
- 同じ日に**新しい扁額**も公開されました。2010年の扁額は白地に黒い文字でしたが、新しい扁額は**黒地に金色の文字**です
- 欄干の端を飾る**瑞獣像**1対は、2023年8月に故・李健熙（イ・ゴニ）会長の遺族が寄贈しました

### 2026年、感謝の庭園

**2026年5月12日**、光化門広場に**感謝の庭園**が開場しました。朝鮮戦争（6・25戦争）の参戦国をたたえる空間です。

- 地上：高さ**6.25m**の石造の造形物**23本**「感謝の光23」（韓国と参戦22か国）
- 地下：メディア展示空間「フリーダムホール」。**火〜日10:00〜20:00、月曜休み**
- 夜間照明：毎日20:00〜23:00

YTNの報道によると、一部の市民団体と与党からは**造形物の形が光化門広場のほかの記念物と調和しない**という批判が出ました。マネートゥデイの2026年8月の記事は、開場直後の10日間（5月13〜23日）の光化門広場の訪問者が134万7,350人、2025年の年間訪問者が**約2,700万人、1日平均7万4,000人**だったと伝えています。

## ソウル広場：79日でつくった芝生

![縞模様に刈られたソウル広場の芝生の向こうに、時計塔のある旧ソウル市庁の石造建物と、その背後を覆うガラスの曲面の新庁舎が見える](/images/gwanghwamun-guide-2026-09/05.webp)

ソウル広場の公式サイトは、工事を「**79日間の記録**」というタイトルでまとめています。

| 項目 | 記録 |
| --- | --- |
| 以前の姿 | **1963年6月29日**に完成した噴水台を車が回る交通広場、約40年 |
| 2001年の交通事故 | **70件、負傷67人**。事故多発地点2位 |
| 2002年8月の市民世論調査 | 賛成79%、反対15%（1,000人） |
| 着工 | 2004年3月19日 |
| 開場 | **2004年5月1日** |
| 面積 | 全体約13,207㎡、中央の芝生6,449㎡（ウィキペディア） |

芝生の奥の石造建物は、**1926年に京城府庁舎**として建てられました。国家遺産ポータルによると、解放後はソウル市庁として使われ、国家登録文化遺産になっています。2012年10月26日に**ソウル図書館**として開館し、後ろのガラスの建物がいまの市庁新庁舎です。

### 数字が食い違うソウル広場

2021年の世宗大路サラムスッキルの報道資料は、新しくできた歩行空間13,950㎡が「**ソウル広場（6,449㎡）の2倍を超える**」と書いています。6,449㎡はウィキペディアが**芝生部分**の面積として載せている数字と同じです。ソウル広場全体を13,207㎡とすると、サラムスッキルの歩行空間とほぼ同じ広さになります。この記事ではソウル市の公式ページで全体面積を直接確認できなかったため、2つの数字を出典とともに並べました。

### 世宗大路サラムスッキル

ソウル広場の南には、2021年にできた**世宗大路サラムスッキル**（「人の森の道」の意味）が続きます。ソウル市の発表によると次のとおりです。

- 区間：世宗大路交差点〜市庁〜崇礼門〜ソウル駅、**1.55km**
- 車線：**9〜12車線から7〜9車線に**
- 歩行空間が13,950㎡増加、歩道幅は最大12m
- 木418本、低木1万5,000株、草花13万本
- 工事前後の平均車速は21.7km/hから21.6km/h

ソウル市は、光化門広場の西側道路の編入とサラムスッキルをつなげて**光化門からソウル駅までの2.6kmの都心歩行軸**をつくると説明しています。

## 2つの広場、2つのルール

この記事を書いていていちばん驚いたところです。ソウル広場と光化門広場は同じ世宗大路の上にあるのに、**条例が定めるルールが正反対**です。

| 項目 | ソウル広場 | 光化門広場 |
| --- | --- | --- |
| 第1条の目的 | 余暇と文化活動、公益的行事、**集会とデモの進行**など | 市民の健全な**余暇と文化活動**など |
| 手続き | **使用届出**（使用日の90日前〜5日前） | **使用許可申請**（使用日の60日前〜7日前） |
| 市の判断 | 「原則として受理しなければならない」 | 造成目的に反しないかなどを「検討して許可するかどうかを決定」 |

ソウル広場も最初から届出制だったわけではありません。ソウル新聞によると、**2009年12月、市民約10万人が署名した住民発議**で条例改正の請求が出され、韓国日報によると**2010年8月13日、ソウル市議会が許可制を届出制に変える改正案**を可決しました。いまの条例第1条の「集会とデモ」の文言には、2010年9月27日の改正表示がついています。

光化門広場は逆の方向です。ソウル市は再開場2日前の**2022年8月4日の説明資料**で、光化門広場は余暇・文化活動のために許可する空間であり、**集会とデモは原則として許可の対象ではない**と明らかにしました。騒音・行事・法律・交通の専門家5人で諮問団をつくり、大規模な行事を検討するという内容もあります。

ただし、**広場の使用許可と道路上の集会は別の話**です。広場のすぐ横の世宗大路ではよく集会が開かれ、そのたびに道路が規制されます。

## 清渓川：高架道路をはがした川

## 鍾閣：鐘は替わり、地下はそのまま

![赤い柱と緑の丹青が施された2階建ての楼閣・普信閣を正面から見たところ。軒下に「普信閣」の扁額がかかり、手前に石の欄干と階段がある](/images/gwanghwamun-guide-2026-09/10.webp)

### 普信閣

韓国観光公社の普信閣跡の案内をまとめると次のとおりです。

- **1395年（太祖4年）** 最初の鐘楼を建てました。4回焼失し、8回建て直されています
- **1895年（高宗32年）** 「普信閣」の名を賜りました。「鍾閣」とも呼ばれ、駅名もここから来ています
- **いまの建物は1979年8月**にソウル市が建てた2階建ての楼閣です
- 朝鮮時代には朝4時に33回、夜7時に28回鐘を鳴らし、都城の門を開け閉めしていました

**いまかかっている鐘は1468年の古い鐘ではありません。** 国立中央博物館の発表によると、古い普信閣鐘はひび割れで音が悪くなり、除夜の鐘に使われたのは**1985年まで**でした。**2004年12月**に国立中央博物館へ移されています。いまの鐘は国民の募金で新しくつくられ、1985年8月14日にかけられ、翌日の光復節（8月15日、解放記念日）に初めて鳴らされました。

### 除夜の鐘と交通規制

ソウル市の2025年除夜の鐘の案内によると次のとおりです。

- 2025年12月31日22:50〜2026年1月1日0:20、普信閣一帯、**33回打鐘**
- 全面規制：12月31日18:00〜1月1日7:00。**鍾路（世宗大路〜鍾路2街）、清渓北路、郵政局路**
- ソウル交通公社区間の1〜9号線などの終電を**深夜2時まで延長**、周辺の45のバス路線も2時まで

今年の12月31日も同じように規制されるなら、この日の夜に鍾閣近くのホテルまでタクシーで入るのは難しくなります。2026年の行事案内は、この記事を書いている時点ではまだ出ていませんでした。

### 公平都市遺跡展示館

普信閣の東側のビルの地下には、**公平（コンピョン）都市遺跡展示館**があります。ソウル歴史博物館の報道資料（2018年9月12日）によると、2015年の公平1・2・4地区の**都市環境整備事業中に発掘された建物跡と路地を、その場所のまま保存**した施設です。

| 項目 | 内容 |
| --- | --- |
| 開館 | 2018年9月12日 |
| 規模 | 延べ面積3,817㎡（報道資料ではソウル最大の遺跡展示館） |
| 見どころ | 16〜17世紀の建物跡、**実際に歩ける朝鮮時代の路地42m**、復元家屋3棟、生活遺物約1,000点 |
| 観覧 | 9:00〜18:00（入場締切17:30）、**無料** |
| 休館 | 開館時の報道資料では毎週月曜・1月1日 |
| 行き方 | [[line:1]] 鍾閣駅3-1番出口 |

再開発でビルは建ちましたが、**地下の朝鮮の路地は壊さずにビルの地下に残した**やり方です。現在の観覧案内ページには休館日が書かれていないので、行く前に確認してください。

### 週末の集会を確認してください

光化門一帯は、週末や記念日に道路規制がよくあります。2026年に報じられた例です。

- **4月4日（復活祭の週末）**：世宗大路の光化門交差点〜世宗交差点が**0時から24時まで規制**、鍾路・乙支路・社稷路・栗谷路も規制（ソウル新聞）
- **8月15日（光復節）**：世宗路一帯、乙支路入口交差点〜市庁方面などが規制、交通警察約218人を配置（ニュースピム）

警察はどちらのときも**公共交通、とくに地下鉄の利用**を呼びかけました。ソウル新聞によると、規制情報はソウル警察庁の交通情報案内電話、ソウル市交通情報センター**TOPIS**のウェブサイト、カカオトークの交通情報サービスで確認できます。バスやタクシーは渋滞しても地下鉄は走るので、週末は地下鉄駅を基準に動線を組むほうが安全です。

## こう歩いてください

北の光化門から南へ、そして東へ。**光化門 → 市庁 → 清渓広場 → 鍾閣**の順に歩くと、4つの広場をすべて通ります。

1. **午前** — [[line:5]] 光化門駅から光化門広場と月台へ。景福宮の回り方は[鍾路の見どころ](/ja/posts/jongno-things-to-do-2026-09/)に、この一帯の見どころだけを集めた記事は[光化門・市庁・鍾閣の見どころ](/ja/posts/gwanghwamun-things-to-do-2026-09/)にあります。
2. **昼** — 食事の選び方は[光化門・市庁・鍾閣のグルメ](/ja/posts/gwanghwamun-food-2026-09/)にまとめました。
3. **午後** — 世宗大路に沿ってソウル広場とソウル図書館へ。続いて清渓広場から清渓川に下ります。
4. **夕方前** — 清渓川沿いに東へ歩き、鍾閣側に上がって普信閣と公平都市遺跡展示館へ。展示館の入場締切は17:30です。

清渓川をさらに東へ歩くと、乙支路や広蔵市場のほうに出ます。[乙支路まとめ](/ja/posts/euljiro-guide-2026-09/)とあわせて読んでも大丈夫です。

## どこに泊まるか

光化門と市庁の周辺は、官庁とオフィスが集まる業務地区です。ホテルを選ぶときは、週末の集会や12月31日の除夜の鐘の規制で**タクシーでホテルの前まで行きにくくなる**ことがある点に注意してください。駅から歩ける距離かどうか、地図で確認しましょう。比較は[光化門・市庁・鍾閣の宿](/ja/posts/gwanghwamun-hotels-2026-09/)にあります。

## こんな方に向いています

**向いている方です。**

- 歩くことが目的の方。光化門からソウル駅まで、広くなった歩道が続きます
- 朝鮮の王宮の門から1920年代の庁舎、2020年代の広場まで、**ソウル都心の移り変わり**を一度に見たい方
- 無料で見られる場所を中心に予定を組みたい方。広場、清渓川、普信閣、遺跡展示館はすべて無料です

**向いていない方です。**

- 静かな路地と韓屋が目的なら、[北村・三清洞まとめ](/ja/posts/bukchon-guide-2026-09/)や[西村まとめ](/ja/posts/seochon-guide-2026-09/)が合っています
- 週末に車で移動する予定なら、集会による規制を先に確認してください

## まとめ

- 光化門・市庁・鍾閣の4つの広場は、**すべて車道か高架道路をはがした場所**です。
- **光化門広場**：2009年8月1日に16車線を10車線に減らして開場し、**2022年8月6日に西側車道を取り込んで40,300㎡（2.1倍）で再開場**。
- **月台**：1923年に電車の線路のために壊され、**2023年10月15日**に復元。扁額も黒地に金色の文字に変わりました。
- **ソウル広場**：噴水台のロータリーを**79日の工事で2004年5月1日**に芝生広場へ。
- **2つの広場は条例が違います。** ソウル広場は集会・デモを目的に書いた**届出制**、光化門広場は余暇・文化活動のための**許可制**。
- **清渓川**：2003年7月1日に高架撤去、**2005年10月1日**に5.8kmを復元、20年で累計約3億3,000万人。
- **普信閣**：いまの鐘は1985年製で、1468年の古い鐘は国立中央博物館に。すぐ隣の地下には朝鮮の路地42mを残した無料の**公平都市遺跡展示館**。
- [[line:5]] 光化門、[[line:1]] [[line:2]] 市庁、[[line:1]] 鍾閣。週末は集会の規制を確認して、地下鉄で動きましょう。

ひと言でいえば、**光化門から鍾閣までは、ソウル市が20年かけて車線を一本ずつはがし、広場として人に返してきた道**で、その広場ごとに使うルールが違います。
