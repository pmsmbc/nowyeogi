西村（ソチョン）は、**47年間、建物の高さが凍結されていた町**です。

景福宮の隣なので1977年から最高高度地区に指定されており、その規制が**2024年になってはじめて緩和**されました。その間、ソウルの大部分が建て替えられていくあいだ、ここは高くできませんでした。

![屋上から見下ろした西村。低い屋根が続き、遠くに都心の高層ビルが見える](/images/seochon-guide-2026-09/07.webp)

上の写真がその結果です。**低い屋根が続いていき、その先の遠くに都心のビルが見えます。**

## 名前が三つあります

まずここから整理します。同じ場所を指す呼び方が三つあります。

**西村（ソチョン）** — 人々が呼んでいる通称です。

**世宗村（セジョンマウル）** — 住民がつけた名前です。現地の案内板にこう書かれています。

> **2010年から住民は**、世宗大王の魂が生きている文化芸術の村として育てたいという願いを込め、**世宗村と名づけて呼びはじめた。**

役所がつけたのではなく、**住民が呼びはじめた名前**です。世宗大王の生誕の地がここにあります。

「景福宮西側」は、ソウル市の行政文書上の**正式名称**です。町の名前ではなく、**位置を示す語**です。

> 景福宮西側 地区単位計画区域
> 景福宮西側 住居環境管理事業区域

都市計画の文書をお探しになるときは、**景福宮西側**という語で検索しないと出てきません。

### どこまでが西村か

ソウル韓屋ポータルの説明です。

> 景福宮西側は、景福宮の西から仁王山（イナンサン）の麓に至る地域で、朝鮮時代から形成された古い韓屋密集の住居地域である。**ソウル市鍾路区孝子洞、玉仁洞など14の法定洞を含む地域で、北村の面積に比べると3分の1ほどの規模である。**

**北村の3分の1**です。思っているより小さいです。

## なぜ今も低いのか

![世宗村の案内板。村の古い名前と由来が韓国語と英語で書かれている](/images/seochon-guide-2026-09/02.webp)

年表でご覧になると、はっきりします。

| 時点 | 起きたこと |
| --- | --- |
| **1977年5月9日** | 景福宮周辺を**最高高度地区**にはじめて指定 |
| 2010年4月15日 | 地区単位計画区域の指定 |
| 2010年6月24日 | **韓屋密集地域**の指定 |
| 2015年2月17日 | 開発行為許可の制限 |
| **2015年10月8日** | **再開発の整備予定区域3か所を職権解除** |
| **2016年7月14日** | 地区単位計画の再整備 · **フランチャイズの立地を不許可** |
| **2024年6月27日** | **47年ぶり、はじめての高さ緩和**（20m → 24m） |

**1977年から2024年まで、西村の法定の最高高さは15〜20m**でした。4〜6階が物理的な上限だったということです。

2024年に一部の区域（80,747㎡）が24mまで緩和されましたが、ソウル市の報道資料の表現がこうです。

> **1977年の高度地区の最初の指定以来はじめて**、西村地域の一部を20→24mに緩和

**47年ぶり、はじめて**です。

### 再開発はあって、そして解除されました

ここは私が最初に取り違えていた部分です。**西村にも再開発の計画がありました。**

**弼雲（ピルン）・体府（チェブ）・樓下（ヌハ）の三か所が、住宅再開発の整備予定区域**に指定されていました（2006年と2007年）。そして**2015年10月8日に職権解除**されました。

ですから「規制のせいで、はじめから開発が不可能だった」というのは半分しか当たっていません。**開発の経路は実際に一度開き、そして閉じました。**

その翌年に保存型の計画が入ります。2016年7月14日の地区単位計画の再整備で、**住居環境管理事業区域**（563,151.2㎡）が新設され、**最大開発規模200〜1,200㎡**、**フランチャイズ飲食店の立地不許可**が定められました。

### 四つの町を並べると

このブログで扱ってきたソウル都心の四か所は、処方がすべて違います。

- **乙支路（ウルチロ）** — 撤去の決定
- **益善洞（イクソンドン）** — 2018年に整備区域を解除 + 同じ日に保全の仕組み
- **西村** — **1977年の高さ規制 → 2015年の職権解除 → 2016年の保存計画**
- **聖水洞（ソンスドン）** — 2015年の賃料抑制の条例

**西村のほうが、益善洞より3年早かったことになります。**

## フランチャイズがありません

これは歩かれるとすぐに感じられます。ソウル未来遺産の説明文が、その理由を明かしています。

> 2012年の水声洞渓谷の復元を契機に、西村地域は新しい名勝地として脚光を浴びるようになった。しかし、**過度な商業化による主要な景観資源の毀損、ジェントリフィケーション現象などの副作用が発生**した。そこで2016年5月に … **建物の高さを4階に制限し、フランチャイズのパン屋と飲食店の出店を制限**した。

**チェーン店が見当たらないのは、好みではなく計画です。**

## 行き方

[[line:3]] **景福宮（キョンボックン）駅**です。出口を知っておかれると楽です。

| 目的地 | 出口 |
| --- | --- |
| **通仁市場 · 世宗村 飲食文化通り** | **2番出口**（市場まで515m） |
| 水声洞渓谷 | **3番出口**から [[bus:village:9]] 鍾路09番の村バス |
| 鍾路区の公式徒歩コースの集合場所 | 1番出口 |

### 空港バスが停まります

空港リムジンの [[bus:6011]] が、**景福宮駅に停まります。** 停留所は**1番出口、ソウル警察庁の向かい**です。

- 始発**04:31**、終バス**20:48**
- 大人17,000ウォン

**景福宮駅に停まる路線は6011番の一つだけ**です。同じ路線が昌徳宮と安国駅にも停まるので、韓屋の宿の側にも使えます。

## 月曜日にご注意ください

これが西村の落とし穴です。**宮は火曜日に休むのに、西村の施設は月曜日に休みます。**

月曜休館のところです。

- 尹東柱文学館
- 朴魯壽美術館
- 上村斎
- 黄鶴亭 国弓展示館
- 清雲文学図書館
- 仁王山 森の休憩所

**月曜日にお越しになると、見られる屋内の施設がほとんどありません。** ただし**社稷壇は常時開放で無料**なので、月曜日の代わりになります。

逆に**火曜日は景福宮が休むので、西村が代わりになります。** 二つの町をつなげて回られるときは、曜日を合わせてください。

## 一日のコース

![通仁市場の瓦の形をした入口の看板と、その両脇に並ぶ古い商店の建物](/images/seochon-guide-2026-09/09.webp)

西村は小さいです。半日あれば十分です。

1. **[[line:3]] 景福宮駅 2番出口** — 通仁市場でヨプチョン弁当（昼食、月曜休み）
2. **路地歩き** — 韓屋と低い建物のあいだを
3. **水声洞渓谷** — 3番出口から村バス、または歩いて上る
4. **尹東柱文学館**または**朴魯壽美術館**（月曜休館）
5. 夕食は**世宗村 飲食文化通り**

景福宮と隣り合っているので、**午前に景福宮、午後に西村**という組み合わせがいちばんよくある形です。ただし**火曜日は景福宮が休みです。**

## こういう方に向いています

**向いている場合です。**

- 低い町を歩くのがお好きな方
- 景福宮の日程に半日を足したい方
- チェーン店のない町を見たい方
- 韓屋に泊まってみたい方。ソウルの韓屋の宿の4分の1がここにあります

**向かない場合です。**

- 買い物や大型の施設を期待されると、ありません
- 月曜日にお越しになると、屋内の施設がほとんど閉まっています
- 北村のような規模をお考えなら、3分の1の大きさです

## まとめ

- **1977年から2024年まで47年間、高さが凍結**されていました。
- **再開発の整備予定区域3か所が2015年に職権解除**され、その翌年に保存計画が入りました。
- **2016年からフランチャイズのパン屋・飲食店は入れません。**
- **名前が三つ**あります。西村、世宗村（住民が2010年から）、景福宮西側（行政）。
- **北村の3分の1の大きさ**です。
- **景福宮駅2番出口**が市場の方向、**空港バスは6011番**です。
- **西村の施設は月曜休館**、宮は火曜日です。

一行にまとめるとこうです。**西村が低いのは、残したからではなく高くできなかったからで、そうしているあいだに残す値打ちのある町になりました。**
