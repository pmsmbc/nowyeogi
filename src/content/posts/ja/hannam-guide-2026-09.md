梨泰院（イテウォン）と漢南洞（ハンナムドン）は、このブログで取り上げてきたソウルの町のなかで、**規制を緩めてもらった町と、まるごと建て直している町が一本の通りを挟んで隣り合っている**場所です。

梨泰院路一帯は1997年、**ソウルで初めて観光特区**になりました。観光特区とは、もともと**夜も店を開けられるよう営業時間の制限を緩めるため**につくられた制度です。その南と東の斜面、漢南洞・普光洞（ポグァンドン）・東氷庫洞（トンビンゴドン）は2003年に**ニュータウン**に指定され、ソウル市の告示に書かれた完了目標年度の**2025年を過ぎたいま**、撤去工事の真っ最中です。

基本情報（場所、空港からの行き方、町の性格）は先に書いた[梨泰院・漢南洞まとめ](/ja/posts/itaewon-guide-2026-09/)にあります。この記事はその上に、**公式の記録**をもう一枚重ねます。

![漢南大橋側から見た普光洞の丘。赤れんがの低層住宅が斜面をびっしり覆い、頂上に尖塔のある教会が立っている](/images/hannam-guide-2026-09/14.webp)

写真は漢南大橋側から見た**普光洞**の丘です。「漢南ニュータウン」という名前とは違い、再開発区域のかなりの部分はこうした普光洞の斜面にあります。撮影時期は確認できませんでしたが、転居と撤去が進み、この風景は消えつつあります。

## 梨泰院：ソウル初の観光特区

### 名前からして旅人の宿でした

龍山区梨泰院2洞住民センターの町名の由来によると、**梨泰院は朝鮮時代にここにあった駅院（ヨグォン）の名前**です。駅院は公用で旅する人が泊まる宿でした。梨の木が多かったという記録も添えられています。

同じ資料の行政上の移り変わりです。

| 時期 | 名称 |
| --- | --- |
| 1751年 | 漢城府南部 屯之坊 梨泰院契 |
| 1914年 | 京畿道高陽郡漢芝面 梨泰院里 |
| 1936年 | 京城府に編入、梨泰院町 |
| 1943年 | 龍山区に編入 |
| 1946年 | 梨泰院洞 |

住民センターは、この町が**朝鮮戦争後の米軍駐留と外国公館の集中によって国際的なショッピング街になった**と書いています。龍山歴史博物館の常設展示も、解放後に龍山基地へ米軍第24軍団の司令部が入り、朝鮮戦争のなかで米軍の常時駐留が決まったこと、そして**梨泰院一帯に基地村ができた**ことを説明しています。

### 1997年9月25日、ソウル初の観光特区

国家記録院の観光特区の解説をまとめるとこうなります。

- **1993年** 観光振興法に観光特区制度を導入。目的は**夜間観光を活性化するための営業時間制限の緩和**
- **1994年8月31日** 最初の5か所：済州島、慶州、雪岳、儒城、海雲台
- **1997年9月25日** 梨泰院を指定

最初の5か所はすべてソウル以外のリゾート地で、**ソウルで最初に名前が載ったのが梨泰院**でした。この制度がはじめから「夜に店を開けさせる仕組み」だったと知ると、梨泰院が夜の町として知られてきた理由が、行政の記録からも説明できます。

![梨泰院観光特区の石畳の路地。右側にメキシコ風のネオンサインと紙の旗で飾った飲食店があり、奥へ洋服店と看板が続く](/images/hannam-guide-2026-09/08.webp)

### 2025年12月、特区が漢江鎮駅まで

2026年1月8日の報道（市政日報、文化ニュース）によると、梨泰院観光特区は**2025年12月26日のソウル市告示で拡大**されました。

| 項目 | 内容 |
| --- | --- |
| もとの範囲 | 梨泰院路入口〜漢南洞住民センターの約1.4km、梨泰院洞・漢南洞一帯 |
| 拡大後の面積 | 約**39万㎡**（記事によると以前は約38万㎡） |
| 新たに入った場所 | **漢江鎮（ハンガンジン）駅一帯**、リウム美術館、ブルースクエア |
| 龍山区が掲げた目標 | 「訪れる観光地」から「滞在する観光地」へ |

つまり、**漢南洞の美術館通りもいまは観光特区の中**です。2本の記事でもとの1.4km区間の説明の仕方が少し違うため、拡大で加わった境界線の正確な位置はこの記事では断定していません。

## 2022年10月29日のあと

梨泰院について書くなら、2022年10月29日の夜、ハミルトンホテル横の路地で159人が亡くなった惨事を外すことはできません。その後の公式な変化だけを短く記します。

| 時期 | できごと |
| --- | --- |
| 2023年10月26日 | 惨事の路地に**10・29記憶と安全の道**が造られる（10・29梨泰院惨事遺族協議会が主導） |
| 2024年5月21日 | **10・29梨泰院惨事被害者の権利保障と真相究明および再発防止のための特別法**が公布・施行（法律第20427号） |
| 2026年9月15日 | 改正法が公布・施行。特別調査委員会の調査期間を**2027年9月16日まで**1年延長、被害者認定の申請期限は2028年3月16日まで |

京郷新聞の報道によると、記憶と安全の道は**梨泰院駅1番出口から約40m**の路地です。入口の地面には「私たちにはまだ覚えておくべき名前があります」という言葉が刻まれ、ハミルトンホテルの壁には写真作品と惨事の経緯を記したパネルが掲げられています。作品と付箋は2か月に一度入れ替えるそうです。

この路地は梨泰院駅から梨泰院路に出てすぐ横にあります。通るときは**歩みをゆるめ、追悼している人を撮らないこと**が基本です。この記事にはその路地の写真を入れていません。

## 漢南ニュータウン：目標年度を過ぎた再開発

### 告示に書かれていること

漢南ニュータウンの正式名称は**漢南再整備促進地区**です。2023年4月27日のソウル市報に載ったソウル特別市告示第2023-154号の冒頭に、それまでの告示が順に並んでいます。

- **2003年11月18日** ニュータウン地区指定（第2003-372号）
- **2006年10月19日** 再整備促進地区指定（第2006-357号）
- **2009年10月1日** 再整備促進計画決定（第2009-387号）
- **2017年3月30日** 漢南1区域の整備区域**解除**（第2017-112号）
- その後2023年まで、変更決定が10回以上続きます

同じ告示の概要です。

| 項目 | 告示の内容 |
| --- | --- |
| 位置 | 龍山区**普光・漢南・梨泰院・東氷庫洞**一帯 |
| 面積 | **948,390.3㎡** |
| 指定目的 | 老朽住宅が密集し基盤施設が不十分な**普光洞一帯**の住環境改善 |
| 基準年度／目標年度 | 2007年／**2025年** |
| 人口・住宅の受け入れ計画 | 33,012人／12,775世帯 |
| 高さ | 地区全体で建物の最高高さは**海抜90m以下** |

基本方向には**南山のすその丘陵地の景観を損なわないよう**計画するという一文があり、そのため階数ではなく**海抜の高さで上限**をかけているのがこの地区の特徴です。

### 区域別に見ると（2026年5月の報道時点）

| 区域 | 告示上の位置・面積 | 2026年の状況 |
| --- | --- | --- |
| 1区域 | 普光洞151番地一帯 58,795㎡ | 2017年に解除、存置管理区域。迅速統合企画が進行中（ソウル新聞） |
| **2区域** | **普光洞**272-3番地一帯 114,580.6㎡ | 2026年5月13日に都市再整備委員会で修正可決、**1,311世帯**（公共住宅197世帯）。2026年に転居、2027年下半期の着工が目標 |
| **3区域** | **漢南洞**686番地一帯 386,395.5㎡ | 転居完了、撤去は仕上げの段階。最高22階127棟**5,988世帯**、早ければ2026年末に分譲 |
| **4区域** | **普光洞**360番地一帯 160,156㎡ | 2025年11月に事業施行認可、最高22階51棟**2,331世帯** |
| **5区域** | **東氷庫洞**60番地一帯 183,707㎡ | 最近事業施行計画の認可、**2,592世帯** |

4区域の計画を足すと**約1万2,200世帯**です。ソウル新聞は2003年の指定から数えて**23年ぶりに加速した**と書いています。2008年の金融危機で止まり、2019年に3区域の事業施行認可で再び動き出したという説明です。

旅行者に関係があるのはこの点です。**梨泰院路の南、漢南洞・普光洞の斜面では、これから数年、仮囲いと工事車両をよく見かけることになります。** 昔の路地の風景を見にわざわざ行く場所ではなく、すでに空き家になった区画も多くあります。

## わたしが間違えていたこと

この記事を準備しながら、思い込んでいたことが4つ間違っていました。

**ひとつ、漢南ニュータウンは漢南洞の再開発ではありません。** 告示上の区域の位置を見ると、**漢南洞にあるのは3区域だけ**で、2区域と4区域は普光洞、5区域は東氷庫洞です。指定目的の文も「普光洞一帯の住環境改善」から始まります。

**ふたつ、5区域ではなく4区域です。** 1区域は**2017年3月30日に整備区域から解除**され、いまの告示には存置管理区域として残っているだけです。

**みっつ、観光特区は「観光地のお墨付き」ではありませんでした。** 国家記録院の解説のとおり、**1993年の導入時の目的は営業時間制限の緩和**でした。梨泰院が最初の5か所に入らず、1997年に加わったことも今回知りました。

**よっつ、リウム美術館のあたりは特区の外だと思っていました。** 2025年12月の拡大で**漢江鎮駅一帯が特区に入りました**。いまは「梨泰院観光特区」という名前が漢南洞の美術館通りまで覆っています。

## 梨泰院・漢南洞はどこまでか

韓国の住所には、住所に使う「法定洞」と、住民センター単位の「行政洞」があり、両者は一致しないことがあります。

| 名前 | 実体 | 旅行者にとって |
| --- | --- | --- |
| **梨泰院洞** | 法定洞ひとつを行政洞の梨泰院1洞・2洞が分けて担当 | 梨泰院路の中心街、経理団（キョンニダン）キル（観光公社の住所も梨泰院洞） |
| **漢南洞** | 法定洞 | 漢江鎮駅周辺の美術館・セレクトショップ、漢南3区域 |
| **普光洞** | 法定洞 | 漢南2・4区域、大部分が再開発中 |
| **解放村** | 洞の名前ではない。観光公社の住所は**龍山洞2街** | 緑莎坪（ノクサピョン）駅の北、南山の斜面 |
| **梨泰院観光特区** | 1997年指定、2025年拡大、約39万㎡ | 梨泰院路〜漢江鎮駅 |
| **漢南ニュータウン** | 漢南再整備促進地区 948,390.3㎡ | 梨泰院路の南の斜面 |

![解放村の坂道。木の手すりのついた階段が緑の間を上り、その先の青空にNソウルタワーがそびえる。道端に車と自転車が停まっている](/images/hannam-guide-2026-09/03.webp)

**解放村**（ヘバンチョン）は、その名のとおり解放後にできた村です。龍山歴史博物館は、解放後に北から南へ移ってきた人や戦争で住まいを失った人たちが**龍山基地近くの南山のすそに村をつくった**と説明しています。写真のように、階段の上にNソウルタワーが近く見えます。

## 西側の塀：龍山基地と龍山公園

梨泰院の西の端は、長いあいだ**米軍龍山基地の塀**でした。返還された土地の一部は「龍山子ども庭園」という名前で仮開放されてきましたが、ふたつのことが変わりました。

- **2025年12月30日** 国土交通部が事前予約と身元確認をやめ、**誰でも自由に出入りできるよう全面開放**しました。運営は火〜日の9時〜18時、土曜は21時まで、**月曜休み**。仮開放以来の累計来場者は180万人を超えたとのことです。名前も2026年上半期に意見を集めて変えると発表しました。
- **2026年8月14日** 国土交通部の次官がラジオのインタビューで、**子ども庭園の敷地を住宅供給に活用する案をソウル市と協議する**と述べ、ソウル市は反対の立場だとソウル新聞が報じました。同じ記事によると龍山公園全体は約100万坪（約330万㎡）、子ども庭園は約9万坪（約29万7,000㎡）です。

新しい名前が決まったのか、住宅供給の議論がどうなったのかは、執筆時点で確認できませんでした。行く前に国土交通部の龍山公園造成推進企画団の案内を一度確認してください。

## こう歩いてください

西の丘から東の漢江へ、**解放村 → 梨泰院路 → 漢南洞**の順が地下鉄3駅と重なります。

1. **午前** — [[line:6]]緑莎坪駅から解放村・経理団キルの坂道へ。上り坂がきついので歩きやすい靴で。
2. **昼** — 梨泰院路に下りて食事。選び方は[梨泰院・漢南洞のグルメ](/ja/posts/hannam-food-2026-09/)の記事にあります。
3. **午後** — ウサダンギルの上のソウル中央聖院、続いて漢江鎮駅側の美術館通り。回る順番と営業時間は[梨泰院・漢南洞の見どころ](/ja/posts/hannam-things-to-do-2026-09/)の記事にまとめました。
4. **時間があれば** — 龍山公園の返還地へ。月曜休みなので曜日を確認してください。

## どこに泊まるか

観光特区の拡大で梨泰院駅と漢江鎮駅のあいだがひとつのエリアにまとまりましたが、**宿の性格はいまも駅ごとに違います**。梨泰院駅の周辺は夜遅くまでにぎやかで、漢江鎮駅側は静かな代わりに価格帯が高めです。比較は[梨泰院・漢南洞の宿](/ja/posts/hannam-hotels-2026-09/)の記事にあります。再開発区域に近い宿は工事の音があるかもしれないので、地図で位置を一度確認してください。

## こんな方に向いています

**向いている方です。**

- 世界各国の料理と夜の時間を中心に町を見たい方
- 美術館を一日の予定の中心に置きたい方。漢江鎮駅側はいまや特区の中です

- 坂道がつらい方は、解放村・経理団キルは外して梨泰院路と漢江鎮駅側だけを回ってください

## まとめ

- **梨泰院は朝鮮時代の駅院、つまり旅人の宿の名前**に由来します。
- **1997年9月25日にソウル初の観光特区**になり、この制度はもともと**営業時間の制限を緩めるため**のものでした。
- **2025年12月26日**、特区が**漢江鎮駅一帯**（リウム・ブルースクエア）まで広がり、約39万㎡になりました。
- **漢南ニュータウン、正式には漢南再整備促進地区は2003年指定、948,390.3㎡、目標年度2025年**。漢南洞にあるのは3区域だけで、2・4区域は普光洞、5区域は東氷庫洞です。
- 2026年5月時点で、**3区域は撤去の仕上げ、4区域は事業施行認可、2区域は2027年下半期着工が目標、5区域は事業施行計画認可**。4区域合計で約1万2,200世帯です。
- **10・29記憶と安全の道**は梨泰院駅1番出口横の路地で、特別調査委員会の活動は**2027年9月16日まで**延長されました。
- 西から東へ、**緑莎坪**（解放村・経理団キル）、**梨泰院**（中心街）、**漢江鎮**（美術館通り）の3駅が続きます。

ひと言でいえば、**梨泰院は夜を延ばしてもらったソウル初の観光特区で、その南の漢南洞・普光洞は目標年度を過ぎて、まるごと建て直されている途中**です。
