2026年9月29日、ザ・ファクトは漢南ニュータウン3区域の**撤去工程が99%** に達し、年内に着工すると伝えました。2003年のニュータウン指定から23年ぶりの着工です。その9か月前の2025年12月26日には、漢江鎮（ハンガンジン）駅一帯（リウム美術館・ブルースクエア）がソウル市の告示で**梨泰院観光特区に入りました。** 漢南洞はいま、**美術館通りが観光特区になり、その南の斜面がまるごと建て直される**、ふたつの記録が重なった町です。

この記事は、そのふたつの記録をソウル市の告示と日付のある報道で確かめたまとめです。梨泰院の名前の由来、1997年の観光特区指定、10・29記憶と安全の道、解放村、ソウル中央聖院は[梨泰院旅行ガイド](/ja/posts/itaewon-guide-2026-09/)に移しました。見どころの回り方は[漢南洞の見どころ](/ja/posts/hannam-things-to-do-2026-09/)、食事は[漢南洞のグルメ](/ja/posts/hannam-food-2026-09/)、宿は[漢南洞の宿](/ja/posts/hannam-hotels-2026-09/)にあります。

![漢南大橋側から見た普光洞の丘。赤れんがの低層住宅が斜面をびっしり覆い、頂上に尖塔のある教会が立っている](/images/hannam-guide-2026-09/14.webp)

写真は漢南大橋側から見た**普光洞（ポグァンドン）** の丘です。「漢南ニュータウン」という名前とは違い、再開発区域のかなりの部分はこうした普光洞の斜面にあります。撮影時期は確認できませんでしたが、転居と撤去が進み、この風景は消えつつあります。

## 漢南洞をひと目で

ウィキペディア韓国語版は漢南洞を「**龍山区から江南方面へ渡る通り道**」と説明しています。

| 項目 | 内容 | 出典 |
| --- | --- | --- |
| 境界 | 東は城東区、西は梨泰院洞・普光洞、北西は梅峰山（南山の尾根）、南は漢江 | ウィキペディア 漢南洞 |
| 大通り | **漢南大路が町を二つに分け**、漢南大橋を経て京釜高速道路へ | ウィキペディア 漢南洞 |
| 規制 | かなりの部分が**南山景観地区** | ウィキペディア 漢南洞 |
| 古い地名 | 漢南洞726番地の漢南小学校・海兵隊軍楽隊の場所は「陵トゴル」と呼ばれ、朝鮮時代に王陵の候補地とされた場所 | ウィキペディア 漢南洞 |
| 行政洞の漢南洞 | **2.99㎢、23,964人**（2018年第2四半期）。龍山区の行政洞でいちばん広い | ウィキペディア 龍山区の行政区域 |
| 移り変わり | 1975年10月1日に漢南洞の一部が中区へ編入、2008年6月30日に漢南1洞・2洞を漢南洞に統合 | ウィキペディア 龍山区の行政区域 |

### この記事の漢南洞はどこまでか

**このブログの境界**：龍山区の行政洞を基準に分けています。**梨泰院1洞・梨泰院2洞（法定洞は梨泰院洞）と龍山2街洞（解放村）** は[梨泰院旅行ガイド](/ja/posts/itaewon-guide-2026-09/)で、**漢南洞の行政洞**と、その南に続く漢南再整備促進地区（普光洞・東氷庫洞を含む）は[漢南洞旅行ガイド](/ja/posts/hannam-guide-2026-09/)で扱います。例外が3つあります。ひとつめ、ウサダンギルとソウル中央聖院は、韓国観光公社とウィキペディアでは住所が法定洞の漢南洞ですが、梨泰院駅3番出口の生活圏なので梨泰院側に入れました。ふたつめ、戦争記念館は住所が龍山洞1街（三角地駅側）ですが、梨泰院側の見どころとして扱います。みっつめ、龍山子ども庭園など龍山公園の返還地と、住所が梨泰院洞の旧将校宿舎5団地跡（南山韓国の森庭園）は漢南洞側で扱います。梨泰院観光特区も、1997年の指定と梨泰院路の区間は梨泰院の記事、2025年12月の漢江鎮駅一帯への拡大は漢南洞の記事にあります。

## 2025年12月、観光特区が漢江鎮駅まで

梨泰院観光特区がいつ、なぜ指定されたかは[梨泰院旅行ガイド](/ja/posts/itaewon-guide-2026-09/)にあります。漢南洞にかかわるのは、その次の変化です。

2026年1月8日の報道（市政日報、文化ニュース）によると、梨泰院観光特区は **2025年12月26日のソウル市告示で拡大**されました。

| 項目 | 内容 |
| --- | --- |
| もとの範囲 | 梨泰院路入口〜漢南洞住民センターの約1.4km、梨泰院洞・漢南洞一帯 |
| 拡大後の面積 | **約39万㎡**（記事によると以前は約38万㎡） |
| 新たに入った場所 | **漢江鎮駅一帯**、リウム美術館、ブルースクエア |
| 龍山区が掲げた目標 | 「訪れる観光地」から「滞在する観光地」へ |

つまり、**漢南洞の美術館通りもいまは観光特区の中**です。2本の記事でもとの1.4km区間の説明の仕方が少し違うため、拡大で加わった境界線の正確な位置はこの記事では断定していません。

## 漢南ニュータウン：目標年度を過ぎた再開発

### 告示に書かれていること

漢南ニュータウンの正式名称は**漢南再整備促進地区**です。2023年4月27日のソウル市報に載ったソウル特別市告示第2023-154号の冒頭に、それまでの告示が順に並んでいます。

- **2003年11月18日** ニュータウン地区指定（第2003-372号）
- **2006年10月19日** 再整備促進地区指定（第2006-357号）
- **2009年10月1日** 再整備促進計画決定（第2009-387号）
- **2017年3月30日** 漢南1区域の整備区域**解除**（第2017-112号）
- その後2023年まで、変更決定が10回以上続きます

同じ告示の概要です。

| 項目 | 告示の内容 |
| --- | --- |
| 位置 | 龍山区**普光・漢南・梨泰院・東氷庫洞**一帯 |
| 面積 | **948,390.3㎡** |
| 指定目的 | 老朽住宅が密集し基盤施設が不十分な**普光洞一帯**の住環境改善 |
| 基準年度／目標年度 | 2007年／ **2025年** |
| 人口・住宅の受け入れ計画 | 33,012人／12,775世帯 |
| 高さ | 地区全体で建物の最高高さは**海抜90m以下** |

基本方向には**南山のすその丘陵地の景観を損なわないよう**計画するという一文があり、そのため階数ではなく**海抜の高さで上限**をかけているのがこの地区の特徴です。ウィキペディアが書く南山景観地区と同じ流れです。

### 区域別に見ると（2026年5月の報道時点）

| 区域 | 告示上の位置・面積 | 2026年5月の状況 |
| --- | --- | --- |
| 1区域 | 普光洞151番地一帯 58,795㎡ | 2017年に解除、存置管理区域。迅速統合企画が進行中（ソウル新聞） |
| **2区域** | **普光洞**272-3番地一帯 114,580.6㎡ | 2026年5月13日に都市再整備委員会で修正可決、**1,311世帯**（公共住宅197世帯）。2026年に転居、2027年下半期の着工が目標 |
| **3区域** | **漢南洞**686番地一帯 386,395.5㎡ | 転居完了、撤去は仕上げの段階。最高22階127棟 **5,988世帯**、早ければ2026年末に分譲 |
| **4区域** | **普光洞**360番地一帯 160,156㎡ | 2025年11月に事業施行認可、最高22階51棟 **2,331世帯** |
| **5区域** | **東氷庫洞**60番地一帯 183,707㎡ | 最近事業施行計画の認可、**2,592世帯** |

4区域の計画を足すと**約1万2,200世帯**です。ソウル新聞は2003年の指定から数えて **23年ぶりに加速した**と書いています。2008年の金融危機で止まり、2019年に3区域の事業施行認可で再び動き出したという説明です。

### 2026年9月に変わったこと

4か月後、ザ・ファクト（2026年9月29日）はこう伝えています。

| 区域 | 2026年9月の報道内容 |
| --- | --- |
| 3区域 | 2025年2月に撤去開始、**撤去工程99%、年内着工の予定**。2023年6月に管理処分計画認可、2029年入居予定。約6,000世帯 |
| 2区域 | 転居率99%、**2027年着工の予定**。2025年7月に管理処分計画認可。地下6階〜地上14階、1,311世帯 |
| 4区域 | 2026年5月に組合員分譲申請、11月に管理処分計画の総会予定。地下7階〜地上20階、2,360世帯 |
| 5区域 | 2026年4月に事業施行計画認可、10月から組合員分譲申請。地下5階〜地上22階44棟 2,401世帯とオフィステル146室 |
| 1区域 | 2025年2月にソウル市の迅速統合企画住宅再開発の候補地に選定 |

ザ・ファクトは5区域がすべて完成すると**約1万3,000世帯**になると書いています。5月の報道とは世帯数・階数が少しずつ違います。

旅行者に関係があるのはこの点です。**梨泰院路の南、漢南洞・普光洞の斜面では、これから数年、仮囲いと工事車両をよく見かけることになります。** 昔の路地の風景を見にわざわざ行く場所ではなく、すでに空き家になった区画も多くあります。

## 西側の返還地：龍山公園

漢南洞から梨泰院路を西へ進むと、長いあいだ**米軍龍山基地の塀**に行き当たりました。返還された土地の一部は「龍山子ども庭園」という名前で仮開放されてきましたが、ふたつのことが変わりました。

- **2025年12月30日** 国土交通部が事前予約と身元確認をやめ、**誰でも自由に出入りできるよう全面開放**しました。運営は火〜日の9時〜18時、土曜は21時まで、**月曜休み**。仮開放以来の累計来場者は180万人を超えたとのことです。名前も2026年上半期に意見を集めて変えると発表しました。
- **2026年8月14日** 国土交通部の次官がラジオのインタビューで、**子ども庭園の敷地を住宅供給に活用する案をソウル市と協議する**と述べ、ソウル市は反対の立場だとソウル新聞が報じました。同じ記事によると龍山公園全体は約100万坪（約330万㎡）、子ども庭園は約9万坪（約29万7,000㎡）です。

行く前に国土交通部の龍山公園造成推進企画団の案内を一度確認してください。南山韓国の森庭園など、返還地のほかの施設の運営時間は[漢南洞の見どころ](/ja/posts/hannam-things-to-do-2026-09/)にまとめています。

| 2026年8月14日 | 国土交通部次官、子ども庭園敷地の住宅活用の協議に言及 |
| **2026年9月** | **3区域の撤去工程99%、年内着工の予定** |
| 2029年 | 3区域の入居予定 |

**漢南洞の記録は「中に入る」側（観光特区への編入）と「建て直す」側（再整備促進地区）が同じ年に重なりました。** 2025年はニュータウンの目標年度であり、特区が漢江鎮駅まで広がった年です。

## こんなふうに回ってください

1. **午前** — [[line:6]] 漢江鎮駅から美術館通りへ。開館時間と休館日は[漢南洞の見どころ](/ja/posts/hannam-things-to-do-2026-09/)で確認してください。
2. **昼** — 漢南大路の両側の路地で食事。選び方は[漢南洞のグルメ](/ja/posts/hannam-food-2026-09/)に。
3. **午後** — 漢南大路を南へ、[[line:gyeongui]] 漢南駅と漢江沿いへ。再開発区域は仮囲いの向こうに見えるだけで、工事現場には入らないでください。
4. **時間があれば** — 西の梨泰院駅方面へ。[梨泰院旅行ガイド](/ja/posts/itaewon-guide-2026-09/)を参考に。月曜は龍山子ども庭園が休みです。

## どこに泊まるか

観光特区の拡大で梨泰院駅と漢江鎮駅のあいだがひとつのエリアにまとまりましたが、**宿の性格はいまも駅ごとに違います**。梨泰院駅の周辺は夜遅くまでにぎやかで、漢江鎮駅側は静かな代わりに価格帯が高めです。漢江鎮・漢南側の比較は[漢南洞の宿](/ja/posts/hannam-hotels-2026-09/)に、梨泰院駅・解放村側は[梨泰院・解放村の宿](/ja/posts/itaewon-hotels-2026-09/)にあります。再開発区域に近い宿は工事の音があるかもしれないので、地図で位置を一度確認してください。

## こんな方に向いています

**向いている方です。**

- 美術館と公演会場を一日の予定の中心に置きたい方。漢江鎮駅側はいまや特区の中です
- 都市が町をまるごと建て直す過程、**告示や認可のような行政の記録の裏にある話**に興味がある方
- 漢江と漢南大橋のほうへ歩くルートを求める方

**向いていない方です。**

- 古い路地や昔ながらの住宅街の風景が目的なら、漢南・普光洞の斜面は工事中です。[北村旅行ガイド](/ja/posts/bukchon-guide-2026-09/)や[延南洞・望遠洞旅行まとめ](/ja/posts/yeonnam-guide-2026-09/)が合っています
- 世界の料理と夜の時間が中心なら、[梨泰院旅行ガイド](/ja/posts/itaewon-guide-2026-09/)のほうが合っています

## まとめ

- **境界**：行政洞の漢南洞と、その南の漢南再整備促進地区（普光洞・東氷庫洞を含む）、龍山公園の返還地。梨泰院1・2洞と解放村は[梨泰院旅行ガイド](/ja/posts/itaewon-guide-2026-09/)。
- **漢南洞**：漢南大路が分ける江南への通り道、南山景観地区、行政洞は2.99㎢（2018年）。
- **2025年12月26日**、梨泰院観光特区が**漢江鎮駅一帯**（リウム・ブルースクエア）まで広がり、約39万㎡になりました。
- **漢南ニュータウン、正式には漢南再整備促進地区は2003年指定、948,390.3㎡、目標年度2025年**。漢南洞にあるのは3区域だけで、2・4区域は普光洞、5区域は東氷庫洞です。
- **2026年9月**、3区域は撤去工程99%で年内着工の予定、2区域は2027年着工の予定。5区域合計で約1万3,000世帯（ザ・ファクト）。
- **龍山子ども庭園**は2025年12月30日から予約なしで開放、月曜休み。

ひと言でいえば、**漢南洞は美術館通りが観光特区の中に入る一方で、その南の斜面が目標年度を過ぎて、まるごと建て直されている途中の町**です。
