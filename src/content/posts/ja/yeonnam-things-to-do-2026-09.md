延南洞（ヨンナムドン）と望遠洞（マンウォンドン）でできることは、ほとんど**入場券がいりません**。線路跡の公園を歩き、市場を抜けて、漢江（ハンガン）のほとりに座る。それで全部です。

そのかわり、**ルールと時間**があります。「ヨントラルパーク」は飲酒清浄地域で、バスキングは1日3枠だけ許可されています。漢江の軍艦公園は月曜日に休み、空公園（ハヌル公園）は夜になると門を閉めます。この記事はそのルールと時間を公式資料で整理し、**時間帯別のルート**をつけました。

[弘大の見どころ](/ja/posts/hongdae-things-to-do-2026-09/)では京義線森の道・望遠市場・漢江を短く紹介しましたが、ここでは延南洞と望遠洞だけを深く見ます。町全体の概要は[延南洞・望遠洞まとめ](/ja/posts/yeonnam-guide-2026-09/)にあります。

## 京義線森の道 延南洞区間 — 1.2kmか1.3kmか

**京義線森の道**（キョンイソン・スプキル）は、麻浦区から龍山区までつづく**全長6.3kmの線形公園**です。ソウルの公園の案内によると、2012年3月の大興洞区間から順につくり、**2016年に全区間が完成**しました。地下に移った旧龍山線の線路跡です。

そのうちの**延南洞区間**が、セントラルパークをもじって「ヨントラルパーク」と呼ばれる場所です。

- **範囲：延南交差点〜弘大入口駅**
- **長さ：約1.2km**（ソウルの公園）。麻浦区の文化観光サイトは**1.3km**と書いています。
- ソウルの公園の案内によると、**イチョウの並木と860mの水路**がつづき、線路や小さな駅を模した休憩所があちこちにあります。
- 最寄り駅：弘大入口駅 [[line:2]] [[line:gyeongui]] [[line:arex]]、加佐駅 [[line:gyeongui]]
- **公園専用の駐車場はありません**。公共交通で来てください。

### バスキングは1日3枠

公園が許可するバスキングの場所は、**弘大入口駅3番出口〜延南派出所の約200m**です。

| | バスキングの時間 |
| --- | --- |
| 1部 | 11:00〜13:00 |
| 2部 | 14:00〜16:00 |
| 3部 | 17:00〜19:00 |

ソウル市の公共サービス予約で、**先着順・無料の申し込み**で出演者が決まります。つまり公園の公式な公演は**夜7時に終わります**。夜に聞こえる音楽は、公園が許可した公演ではないかもしれません。

同じ**弘大入口駅3番出口〜延南洞派出所の交差点**は、**撮影不可の区域**でもあります。個人の写真ではなく、放送や広告のような許可制の撮影の話です。

### 飲酒清浄地域 — 飲むこと自体は禁止ではありません

延南洞の芝生でコンビニのビールを飲む風景は有名です。ところが**京義線森の道は飲酒清浄地域**です。ソウル市が直営する公園22か所のひとつで、取り締まりは2018年4月1日からです（ソウル市のカードニュース）。

- **禁止されること：お酒を飲んで、ひどい騒音や悪臭で他人に不快感を与える行為**
- **過料10万ウォン以下**
- ソウル市は、**公園での飲酒そのものは禁止ではない**と明記しています。

両側が住宅地だということを覚えておけば大丈夫です。人の多い延南洞区間で道を聞きたいときは、**延南派出所前の延南詰所**の職員にたずねるよう公園が案内しています。詰所にはリーフレットもあります。

## 望遠漢江公園 — 7.4kmの川辺

![晴れた日の望遠漢江公園の丘。松のあいだを通る階段状の散策路の向こうに、広い漢江と赤いアーチの橋が見える](/images/yeonnam-things-to-do-2026-09/16.webp)

漢江公園を管理する未来漢江本部の基準で、**長さ7.4km、面積422,347平方メートル**です。元暁大橋の北端から上岩洞の弘済川橋の手前までです。芝生、運動施設、**自転車道7.2km**、売店（コンビニ）2か所、トイレ11か所があります。

### 行き方 — ナドゥルモク

川沿いの高速道路・江辺北路が、町と公園を分けています。その下をくぐる通路を**ナドゥルモク**と呼びます。公式の案内は出発する方向ごとにこう分けています。

| 出発 | 使う道 |
| --- | --- |
| 望遠駅の方向 | 望遠・城山・合井のナドゥルモク、望遠チョロッキル |
| 合井駅8番出口の方向 | **望遠チョロッキル**（自転車道） |
| 望遠郵便局交差点の方向 | 望遠ナドゥルモク |
| 麻浦区庁駅7番出口の方向 | **弘済川の散策路** |

バスなら、望遠駅 [[line:6]] 1番出口か合井駅 [[line:2]] [[line:6]] 1番出口から、[[bus:village:09]] 麻浦09・[[bus:village:16]] 麻浦16の村バスに乗り「望遠漢江公園」で降ります。村バスは町内を回る小型バスで、T-moneyも同じように使えます。

### 知っておきたいルール

- **ごみは持ち帰り。違反すると過料10万ウォン**
- 日よけテントは**3〜11月、許可区域だけ**（望遠には上流・下流の2か所）
- 公園内の**指定場所以外の駐車は過料5万ウォン**。週末・祝日は公共交通がすすめられています。
- 禁煙、炊事禁止、ペットはリード着用

### 自転車はタルンイで

漢江公園の**自転車貸出所12か所のリストに、望遠はありません**。江北側で近いのは下流の蘭芝（ナンジ）の貸出所です。望遠では、ソウル市の公共自転車**タルンイ**（따릉이）が現実的です。

- **1時間券1,000ウォン、2時間券2,000ウォン**（1日券）
- 基本時間を超えると**5分ごとに200ウォン**
- 1日券は24時間有効で、**1回の貸出時間を守れば何度でも借り直せます**（ソウル市の媒体）。
- 外国人観光客は、アプリかサイトで外国人利用を選び、**海外で発行されたクレジットカード**で利用券を買います。カード1枚につき1枚です（タルンイのよくある質問）。

### 漢江バスとプール

望遠漢江公園には**漢江バスの望遠船着場**があります。2026年3月1日に全区間の運航を再開したとき、汝矣島を中心に東部（蚕室〜汝矣島）と西部（麻谷〜汝矣島）に分かれ、望遠は西部路線です。3月の告知では**大人3,000ウォン**で、現金は使えません。運航時間はその後も何度か変わっているので、**漢江バスの公式サイトかNAVER地図・カカオマップで当日確認**してください。

プールは**望遠にはありません**。また未来漢江本部は、**2026年の漢江公園のプール・水遊び場の運営が終わった**と告知しています（汝矣島のプールは8月30日に終了）。

## ソウル艦公園 — 月曜日に休む軍艦3隻

![川沿いの自転車道の横に停泊する灰色の護衛艦ソウル艦。甲板にミサイル発射筒と艦砲があり、かすんだ対岸にビルが見える](/images/yeonnam-things-to-do-2026-09/13.webp)

望遠漢江公園の中、子ども野球場の横にある**ソウル市初の艦上テーマパーク**です。退役した軍艦**3隻**をそのまま保存しています。

- **ソウル艦**：護衛艦、1,900トン。30年の任務を終えて退役
- **チャムスリ**：高速艇、150トン
- **トルゴレ級潜水艦**：175トン
- 案内センターの屋上に**図書館**

未来漢江本部は、このあたりの川辺が**朝鮮時代の水軍の訓練場**で、王が訓練を見に来たこともあったと紹介しています。

| | 開館時間 |
| --- | --- |
| 火〜金 | 10:00〜19:00 |
| 土・日 | 10:00〜20:00 |
| 休館 | **月曜日**、1月1日、旧正月・秋夕の当日 |

入場は**閉館30分前**までです。上の時間は3〜10月の夏季の基準です。

| 入場料 | 個人 | 団体（20人以上） |
| --- | --- | --- |
| 大人 | **3,000ウォン** | 2,000ウォン |
| 青少年（13〜18歳）・軍人 | 2,000ウォン | 1,400ウォン |
| 子ども（6〜12歳） | 1,000ウォン | 700ウォン |

**週末・祝日には無料のドーセント**があります（夏季13:30・16:00、冬季13:00・15:00）。何語で行われるかは公式ページに書かれていません。

望遠駅1番出口から [[bus:village:09]] 麻浦09に乗り、「漢江公園入口」で降りて歩いて7分です。

## 望遠亭 — 名前がふたつある東屋

望遠洞という町の名前は、この東屋から来ています。国家遺産ポータルの登録名は**望遠亭址**で、**ソウル特別市記念物**（1990年6月18日の指定）です。

ソウル市の媒体「내 손안에 서울」によると、次のとおりです。

- **1424年、孝寧大君**（世宗の兄）が建てた東屋
- 世宗がここで恵みの雨を見て喜び、**喜雨亭**（うれしい雨に出会った東屋）という名がついた
- のちに**月山大君**（成宗の兄）が建て直し、遠くを望むという意味の**望遠亭**に改めた
- **1925年の乙丑年の大洪水**などで失われ、**1989年に建て直された**

そのため今も、**外側に望遠亭、内側に喜雨亭の扁額**がかかっています。

いまは目の前を江辺北路が走っています。ソウル市の媒体は、路地の突き当たりの低い門と、急な階段の上の2階建ての東屋を描写しています。住所は**東橋路8アンギル23**、合井駅8番出口から約870mです。

**開放時間は公式資料で確認できませんでした**。管理団体は麻浦区です。

## 望遠市場 — 歩く道として短く

**望遠市場**（浦隠路6ギル27）は、望遠駅2番出口から歩いて5分です。営業時間は**店舗ごとに異なる**というのが韓国観光公社の案内です。

この記事では、市場を**駅と漢江のあいだの通り道**として扱います。ソウル市の媒体は、市場から望遠漢江公園まで**歩いて10分以内**と紹介しています。市場の食べ物は[延南洞・望遠洞のグルメ](/ja/posts/yeonnam-food-2026-09/)にまとめました。

## 住民が案内する無料の街歩きツアー

麻浦区は、**住民ガイドと歩く麻浦マウル旅行**を運営しています。延南洞と望遠洞のコースがそれぞれあります。

## 空公園 — 10月17〜23日のソウルススキ祭り

![秋の空公園。白い穂が開いたススキ原のあいだにロープの柵で囲まれた土の道が続き、遠くに風力発電機が3基立っている](/images/yeonnam-things-to-do-2026-09/10.webp)

望遠から [[line:6]] で西へ2駅、ワールドカップ競技場駅のそばに**ワールドカップ公園**があります。1978年から1993年まで**ソウルのごみを埋めていた蘭芝島**を安定化させ、2002年5月に公園として開いた場所です。そのうち**空公園**が、第2埋立地の上の草地の公園です。

**第25回ソウルススキ祭り**が決まりました。

- **2026年10月17日（土）〜23日（金）、10:00〜21:00**
- 場所：ワールドカップ公園 空公園一帯
- 問い合わせ：西部公園余暇センター 02-300-5574

**ワールドカップ公園は夜に立ち入りを止めます**。生き物の保護のためです。

| | 開場 | 閉場 |
| --- | --- | --- |
| 4〜9月 | 06:00 | 22:00 |
| 10〜3月 | 06:00 | **21:00** |

**上るまでが長いです**。ソウル市は、[[line:6]] ワールドカップ競技場駅か麻浦区庁駅から**歩いて約40分**、または蘭芝川公園の駐車場から**メンコンイ電気車**に乗るよう案内しています。電気車は蘭芝川公園↔空公園頂上で**片道2,000ウォン、往復3,000ウォン**です。祭りの期間は交通がとても混むので、公共交通がすすめられています。

## 時間帯別のルート

**午前 — 延南洞**
弘大入口駅3番出口から、京義線森の道の延南洞区間を延南交差点の方へ。イチョウ並木と水路がつづく約1.2kmです。11時から最初のバスキングの枠が始まります。

**昼〜午後 — 望遠洞**
[[line:6]] 望遠駅に移り、望遠市場を抜けて望遠漢江公園へ。途中で望遠亭（東橋路8アンギル）に寄れます。午後は**ソウル艦公園**（月曜日を除く）か、タルンイで川沿いを走る。

**夕暮れ — 漢江**
川辺の芝生でひと休み。ごみは持ち帰ってください。ソウル艦公園は週末20時、平日19時までです。

**10月17〜23日なら**
午後を空公園に使ってください。歩いて40分か電気車で、**21時に門が閉まります**。

## まとめ

- **京義線森の道の延南洞区間は約1.2km**で、延南交差点〜弘大入口駅。公園が許可するバスキングは**11〜13・14〜16・17〜19時**。
- **飲酒清浄地域**なので、騒音などで迷惑をかけると**過料10万ウォン以下**。飲むこと自体は禁止ではありません。
- **望遠漢江公園は7.4km**。ごみは持ち帰り（過料10万ウォン）、自転車は**タルンイ**（望遠に漢江の貸出所なし）。
- **ソウル艦公園は月曜休館**、大人3,000ウォン、週末は20時まで。
- **望遠亭**は外に望遠亭、内に喜雨亭のふたつの扁額。1989年に復元。
- **ソウルススキ祭りは10月17〜23日**、空公園は10月は**21時に閉場**。
