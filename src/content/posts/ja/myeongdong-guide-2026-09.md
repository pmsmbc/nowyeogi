明洞に住民登録している人は2,494人です（中区、2026年6月末）。ところが、この町を1日に通る外国人は平均**10万910人**（ソウルAI財団、2025年）。住む人より訪れる人が40倍も多い町、それが明洞です。

先に結論を言うと、明洞は**ソウルで外国人がいちばん多く歩く1平方キロメートル**で、その人数をさばくために区役所が屋台に名札を付け、店に値札を貼らせ、街灯に電光掲示板を立てた町です。この記事は、その明洞を公式記録で組み立て直す総まとめ編です。朝鮮時代の明礼坊、日本統治期の明治町から1946年に「明るい町」明洞になるまで、1898年の聖堂と旧国立劇場、2000年の観光特区指定、そして2026年9月に裁判所でふたたび止められた南山ゴンドラまでを追います。

見どころ・グルメ・宿はそれぞれ[明洞の見どころ](/ja/posts/myeongdong-things-to-do-2026-09/)、[明洞グルメ](/ja/posts/myeongdong-food-2026-09/)、[明洞の宿](/ja/posts/myeongdong-hotels-2026-09/)にまとめました。北の乙支路（ウルチロ）は[乙支路旅行まとめ](/ja/posts/euljiro-guide-2026-09/)、西の市庁・北倉洞（プクチャンドン）側は[光化門・市庁・鐘閣まとめ](/ja/posts/gwanghwamun-guide-2026-09/)で扱っています。

## 名前の歴史：明礼坊、明治町、明洞

### 朝鮮時代の「南村」

朝鮮時代、この一帯は漢城府南部の**明礼坊**（ミョンネバン）でした。韓国民族文化大百科事典と中区の資料によると、いまの「明洞」という名前はこの明礼坊の「明」から来ています。北の両班（ヤンバン、貴族）の町・北村（プクチョン）に対して、南山のふもとの町は**南村**（ナムチョン）と呼ばれ、韓国語版ウィキペディアは貧しい学者が多く住んでいた所だと書いています。

明礼坊が記録に大きく残ったのはカトリックのためです。韓国語版ウィキペディアによると、**1784年**、李承薫（イ・スンフン）ら初期の信者が明礼坊の**金範禹（キム・ボムウ）の家**に集まり、信仰共同体をつくりました。韓国観光公社は明洞聖堂を「韓国カトリック教会の共同体が初めて誕生した場所」と紹介しています。聖堂がわざわざこの丘に建った理由です。

### 明治町と本町

日本統治期、この土地は**明治町**（めいじちょう）になりました。日本の元号「明治」から取った名前です。韓国語版ウィキペディアは、1943年6月10日に明治町1・2丁目が中区の管轄に整理されたと記しています。すぐ南のいまの忠武路は**本町**（ほんまち）で、明治町とともに日本人の商業・居住の中心でした。明洞が「平地の商業ブロック」として形づくられたのはこの時期からだ、というのがウィキペディアの説明です。

### 1946年、明るい町

解放後の**1946年**、明治町は明洞1街・2街になりました。ソウル市の記事は「明るい町、明るい村」という意味を込めたと伝え、百科事典は1955年に2つの街が「明洞」にまとめられたと書いています。日本の元号から来た名前を消し、朝鮮時代の町名・明礼坊の「明」をよみがえらせたわけです。

## 聖堂と劇場：2つの目印

### 明洞聖堂、1898年

![晴れた秋の日、階段の下から見上げた明洞聖堂。赤レンガの鐘楼に緑の尖塔がそびえ、街灯と垂れ幕の横を人々が階段を上っていく](/images/myeongdong-guide-2026-09/62.webp)

繁華街の南の端、丘の上の赤レンガの建物が**明洞聖堂**です。韓国語版ウィキペディアと国家遺産の資料をまとめるとこうなります。

| 時期 | できごと |
| --- | --- |
| 1784年 | 明礼坊の金範禹の家で最初の信仰共同体 |
| 1887年 | 敷地の確保を終え、整地を始める |
| 1892年8月5日 | 起工 |
| **1898年5月29日** | **献堂（完成・奉献）**。フランス人宣教師コスト神父が設計・監督 |
| **1977年11月22日** | **史跡に指定**（国家遺産ポータル） |
| 1987年6月 | 民主化デモの参加者が聖堂に避難し、金寿煥（キム・スファン）枢機卿が警察の突入を阻む |

韓国観光公社はここを**朝鮮半島で初めて建てられた大規模なゴシック様式のカトリック聖堂**であり、韓国最初の小教区教会だと紹介し、地下聖堂に殉教者の遺骨が安置されていると書いています。いまもソウル大司教区の司教座聖堂としてミサが行われる場所なので、中では静かにするのがマナーです。見学ルートやミサの時間は[明洞の見どころ](/ja/posts/myeongdong-things-to-do-2026-09/)にまとめました。

### 旧国立劇場、明洞芸術劇場

明洞キルの途中、角が丸い古い建物が**明洞芸術劇場**です。韓国語版ウィキペディアと京郷新聞（2023年11月）を合わせると、この建物は明洞の100年をそのまま生きてきました。

| 時期 | 名前と用途 |
| --- | --- |
| **1936年** | **明治座**。日本人向けの映画館 |
| 1957年6月1日 | 明洞芸術会館として国立劇場の役割 |
| 1962年 | 明洞国立劇場 |
| 1973年 | 国立劇場が南山（奨忠洞）に移り閉館 |
| 1975年 | 金融会社に売られ事務所に |
| 2003年12月 | 政府が買い戻す |
| **2009年** | **明洞芸術劇場として再開館**（558席、国立劇団が運営） |

![夕暮れにライトアップされた明洞芸術劇場。丸い角の建物に装飾柱と楕円形の窓が並び、入口の上に「명동예술극장 MYEONGDONG THEATER」の文字が光る。左の壁には演劇の垂れ幕](/images/myeongdong-guide-2026-09/20.webp)

百科事典は、戦後の明洞には国立劇場と聖堂があり、文人や芸術家が喫茶店（タバン）に集まって音楽・美術・文学・演劇を語り合う**文化の街**だったと書いています。1973年に国立劇場が去ったのは、その時代が終わった合図でもありました。劇場は30年近く事務所として使われ、2009年にふたたび劇場に戻ったことになります。

## 証券街からショッピング街へ、そして韓国一高い土地

韓国語版ウィキペディアは、明洞が**1970年代以前は証券会社が集まる経済の中心地**だったと記し、百科事典は1970年代までソウルを代表する商業地だったものの、江南（カンナム）の開発と金融機関の汝矣島（ヨイド）移転で相対的に地盤を下げたと説明します。その空白を埋めたのが衣料品とコスメの店、そして外国人観光客でした。

地価はその流れを数字で示しています。国土交通部が2025年12月に発表した**2026年の標準地公示地価**の上位を、イートゥデイの記事から整理します。

| 順位 | 土地 | 1㎡あたり公示地価（2026年） |
| --- | --- | --- |
| **1** | ネイチャーリパブリック明洞ワールド店（忠武路1街、169.3㎡） | **1億8,840万ウォン** |
| 2 | ウリィ銀行の敷地（392.4㎡） | 1億8,760万ウォン |
| 3 | 旧ユニクロの敷地（300.1㎡） | 1億7,180万ウォン |

ネイチャーリパブリックの敷地は**23年連続で全国1位**で、2025年（1億8,050万ウォン）より4.4%上がりました。上位1〜8位がすべて明洞一帯です。証券街は去っても、地価の地図では明洞がいまも頂点にいます。

## 観光特区：2000年指定、2012年に拡大

韓国には、買い物や観光の規制をゆるめる「観光特区」という制度があります。明洞は早い時期に指定された町です。韓国日報は1999年3月、ソウル市が南大門市場・北倉・小公・明洞を観光特区にしようとしていると報じ、中区によると**2000年3月30日、文化観光部告示第2000-2号**で指定されました。

| | 内容 |
| --- | --- |
| 正式名称 | 明洞・南大門・北倉洞・茶洞・武橋洞観光特区 |
| 最初の指定 | **2000年3月30日**（明洞・南大門・北倉） |
| 拡大 | **2012年12月27日**、ソウル市告示第2012-363号で茶洞・武橋洞・清渓川の一部を追加 |
| 追加面積 | 239,295.2㎡（ソウル新聞、2012年12月） |
| 現在の面積 | **872,809.2㎡**（中区） |
| 境界 | 世宗ホテル横の三一大路 → 退渓路 → 新世界百貨店 → 南大門市場 → プラザホテル → 市庁前 → 清渓広場 → 広通橋 → 長橋ビル → 世宗ホテル |

2つの数字を引き算すると、2000年に最初に指定された広さは約63万㎡です。2012年の拡大でソウル広場や清渓広場、武橋洞のナクチ（テナガダコ）横丁まで特区に入りました。だから市庁前のソウル広場も、公式には「明洞観光特区」です。

特区の中でも開発の方向は変わり続けています。ニュースピム（2026年6月）によると、ソウル市は2026年6月、**北倉洞93,187㎡の地区単位計画**を変更して高さと容積率の規制をゆるめ、観光宿泊施設にはさらに上乗せして最大容積率1,560%まで可能にしました。記事は北倉洞の建物の88%が築40年を超えていると伝えています。明洞の西のブロックに、これからホテルが増える可能性があるということです。

## 屋台：名札、値札、カード端末

明洞の夜をつくっているのは、通りの真ん中に並ぶ屋台です。そしてこの10年、明洞の行政のかなりの部分がこの屋台をめぐる仕事でした。

### 2016年、屋台の実名制

中区は**2016年6月27日**から、明洞で**屋台実名制**を始めました。ソウル新聞（2016年6月）の内容をまとめます。

- 対象は**366人**。道路占用許可を受け、年に約130万ウォンの占用料を払います
- **1人1屋台、本人が直接営業**。譲渡・賃貸・委託は禁止で、違反すれば許可取り消し
- 営業区域は明洞キル、中央路、忠武路キルなど5か所
- 3交代制から**2交代制（隔日制）** に変更
- 営業開始：**平日は夏16時・冬15時、週末・祝日は14時**

狙いは、1人が何台もの屋台車を回す**企業型の屋台**をなくすことでした。イーデイリーは「屋台天国・明洞」という見出しでこのニュースを伝えています。

### 2023年、ぼったくり騒動

コロナ後に観光客が戻ってきた2023年夏、値段が問題になりました。ニューシス（2023年7月）は、明洞の一部で**たい焼き（プンオパン）4個5,000ウォン、イカ焼き1杯1万2,000ウォン**ほどで売られ、ぼったくりだと批判されたと伝え、ソウル新聞は「揚げ餃子3個5千ウォン」を見出しにしました。中区は明洞観光特区協議会と会い、管理の強化と価格表示制を進めると表明しました。

その後の措置は段階的でした。

| 時期 | 措置 | 出典 |
| --- | --- | --- |
| **2023年10月1日** | 明洞一帯0.42㎢を**価格表示義務地域**に。地下街を含む1,011店舗、違反すると過料最大1,000万ウォン。**ただし屋台は対象外** | イーデイリー 2023年8月 |
| 2024年2〜3月 | 屋台に**カード端末**を普及。たい焼き・おでん・イカ焼きなど人気10品目の価格を毎月共有し、値上げは区と事前協議。衛生帽・マスク・手袋を統一 | イーデイリー 2024年2月 |
| 2024年12月1日 | 明洞の価格表示義務地域を**拡大告示**（中区告示2024-77） | 政府24 |
| **2025年6月18日〜7月17日** | 明洞の屋台を**特別整備**：行政処分45件、現場での指導136件。許可者以外の営業、隔日制違反、許可証の未掲示、不法転貸など | 国際ニュース、マネートゥデイ 2025年8月 |

マネートゥデイによると、2025年の整備では**すでに亡くなった人の名義で営業していた屋台**まで見つかり、その場で許可が取り消されたそうです。実名制から9年たっても「名札」を守らせるのは簡単ではない、ということです。国際ニュースは、中区が2024年に**全国で初めて屋台にカード端末を導入し、価格表示制を始めた**とまとめています。

旅行者向けに言い換えるとこうです。屋台車には**許可証と値段が貼ってあるはず**で、カードが使える屋台も増えました。値段が見えなければ先に聞きましょう。何をいくらで売っているかは[明洞グルメ](/ja/posts/myeongdong-food-2026-09/)にまとめています。

## 光の街：明洞スクエア

![曇りの昼の明洞キル。街灯ごとに縦長のLED広告が立ち、右には大きな正方形の画面が映っている。両側にコスメとファッションの店が続き、人々が歩いている](/images/myeongdong-guide-2026-09/11.webp)

いま明洞キルを歩くと、街灯ごとに縦長の電光掲示板が付いています。これは**屋外広告物自由表示区域**の事業です。中区の報道資料によると、明洞は**2023年12月28日、行政安全部の第2期自由表示区域**に選ばれ、2024年から**2033年までの10年間、3段階**で広告物を設置します。第1段階（2025年まで）は**ハナ銀行、ロッテヤングプラザ、明洞芸術劇場、新世界百貨店**の4拠点と明洞キル周辺が先でした。金吉成（キム・ギルソン）中区長は明洞を「ニューヨークのタイムズスクエアのような世界的な観光名所」にすると語っています。中区はこの区域を「明洞スクエア」と呼んでいます。

電光掲示板はイベントの舞台にもなります。中区は**2024年12月31日の夜、新世界百貨店本店前**でカウントダウンイベントを開くと発表しました。報道資料によると、事前予約の観客**1,500人**、明洞各所の電光掲示板**18面**で同時中継、そして人が集中しうる**33か所を密集懸念地域に指定**して管理する計画でした。冬のメディアファサードや年末イベントの日程は毎年変わるので、[明洞の見どころ](/ja/posts/myeongdong-things-to-do-2026-09/)で確認してください。

## 南山ゴンドラ：着工から二審まで

明洞駅から南山の頂上まで5分。それがソウル市の掲げた**南山ゴンドラ**の約束でした。2026年10月現在、ゴンドラは動いていません。日付順に並べると理由が見えます。

| 時期 | できごと | 出典 |
| --- | --- | --- |
| **2024年9月5日** | 下部駅予定地の**芸場公園**で着工式。明洞駅から約200m、頂上まで**832m**、キャビン**25台（10人乗り）**、1時間最大1,600人。「2026年春運行」が目標 | アジア経済、韓国日報 |
| 2024年10月 | 南山ケーブルカー運営会社の**韓国索道工業**による執行停止の申し立てを裁判所が認め、工事中断（工程率約15%） | 韓国日報 |
| **2025年12月19日** | 一審（ソウル行政裁判所）でソウル市敗訴。支柱を立てるため都市自然公園区域を変更した決定が、解除の要件を満たしていないという判断 | 国民日報 |
| **2026年9月17日** | 二審（ソウル高裁）でもソウル市敗訴。市は上告を検討 | 韓国日報、ファイナンシャルニュース |

争点は高さです。韓国日報によると中間支柱は約35mですが、都市自然公園区域では12mが上限のため、ソウル市が区域を変更し、裁判所はそれを違法と判断しました。ソウル市は、アクセスをよくし既存ケーブルカーの**64年に及ぶ独占**を解くことを大義に掲げていました（国民日報）。ビズ韓国（2026年9月）は、事業にすでに100億ウォン以上がかかり、止まった現場を維持するだけで年1億7,000万ウォンかかっていると伝えています。

旅行者にとって大事なのはひとつです。**南山に上るなら、いまは既存のケーブルカー、バス、徒歩のどれか**。古い旅行情報や2024年の記事で「2026年春ゴンドラ開業」を見たなら、それは過去の計画です。南山への上り方は[明洞の見どころ](/ja/posts/myeongdong-things-to-do-2026-09/)にまとめました。

## 南大門市場：道を1本渡って

![晴れた日の南大門市場。服やおみやげを吊るした店の日よけが両側に続き、商店街ビルや高麗人参・メガネ店の看板の下を人々が歩く。手前で2人がホットクを食べている](/images/myeongdong-guide-2026-09/31.webp)

明洞の西、新世界百貨店本店を過ぎると**南大門市場**です。中区は「600年の歴史」をもつ在来市場と紹介し、韓国観光公社によると崇礼門（南大門）側から広がる**店舗1万軒あまり**が**1,700種ほど**の商品を売り、1日平均**30万人**が訪れます。卸と小売を兼ねる市場なので、営業時間は店ごとに違います。明洞が新しいものを売る街なら、南大門市場はメガネ、食器、子ども服、高麗人参のような「暮らしの品」が集まる所です。カルグクス（韓国式うどん）横丁やタチウオ煮込み横丁は[明洞グルメ](/ja/posts/myeongdong-food-2026-09/)、市場の歩き方は[明洞の見どころ](/ja/posts/myeongdong-things-to-do-2026-09/)にあります。

## 私が間違っていたこと

この記事の最初の版（2026年9月10日）には、間違いや根拠の弱い内容がありました。訂正します。

**1つ目、「空港鉄道でソウル駅まで来て4号線で1駅」と書きました**。ソウル駅から[[line:4]] に乗ると1駅目は**会賢**（南大門市場）で、**明洞駅は2駅目**です。

**2つ目、「屋台はだいたい16時から」と書きました**。2016年の実名制のルールでは**平日は夏16時・冬15時、週末・祝日は14時**で、季節と曜日によって違います。

**3つ目、「屋台は市場の2倍くらいの値段」と書きました**。この比較を裏づける公式資料がないため削除しました。代わりに2023年のぼったくり騒動と、その後の価格表示・カード端末の措置を書いています。

**4つ目、明洞を「明洞キルの通り」程度にしか説明していませんでした**。観光特区としての明洞は、2012年から茶洞・武橋洞、ソウル広場、清渓広場まで含む87万㎡の広さです。

**5つ目、宿を「6万ウォンのビジネスルームから50万ウォンのスイートまで」「広さと静けさなら南大門路側」とまとめていました**。どちらも根拠となる資料がないため削除しました。宿の数と客室数は、許認可データで数えた[明洞の宿](/ja/posts/myeongdong-hotels-2026-09/)をご覧ください。

### 夕方の明洞入口バス停

明洞は観光地であると同時に、首都圏南部へ向かう**広域バス**の停留所でもあります。ソウル新聞（2024年1月）によると、ロッテ百貨店前の明洞入口停留所には広域バス**29路線**が停まり、2023年12月28日に並び位置の表示板を立てたところバスが数珠つなぎになる渋滞が起き、2024年1月6日に呉世勲（オ・セフン）市長が現場で謝罪しました。ソウル市は2024年2月24日から**広橋停留所と明洞入口B停留所**を新設して路線を分けています（デイリーアン）。記事によれば長さ35mほどの停留所が待つ人でいっぱいになったそうです。退勤時間にスーツケースを引いてロッテ百貨店前を通るなら、1本内側の道に回るほうが楽です。

## こう回るのがおすすめ

同じ通りでも、時間によって顔が変わります。

1. **午前**：明洞聖堂と南山側を先に。屋台が出る前なので明洞キルも比較的すいています。
2. **昼ごろ**：南大門市場か明洞の路地の食堂へ。[明洞グルメ](/ja/posts/myeongdong-food-2026-09/)を参考に。
3. **午後**：明洞キルで買い物。免税の還付と両替は[明洞の見どころ](/ja/posts/myeongdong-things-to-do-2026-09/)に、オリーブヤングは[オリーブヤング買い物ガイド](/ja/posts/olive-young-shopping-2026-09/)にあります。
4. **夕方〜夜**：屋台が出る時間。週末は14時、平日は15〜16時からです。明洞芸術劇場で公演があれば夜の部へ。
5. **夜**：南山ケーブルカーで夜景を見るか、電光掲示板の通りをもう一度歩く。

道に迷ったり通訳が必要なときは、乙支路66の**明洞観光情報センター**（9:00〜18:00、旧正月・秋夕の当日休み）や**1330観光通訳案内電話**で、韓国語・英語・日本語・中国語で相談できます（韓国観光公社）。

## どこに泊まるか

地下鉄2路線と空港バス、そして歩いて行ける南山・南大門市場・光化門のおかげで、明洞はソウルが初めての旅行者がいちばん多く泊まる町です。ソウル市の許認可データで数えた[明洞の宿](/ja/posts/myeongdong-hotels-2026-09/)の集計では、この一帯に**観光宿泊業69軒・6,399室**（観光ホテル29軒、ホステル40軒）と外国人観光都市民泊150軒があり、都市民泊はすべて南山洞・会賢洞にあります。ロッテホテルソウルやウェスティン朝鮮のような大型ホテルは、実際には小公洞の住所です。名前に「明洞」が付いていても住所が小公洞・北倉洞のホテルは[光化門・市庁・鐘閣の宿](/ja/posts/gwanghwamun-hotels-2026-09/)に、ソウル全体の比較は[ソウルどこに泊まる？](/ja/posts/seoul-where-to-stay-2026-09/)にあります。2026年6月の北倉洞の計画のように**観光宿泊施設に容積率の優遇**を与える方向なので、ホテルの地図はまだ変わっていきそうです。

## こんな人に向いています

**向いている人**

- ソウル旅行が初めてで、空港アクセス、地下鉄、買い物、南山をひとつの町で済ませたい人
- コスメやファッションの買い物、夜の屋台グルメが旅の中心の人
- 聖堂や旧国立劇場のような100年級の建物を、買い物の動線の中で見たい人

**向いていない人**

- 静かな路地と地元の店が目当てなら[益善洞まとめ](/ja/posts/ikseon-guide-2026-09/)や[鍾路まとめ](/ja/posts/jongno-guide-2026-09/)のほうが合います
- 夜遅くまで遊ぶのが目的なら[弘大まとめ](/ja/posts/hongdae-guide-2026-09/)がおすすめです
- 人混みが苦手なら、週末の夜の明洞キルは避けましょう

## まとめ

- **明洞**：行政洞0.99㎢に住民2,494人。外国人は1日平均**10万910人**が通り、流動人口の47.1%が外国人です（2025年）。
- **名前**：朝鮮の明礼坊 → 日本統治期の明治町 → **1946年に明洞**。南の本町は忠武路になりました。
- **2つの目印**：**明洞聖堂**（1898年献堂、1977年史跡）と**明洞芸術劇場**（1936年の明治座、1957〜1973年国立劇場、2009年再開館）。
- **観光特区**：2000年3月30日指定、2012年に茶洞・武橋洞まで広げて872,809.2㎡。
- **屋台**：2016年実名制（366人）→ 2023年ぼったくり騒動と価格表示義務地域 → 2024年カード端末 → 2025年特別整備で行政処分45件。
- **南山ゴンドラ**：2024年着工、工程率約15%で停止。**2026年9月17日、二審でもソウル市敗訴**。いま南山へはケーブルカー・バス・徒歩で。

ひと言でまとめるとこうです。**明洞は住む人より通る人が40倍多い1平方キロメートルで、その人たちを相手にした路上の商売をどう正直にするかが、この10年の宿題**でした。
