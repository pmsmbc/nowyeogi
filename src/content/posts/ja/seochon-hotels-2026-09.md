西村の宿は、二つの数字で説明がつきます。そして、その二つが正反対です。

- **西村一帯の登録された宿泊業は2か所、39室。** どちらも旅館で、**ホテルは一軒もありません**
- **ソウルの韓屋の宿133か所のうち、33か所が西村。** ソウルで韓屋の宿がもっとも密集している町です

同じ町なのになぜこうも違うのか、そこから説明します。

![世宗村の案内板。村の古い名前と由来が韓国語と英語で書かれている](/images/seochon-guide-2026-09/02.webp)

## ホテルが0軒です

ソウル市の許認可データで、西村一帯を数えてみました。**ソウル韓屋ポータルは西村を14の法定洞と定義**していますが、この集計はそのうち住所で特定できる**13の洞**を対象にしたものです。

| 業態 | 事業所 | 客室 |
| --- | --- | --- |
| **旅館業** | **2か所** | **39室** |
| 観光ホテル | 0 | 0 |
| 一般ホテル | 0 | 0 |
| 宿泊業（生活） | 0 | 0 |
| 旅人宿業 | 0 | 0 |

**旅館が二軒、それだけ**です。一軒は1985年、もう一軒は1999年の許認可です。

観光宿泊業も別に確認しましたが、**同じ13の洞に所在するものは0か所**です。いちばん近いのが唐珠洞と新門路1街、つまり光化門の側です。

聖水洞の記事でも「ホテルが0か所」と書きましたが、あちらはそれでも旅館が21か所299室ありました。**西村はそれよりずっと少ないです。**

理由は[まとめの記事](/ja/posts/seochon-guide-2026-09/)に書きました。**1977年から2024年まで47年間、高さが15〜20mに凍結されていました。** ホテルを建てようがなかったのです。

## ところが、韓屋の宿はソウルで一番多いです

ソウル観光財団のソウルステイの基準で、ソウルの韓屋の宿は**133か所**です。そのうち**33か所が西村**です。

| 地域 | 韓屋の宿 |
| --- | --- |
| **西村** | **33か所** |
| 安国駅から500m以内 | 21か所 |
| 鍾路3街駅から500m以内 | 6か所 |
| 中区（乙支路・明洞） | **0か所** |
| 城東区（聖水洞） | **0か所** |

**ソウルの韓屋の宿の4分の1が、西村にあります。**

### 二つの数字がなぜ重ならないのか

大事な但し書きです。**上の宿泊業2か所に、韓屋の宿33か所は含まれていません。**

根拠となる法律が違います。

- **旅館・ホテル** — 「公衆衛生管理法」上の**届出**の業種
- **韓屋の宿** — 「観光振興法」上の**登録**の業種（韓屋体験業）で、ホテル業ではなく**観光客利用施設業**

ですから**二つの数字を足してはいけません。** 益善洞の記事でも同じ話を書きましたが、西村ではその違いがいちばん極端に出ます。**一般の宿泊業の統計だけを見れば「泊まるところがほとんどない町」なのに、実際にはソウルで韓屋に泊まるのにもっとも適した町**なのです。

## 韓屋の宿とは実際にどういうものか

益善洞の記事に詳しく書きましたが、要点だけもう一度移しておきます。**法が求めるものと求めないもの**が、思っているのと違います。

### 法が求めていないもの

**専用の浴室は義務ではありません。** 条文が「浴室やシャワー設備などの便宜施設を備えること」までしか求めていないので、**共用トイレでも合法**です。

**床で寝なければならないという規定もありません。** ベッド・オンドル・布団に関する条文が、そもそもありません。**ベッドのある韓屋の宿もあります。**

### 法が求めているもの

- **消火器1個以上**、客室ごとに**単独警報型の感知器**
- 個別暖房なら**一酸化炭素の警報器**まで
- 宿泊空間の**延べ面積230㎡未満**
- **営業時間中の管理者の配置**
- **料金表の掲示と遵守**

**西村の韓屋はほとんどが個別暖房なので、事実上、一酸化炭素の警報器があるはずです。** チェックインのときに一度ご覧になってみてください。

**24時間フロントはありません。** 営業時間のあいだだけ管理者がいます。遅い時間に到着されるのなら、前もって連絡しておかれる必要があります。

## 西村に泊まるほうがよいか

**有利な点です。**

- **ソウルで韓屋の宿がもっとも多いです。** 選択肢が33か所あります
- **景福宮まで歩いて行けます。** 塀ひとつ隔てただけです
- **空港バスが景福宮駅に停まります**（下記）
- **フランチャイズがないので静かです。** 夜に居酒屋の騒音が少ないです

**不利な点です。**

- **ホテルがありません。** フロントと朝食、24時間チェックインをお望みなら、光化門の側に出る必要があります
- **韓屋は防音が弱いです。** 木造に障子紙です
- **坂があります。** 仁王山のほうへ行くほど傾斜がきつくなります
- **夜に開いている店が少ないです。** 遅く着くと、食べるところが見つかりにくいです

## 空港バスが停まります

空港リムジンの [[bus:6011]] が、**景福宮駅に停まります。**

- 乗り場 — **1番出口、ソウル警察庁の向かい**
- **始発04:31、終バス20:48**
- 大人17,000ウォン

**景福宮駅に停まる路線は6011番の一つだけ**です。同じ路線が**昌徳宮と安国駅**にも停まるので、北村の側の韓屋の宿にも使えます。

終バスが**20時48分**なので、乙支路（19:50）より遅く、鍾路3街（20:45）とほぼ同じです。

鉄道なら、[[line:arex]] でソウル駅まで来て [[line:3]] に乗り換えると景福宮駅です。ソウル駅から二駅です。

## どこに取るか

- **韓屋に泊まりたい** — 西村がソウルでいちばん選択肢が多いです
- **ホテルが必要だ** — 光化門か安国の側に出てください。西村にはありません
- **静かに眠りたい** — フランチャイズも居酒屋も少ないので、夜が静かです
- **荷物が多い、あるいは遅く着く** — 韓屋には24時間フロントがないので、前もって連絡してください

## 確認できなかったこと

**西村の宿の料金は、公式資料がありません。** ですから金額を書きませんでした。

**韓屋体験業の全数データを確保できませんでした。** ソウルステイの一覧で代えましたが、それはソウル市が広報しているところなので、登録業者すべてではない可能性があります。

**旅館二軒の現在の営業の形**も、許認可の記録を確認しただけで、実際の運営状態は見ていません。

## まとめ

- **西村の登録された宿泊業は旅館2か所39室**で、**ホテルは0軒**です。
- **ところが、ソウルの韓屋の宿133か所のうち33か所が西村**です。ソウルでもっとも密集している町です。
- **二つの数字は根拠となる法律が違うので、足してはいけません。**
- **専用の浴室も、床での就寝も、法的な義務ではありません。** ベッドのある韓屋もあります。
- **消火器と単独警報型の感知器は義務**、個別暖房ならCO警報器まで必要です。
- **空港バスは6011番**、景福宮駅1番出口の向かいで、終バスは20:48です。
- **ホテルが必要なら光化門へ**出てください。
