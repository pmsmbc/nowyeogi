梨泰院と漢南洞を再び訪れる人に必要なのは、新しいグルメより**新しく開いた場所**かもしれません。旧米軍基地の土地は予約なしで入れるようになり、南山のふもとの植物園は今年6月に新しい名前で開園しました。

[梨泰院の見どころ](/ja/posts/itaewon-things-to-do-2026-09/)では戦争記念館・リウム美術館・ソウル中央聖院を短く紹介しました。この記事ではその3か所を繰り返さず、**リウムは秋の展示と予約ルールだけ**、聖院は**訪問マナーだけ**を補ってから、別の場所へ進みます。エリア全体の概要は[梨泰院・漢南洞まとめ](/ja/posts/hannam-guide-2026-09/)にあります。時間と料金はすべて**2026年9月の執筆時点**のものです。

国立中央博物館も近いですが、[国立中央博物館ガイド](/ja/posts/seoul-national-museum-of-korea-2026-09/)で別にまとめています。

## 龍山公園 — 予約なしで入れる旧基地の2か所

龍山米軍基地の返還用地のうち、いま市民に開かれているのは**2か所**です。龍山公園公式サイトの「臨時開放」メニューにある**龍山子ども庭園**と**将校宿舎5団地**です。どちらも無料で、どちらも月曜日に休みます。

### 龍山子ども庭園 — 2025年12月30日から予約廃止

韓国政府の政策ブリーフィングによると、**2025年12月30日から事前予約制と身元確認・保安検査がなくなりました**。開園時間内なら手続きなしで入れます。

| | 開園 | 入場締切 |
| --- | --- | --- |
| 火〜金、日 | 09:00〜18:00 | 17:00 |
| 土 | 09:00〜**21:00** | 20:00 |
| 休み | **月曜**、1月1日、旧正月・秋夕当日 | |

入場締切は韓国観光公社の案内によるもので、屋内施設は平日17:30、土曜20:30に先に閉まります。**月曜が祝日の場合は翌日が休み**です。

- 住所：**漢江大路38ギル 29**（龍山公園公式サイト）
- [[line:4]] 新龍山駅1番出口から徒歩5分、龍山駅1番出口から10分
- **駐車不可**。公共交通機関の利用が公式の案内です。
- 電動キックボード・ペットは持ち込み禁止、手押しのベビーカーは可（ソウル市の媒体）
- 案内センターでベビーカー・車いすの貸し出し。園内シャトルは平日毎正時、週末は1時間に3本

ソウル市の媒体と観光公社は、図書館**龍山書架**、展示空間、展望の丘、カフェなどを紹介しています。庭園公式サイトのトップには、秋のバスキング（9/18〜10/31）、紅葉の散策（10/2〜11/29）、メディアアート（9/1〜11/29）などのプログラムが掲載されています。詳しい時間は公式サイトで確認してください。

政府は、特定の年齢に限らない名前へ**2026年上半期中に変更する**と発表しましたが、9月現在、公式サイトは今も「龍山子ども庭園」を使っています。

### 将校宿舎5団地 — 赤レンガの住宅団地

![澄んだ秋空の下、赤い瓦屋根の2階建てレンガ住宅の前の芝生に白い大きな文字のYongsan Parkのオブジェが立ち、奥にマンションが見える](/images/hannam-things-to-do-2026-09/05.webp)

基地の南東にあった旧米軍将校宿舎で、**2020年8月**に先に開放された場所です。龍山公園公式サイトによると、朝鮮時代の氷の貯蔵庫**西氷庫**（ソビンゴ）があった場所で、解放後に米軍はこの一帯を「キャンプ・ソビンゴ」と呼びました。韓国政府が**1986年**に約49,368㎡を取り戻し、将校宿舎を建てました。

- 住所：**西氷庫路 221**
- **火〜日 09:00〜18:00**、入場締切**17:30**（龍山公園公式サイト）
- 休館：月曜（祝日なら翌日）、1月1日、旧正月・秋夕当日
- **無料**、同時入場は**最大500人**なので、混雑時は待つことがあります。
- 18棟のうち**10棟**を子ども図書館・遊び場・休憩所・展示館に改装
- **一般車両は駐車不可**。障害者の車両と、13歳未満の子ども2人以上を乗せた車両のみ無料で駐車可

漢南洞からは距離があるので、別に半日をとるほうが現実的です。

## リウム美術館 — 秋の展示と予約ルール

基本情報は[梨泰院の見どころ](/ja/posts/itaewon-things-to-do-2026-09/)にあるので、ここでは**9〜10月に見られる展示**と**予約ルール**だけをまとめます。

| 展示 | 場所 | 会期 | 観覧料 |
| --- | --- | --- | --- |
| ク・ジョンア：ウスモス | M2 | 2026-09-05〜12-27 | 有料（一般**18,000ウォン**、デイリーアート報道） |
| 他の空間の中へ：女性作家たちの共感覚的環境 1956-1976 | ブラックボックス、グラウンドギャラリー | 2026-05-05〜11-29 | 有料 |
| アイデア・ミュージアム、明日以降 | グランドホール・ラウンジ | 2026-09-05〜11-29 | 公式サイトに記載なし |
| ガブリエル・オロスコ庭園 | 屋外 | 2026-04-03〜 | **無料** |
| 古美術常設展 | | 常設 | **無料** |

デイリーアートによると、ク・ジョンア個展は1990年代初期の作品からリウムの委嘱新作まで**約35点**を集めています。

リウムの訪問案内ページのルールは次のとおりです。

- **観覧日の14日前からオンライン予約**、1件あたり**最大4人**
- 当日券もありますが、混雑期は**待ち時間が長く**なります。
- 予約時間の**20分前から**次の回の前まで入場可
- チケット販売は**17:30まで**
- リュックサイズのかばんは展示室に持ち込めないので**ロッカー**に預けます。
- **フラッシュ撮影禁止**、三脚・自撮り棒は制限、一部の特別展は撮影そのものが不可
- 駐車は18時まで限られた台数のみなので、公共交通機関がおすすめです。[[line:6]] 漢江鎮駅1番出口から梨泰院方面へ100m、最初の路地を右に入って坂道を約5分。

## 現代カード ミュージックライブラリー — まず入場条件を確認

梨泰院路でよく名前が挙がる場所のひとつですが、**誰でも2階に上がれるわけではありません**。

| | 営業時間 |
| --- | --- |
| 火〜土 | 12:00〜21:00 |
| 日・祝日 | 12:00〜18:00 |
| 休館 | 旧正月・秋夕連休（月曜は営業時間に含まれていません） |

現代カードDIVEの空間案内によると、次のとおりです。

- **1階カフェ：誰でも**利用可
- **2階ライブラリー：現代カード会員＋同伴2人**、またはDIVEアプリ会員本人のみ
- 入場は**月8回**まで、**19歳以上**、カード（またはアプリ）と身分証を確認
- レコード**約1万枚**と海外の希少盤をターンテーブルで試聴
- 同時入場は**最大30人**、超えると順番待ち
- 駐車・バレーなし、ペット・外部の飲食物・プロ用カメラは持ち込み不可、建物全体が禁煙

海外からの旅行者がライブラリーに入れるかどうかは、公式案内だけでははっきりしません。カフェだけ寄るつもりでいるほうが安心です。住所は**梨泰院路 246**。

## ソウル中央聖院 — 訪問前に知っておきたいマナー

聖院の紹介は[梨泰院の見どころ](/ja/posts/itaewon-things-to-do-2026-09/)にあります。ここでは**韓国イスラム教中央会と公的な観光案内が示すマナー**だけを集めます。

- **1976年5月21日**に建てられた韓国初のイスラム聖院（VISIT SEOUL）
- 韓国イスラム教中央会は聖院を**開かれた空間**と紹介していますが、礼拝の場なので服装を守る必要があります。
- **袖なし、短いスカート、短パン**など露出の多い服は不可。その場合は**警備室横の着衣室**にあるスカートやヒジャブなどを着て見学します。
- **礼拝中の人を撮影せず**、礼拝を妨げないこと
- 聖院内は**禁煙**
- 礼拝時間は日の出の時刻によって変わるとVISIT SEOULは案内しています。
- 観光公社の案内では**エレベーター・多目的トイレ・駐車場はありません**。坂道なので、車いすやベビーカーでは大変です。

[[line:6]] 梨泰院駅3番出口から約477m、住所は**ウサダン路10ギル 39**、問い合わせは02-793-6908です。

## 解放村 — 新興市場と108階段

![桜が咲く解放村の坂道。右の建物に新興市場・解放村方面の案内板があり、木々の向こうにNソウルタワーが見える](/images/hannam-things-to-do-2026-09/09.webp)

南山のすぐ下にある坂の町です。**1945年の解放**後、北から来た避難民や朝鮮戦争の避難民が集まって暮らしたことから、この名前がつきました。

### 新興市場 — 空が見える屋根

ソウル市の媒体に載った都市建築家のコラムによると、次のとおりです。

- **1953年**から住民の生活必需品市場、1990年代以降に衰退
- 都市再生と商人たちの努力で、古い店と新しい店が混ざる今の姿に
- 一直線ではない**ㅂ字形の回遊動線**
- **2018年**に完成した透明なETFE膜の屋根（名前は**ソウルチェン**）が、路地の奥まで日の光を入れる

店ごとに営業時間が違うため、この記事には書いていません。食べ物は[梨泰院・漢南洞のグルメ](/ja/posts/hannam-food-2026-09/)で扱います。

### 解放村108階段

ソウル未来遺産のサイトによると、**1943年**、日本統治時代に京城護国神社への入口として造られた階段です。もとは広い石段ひとつで、いまは真ん中に花壇をはさんで分かれています。

- **2015年にソウル未来遺産**に指定
- 2017〜2018年に**斜行エレベーター**を設置、下から上まで**約1分**
- 周辺には1960〜70年代のニット工場が残っています。

エレベーターの運行時間は公式資料で確認できませんでした。

## 南山 韓国森庭園 — 6月に生まれ変わった旧・野外植物園

![スイレンとアヤメが茂る池に赤い木の橋が架かり、松と広葉樹に囲まれた南山野外植物園](/images/hannam-things-to-do-2026-09/01.webp)

梨泰院洞の南山のふもとにある**南山野外植物園**が、**2026年6月27日**、「韓国森庭園」という新しい名前で開園しました。上の写真は観光公社に「南山野外植物園」として登録されたものなので、リニューアル前の姿かもしれません。

- 住所：**梨泰院洞 259-16**、約**3万㎡**
- 旧野外植物園は「南山本来の姿を取り戻す」事業で**1997年**に開園（ソウル市の媒体）
- 韓国を代表する森と庭園を再現した**3テーマ11庭園**

| テーマ | 庭園 |
| --- | --- |
| 伝統と文化 | 池塘苑（チダンウォン）、霊芝苑（ヨンジウォン）、ムクゲ苑 |
| 自然と生態 | ツツジの丘、梅苑、苔苑、竹林苑、松林苑 |
| 休養と休息 | 松林広場、イチョウの庭、南山マル |

ソウル市の媒体は、潭陽（タミャン）の竹林や済州の伝統林のような地方の森の風景を取り入れたと紹介しています。池を過ぎて「寿福泉薬水場」方面へ進むと**松林探訪路**につながり、予約なしで歩けます。

行き方は、[[line:6]] 漢江鎮駅2番出口から [[bus:405]] に乗り、**南山芸術院**停留所（またはハイアットホテル）で降りる方法がソウル市の案内です。問い合わせは南山公園管理事務所 **02-3783-5900**。

**開園時間と休みは、開園の告知では見つけられませんでした**。
