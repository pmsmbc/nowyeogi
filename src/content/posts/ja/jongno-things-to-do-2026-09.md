ソウルの五大王宮のうち四つ、ユネスコ世界遺産の宗廟、そして韓国で最もよく残る韓屋の街並み。そのすべてが鍾路の、互いに徒歩20分以内の範囲にあります。以下の料金と時間は国家遺産庁の案内による2026年9月時点のものです。

## チケット：統合観覧券を買う

| 場所 | 大人 |
|---|---|
| 景福宮 | 3,000ウォン |
| 昌徳宮（王宮） | 3,000ウォン |
| 昌徳宮 後苑 | 追加5,000ウォン |
| 昌慶宮 | 1,000ウォン |
| 徳寿宮 | 1,000ウォン |
| 宗廟 | 1,000ウォン |
| **統合観覧券** | **6,000ウォン、有効期間6か月** |

**統合観覧券**は四つの王宮と宗廟に入れますが、後苑は**含まれません**。三か所回れば元が取れます。

**韓服を着ていれば王宮の入場は無料**で、これは外国から来た方にも適用されます。対象になるには、前を合わせる正しいチョゴリと、スカートまたはパジが必要です。レンタル店は景福宮と安国駅の周辺に集まっていて、4時間でおよそ15,000〜30,000ウォン。つまり王宮を二か所回るなら入場料を払うのとほぼ同じ金額です。写真に写っている人の半分が1450年ごろの装いをしているのは、そういう理由です。

## 景福宮

![景福宮の正殿と、その前に広がる広場](/images/jongno-things-to-do-2026-09/01.webp)

王宮のなかで最も大きく、見応えがあります。1395年の創建の地に再建されたもので、背後には北岳山が立っています。

**開場時間**は季節で変わります。1月・2月・11月・12月は9:00〜17:00、3〜5月と9〜10月は9:00〜18:00、6〜8月は9:00〜18:30。最終入場は閉場の1時間前です。そして**火曜は休み**です。

敷地の中には**国立古宮博物館**と**国立民俗博物館**があり、どちらも無料で、雨の日の避難先としてもよくできています。また**守門将交代**の儀式は光化門の前で1日に数回行われ、見るだけなら無料です。

行くなら9時です。最初の1時間は本当に静かで、11時にはそうではなくなります。

## 昌徳宮と後苑

![昌徳宮の後苑にある、木々を映す池](/images/jongno-things-to-do-2026-09/04.webp)

韓国の人がより好む傾向にあるのが昌徳宮です。規模は小さく、丘を削らずその形に沿って建てられていて、ユネスコ世界遺産に登録されています。

見どころは**後苑、すなわち秘密の庭**ですが、ここは**自由に歩いて回ることができません**。入れるのは**時間指定のガイドツアーだけ**で、王宮の3,000ウォンに加えて5,000ウォンの別チケットが必要です。特に秋は枠が埋まります。

日程が決まっているなら、国家遺産庁のサイトから**事前にオンラインで予約**してください。当日券も現地で先着順に少数販売されますが、早い時間になくなります。ツアーはおよそ90分で、時間帯によって韓国語・英語・中国語・日本語で行われます。

## 宗廟

![横に長く延びる宗廟の正殿](/images/jongno-things-to-do-2026-09/03.webp)

歴代の王の位牌を祀る王室の廟で、ユネスコ世界遺産であり、ソウルの主要な観光地のなかで最も静かな場所です。正殿は装飾のない一棟の建物が100メートル以上続くもので、受ける印象は王宮というより大聖堂に近いかもしれません。

料金は**1,000ウォン**、火曜休みです。ほとんどの日は自由観覧ではなく**決まった時間の解説ツアー**での入場になり、特定の日、多くは土曜に自由に歩けます。行く週に公式サイトで確認してください。

## 北村韓屋村

![山並みを背にした景福宮の建物群](/images/jongno-things-to-do-2026-09/02.webp)

景福宮と昌徳宮にはさまれた丘に、数百軒の伝統的な韓屋が並びます。そのほとんどに人が住んでいます。

**必ず知っておくべきルール**：2025年3月1日から、北村路11キル周辺の特別管理地域は、観光客の立ち入りが**10時から17時のあいだだけ**に制限されています。時間外には**10万ウォンの過怠料**が科されます。この地域内の宿の宿泊客でも、観光をしていると判断されれば対象になります。周辺の道路では2026年1月から貸切バスの通行も禁止されます。

ルール以前の礼儀としては、静かに話す、門の中に入らない、窓越しに写真を撮らない、家の前の段差に座らない。住民が何年も苦情を訴えてきた結果が、この規制です。

多くの人が目当てにするのは**北村文化センター**と、北村路11キルの展望スポットの二つです。すぐ西の三清洞には同じ建築が制限なしで残っていて、カフェはこちらのほうが充実しています。

## 仁寺洞

歩行者専用の通りが1本と、そこから伸びる路地の網。陶磁器、書道の筆、茶、韓紙、そして大量のみやげ物が売られています。なかでも**サムジキル**は螺旋状に登っていく商業施設で、10分使う価値があります。脇の路地の伝統茶房では、オミジャ茶やユジャ茶が陶器の器で出てきます。

観光地らしく値段もそれなりですが、通りの北側にある工芸店は本物ですし、画廊はどこも無料です。

## 2日間の回り方

**1日目**：9時に景福宮 → 国立民俗博物館 → 三清洞で昼食 → 10時から17時のあいだに北村 → 仁寺洞でお茶 → 夜は広蔵市場で食事。

**2日目**：予約した後苑の枠に合わせて昌徳宮 → 隣の宗廟 → 益善洞のカフェ → 夜は鍾路3街の路地で。

## 知っておくと便利なこと

- **火曜**は景福宮・昌徳宮・宗廟がそろって休みです。徳寿宮だけは月曜休みなので、火曜の代替になります。
- **後苑の予約**は、日程が動かせないなら出発前に済ませておいてください。
- **英語の無料ガイドツアー**が主要な王宮で1日数回あります。門の内側の掲示板を見てください。
- **靴は大事**です。砂利の広場と急な路地で、気づかないうちに12,000歩は歩きます。
- **トイレ**は王宮の敷地内のものが無料できれいです。

## まとめ

王宮を二つ、廟を一つ、韓屋の街をひとつ。これで2日間はしっかり満たされます。6,000ウォンの統合観覧券を買い、後苑を先に予約し、開場時間に行き、そして北村は観光地ではなく誰かの住む通りとして歩いてください。
