北村の見どころは、**時計を見ながら回る必要があります**。

いちばん有名な路地である**嘉会洞（カフェドン）31番地の一帯がレッドゾーン**で、観光客は**午前10時〜午後5時**にしか入れません。ところが昌徳宮は9時に開き、国立現代美術館は水・土曜日に夜9時まで開いています。**時間帯ごとに行くべき場所が違います**。

そこでこの記事は、場所の紹介とあわせて**曜日表と時間帯別のルート**をつけました。レッドゾーンの制度そのものは[北村まとめ](/ja/posts/bukchon-guide-2026-09/)で詳しく扱います。

## 北村八景 — 半分がレッドゾーンにあります

北村八景は、ソウル市の媒体と韓国観光公社が次のように紹介しています。

| | 名前 | レッドゾーンとの関係 |
| --- | --- | --- |
| 一景 | 昌徳宮の全景 | 外 |
| 二景 | 苑西洞（ウォンソドン）の工房の道 | 外 |
| 三景 | 嘉会洞11番地の一帯 | 外（工房の通り） |
| 四景 | 嘉会洞31番地の丘（北村展望台） | **嘉会洞31番地の一帯** |
| 五景 | 嘉会洞の路地（上り坂） | **嘉会洞31番地の一帯** |
| 六景 | 嘉会洞の路地（下り坂） | **嘉会洞31番地の一帯** |
| 七景 | 嘉会洞31番地 | **嘉会洞31番地の一帯** |
| 八景 | 三清洞の石段の道 | 外 |

鍾路区が定めた**レッドゾーンは、北村路11ギル一帯の約3万4千平方メートル**です。嘉会洞31番地の路地がまさにここです。写真でいちばんよく見る**四景〜七景が、この中に集まっています**。

- **訪問できる時間：10:00〜17:00**
- **17:00〜翌日10:00に観光目的で入ると、過料10万ウォン**
- 2025年3月1日から本格施行

住民、店の客、ただ通り過ぎる人は例外ですが、鍾路区の案内によると**例外の人でも、写真の撮影やうろうろするなどの観光行為をすると過料の対象**です。「通りすがりに一枚だけ」もだめということです。

正確な境界は筆地単位なので、この記事では断定しません。**現地の案内板に従ってください**。

もう一つ。「ソウル市が選定した北村八景」という文言をよく見かけますが、**誰がいつ選定したのかが書かれた公式の文書は見つかりませんでした**。ソウル市の媒体も観光公社も、選定の主体を書いていません。

## 白麟済家屋 — 無料で、中に入るには予約です

**嘉会洞白麟済（ペク・インジェ）家屋**は**ソウル特別市民俗文化遺産**（1977年3月17日の指定）で、ソウル歴史博物館が分館として運営しています。

「有料で予約制」と書いた記事がありますが、**半分だけ正しいです**。

- **観覧料は無料**
- **09:00〜18:00**、入場は**17:30**まで
- **月曜日休館**（祝日なら開館）、1月1日休館
- **屋外は予約なしで自由観覧**

**母屋・舎廊棟の中に入ることだけが予約制の解説観覧**です。ソウル市公共サービス予約で申し込みます。

| | 解説の回 |
| --- | --- |
| 平日 | 10:00・11:00・14:00・15:00 |
| 週末・祝日 | 10:00・11:00・13:30・14:00・15:00・16:00 |
| 外国語（16:00） | **水曜日 日本語・木曜日 中国語・金曜日 英語** |

予約して**10分以上遅れると自動でキャンセル**されます。

ソウル市の媒体は、この家の**別堂から北村全体が見下ろせる**と紹介しています（内部は予約の解説観覧でだけ入れます）。そして**レッドゾーンより1時間早い9時に開きます**。安国駅 [[line:3]] 2番出口から憲法裁判所の方向へ500mです。

## 北村文化センター — ミン・ヒョンギ家屋か、ユ・ジンギョン家屋か

![雨の日の韓屋の大庁。開いた戸の向こうに中庭と別の棟が見え、踏み石の上に靴が置かれている](/images/bukchon-things-to-do-2026-09/06.webp)

桂洞（ケドン）ギルの入口にある韓屋です。国家遺産庁の登録名称は「ソウル 桂洞 近代 韓屋」、**国家登録文化遺産**（2006年3月2日の登録）です。

**1921年に建てられた家**で、長く**ミン・ヒョンギ（민형기）家屋**と呼ばれてきました。町では「桂洞の奥様の家」とも呼ばれていました。

ところが、**運営しているソウル市のソウル韓屋ポータル**はこう書いています。**最近の研究でユ・ジンギョン（유진경）家屋であることが確認されつつある**。ユ・ジンギョンはミン・ヒョンギの夫人です。国家遺産庁の説明文はまだ「ミン・ヒョンギの家」と書いているので、**二つの公式資料が食い違っています**。

- **火〜金 09:00〜18:00**、**水曜日は20:00まで**
- **土日 09:00〜17:00**
- **月曜日休み**
- 2002年10月開館、安国駅3番出口から歩いて5分

なお、**ソウル韓屋ポータルの別のページ（北村の主な施設）には「休館日なし、週末10:00〜17:00」と違う値が書かれています**。この記事はセンター紹介ページの値に従いました。

入場料をとるという案内はありません。

## 国立現代美術館 ソウル — 月曜日も開きます

![晴れた冬の日の国立現代美術館ソウル館の正面。ベージュの外壁の前に葉の落ちた大きな木と縦長の看板が立っている](/images/bukchon-things-to-do-2026-09/01.webp)

北村の見どころのなかで、**レッドゾーンの時間と逆に動く場所**です。

- **月・火・木・金・日 10:00〜18:00**
- **水・土 10:00〜21:00**
- **定期休館は1月1日・旧正月・秋夕だけ**。月曜日は休みません。
- **2026年12月1日（火）は臨時休館**

観覧料は**展示ごとに違います**。有料の展示が3つ以上あるときは、**統合観覧券が10,000ウォン**です。

**無料で見る方法が二つあります**。

- **水・土 18:00〜21:00の夜間開館は無料**
- **毎月最後の水曜日は無料**

そして**満24歳以下と満65歳以上は無料**です。

午後5時にレッドゾーンが閉まったら、**水・土曜日はここに来ればいい**です。無料で夜9時まで見られます。

## 正読図書館 — 旧京畿高校の校舎

![松の木の向こうに建つ3階建ての白い近代建築。中央のアーチ形の玄関の上に正読図書館の扁額が掛かり、手前に噴水がある](/images/bukchon-things-to-do-2026-09/03.webp)

国家遺産庁の登録名称は「ソウル 旧 京畿高等学校」、**国家登録文化遺産**（2002年2月28日の登録）です。1976年に学校が江南へ移り、図書館になりました。

**休館日は月曜日ではありません**。

- **毎月第1・第3水曜日**
- **日曜日を除く法定公休日**

資料室ごとに開く時間が違い、人文社会自然科学室は平日09:00〜20:00、週末09:00〜17:00です。

同じ敷地に**ソウル教育博物館**があります。ソウル市の媒体によると**平日09:00〜18:00、週末09:00〜17:00**で、休みは図書館と同じパターンです。博物館のホームページに告知された**2026年9月の休館日は2日・16日と24〜26日**でした（第1・第3水曜日と秋夕）。

## 昌徳宮と苑西洞 — 宮は月曜日に休みます

北村八景の**一景 昌徳宮の全景**と**二景 苑西洞の工房の道**は、昌徳宮の塀の側です。レッドゾーンの外なので、**午前10時前でも歩けます**。

昌徳宮は**9時に開きます**。

| 期間 | 観覧時間 | 入場締め切り |
| --- | --- | --- |
| 2〜5月、9〜10月 | 09:00〜18:00 | 17:00 |
| 6〜8月 | 09:00〜18:30 | 17:30 |
| 11〜1月 | 09:00〜17:30 | 16:30 |

- **月曜日休宮**（祝日なら開放）
- 殿閣観覧**3,000ウォン**、後苑は**5,000ウォン追加**（殿閣券が必須）
- **韓服を着ると無料**、満24歳以下・満65歳以上の韓国国内居住者は無料

景福宮は火曜日に休みますが、**昌徳宮は月曜日**です。混同しやすいです。

**10月の紅葉シーズンの後苑予約**は競争が激しいです。予約がいつ開くかは[ソウルの紅葉](/ja/posts/seoul-autumn-foliage-2026-09/)にまとめました。

## 桂洞ギル — 井戸と学校

北村文化センターから桂洞ギルを上っていくと、突き当たりに**中央高等学校**があります。

**石井ポルム井戸**（桂洞ギル110）は、**半月は澄み、半月は濁った**ことからついた名前だと伝えられています。ソウル市の媒体は、1794年に朝鮮に入った**周文謨（チュ・ムンモ）神父がこの水で洗礼を授けたと伝えられる**と紹介しています。どれも「伝えられている話」です。

**中央高等学校**は、**本館・東館・西館がそれぞれ史跡**です（韓国観光公社）。ドラマ「冬のソナタ」のロケ地として有名ですね。

ただし**学校です**。外部の人の訪問を認める時間を**学校が公式に公示した資料は見つかりませんでした**。授業日に校内へ入らず、正門から眺めるだけで十分です。

## 三清公園 — ソウルの都市公園第1号

三清洞ギルの突き当たりの**三清公園**は、ソウル市の媒体によると**1940年3月12日に告示された都市計画公園140か所のうち第1号**です。

公園の入口に**森の図書館**があります。

- **火〜日 10:00〜19:00**
- **月曜日**、1月1日、旧正月・秋夕の連休は休館

八景の**八景 三清洞の石段の道**も三清洞側です。レッドゾーンの外なので、**午後5時以降も歩けます**。

## 時間帯別のルート

**09:00〜10:00 — レッドゾーンの外**
昌徳宮（9時開門）、一景・二景の苑西洞の塀の道、桂洞ギル、正読図書館のあたり。

**10:00〜17:00 — レッドゾーンの中**
四景〜七景の嘉会洞31番地の路地、白麟済家屋。住民が暮らす家なので、**門の前での撮影や大きな声は控えてください**。

**17:00以降 — ふたたびレッドゾーンの外**
三清洞ギルと八景の石段、水・土曜日なら国立現代美術館（21時まで、18時から無料）、水曜日なら北村文化センター（20時まで）。

## 確認できなかったこと

**北村八景の選定主体と選定年**を、公式の文書で確認できませんでした。

**レッドゾーンの筆地単位の境界**は、この記事では断定していません。現地の案内板に従ってください。

**北村文化センターの運営時間**は、ソウル韓屋ポータルのなかでも二つのページで違います。

**中央高等学校の外部の人への開放時間**は、学校が公示した資料を見つけられませんでした。

**ソウル教育博物館の運営時間**は博物館のホームページで直接確認できず、ソウル市の媒体の値を書きました。

## まとめ

- **嘉会洞31番地の一帯（北村路11ギル）はレッドゾーン**で、観光客は**10:00〜17:00**だけ。八景のうち**四景〜七景**がここにあります。
- **例外の人でも、写真の撮影などの観光行為をすると過料10万ウォン**です。
- **白麟済家屋は無料**で、屋外は自由観覧、**母屋だけが予約の解説**。水曜日16時は日本語、金曜日16時は英語です。
- **北村文化センターは1921年の韓屋**で、ソウル市は**ユ・ジンギョン家屋**として紹介しています。
- **国立現代美術館ソウルは月曜日も開き**、**水・土の18時以降は無料**です。
- **正読図書館は第1・第3水曜日**に休みます。月曜日ではありません。
- **昌徳宮は月曜日休宮**、韓服を着ると無料です。
- **三清公園は1940年の都市計画公園第1号**です。
