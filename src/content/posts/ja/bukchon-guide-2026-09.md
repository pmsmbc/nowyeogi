北村は、このブログで取り上げてきたソウルの町のなかで**建物ではなく観光客を規制した最初の町**です。

ほかの町は、高さを抑えたり、再開発を解除したり、家賃を抑えたり、撤去を決めたりしてきました。北村は**人がいつ入ってよいかを決めました。** 午後5時から翌朝10時までは、観光目的で北村路11キルに入ることができません。

![青空の下、韓屋が両側に並ぶ北村路11キルの上り坂。塀には幾何学模様がはめ込まれ、人の姿はない](/images/bukchon-guide-2026-09/04.webp)

上の写真の路地が**レッドゾーン**です。

## 全国初の特別管理地域

根拠となる法律は**観光振興法**です。2019年12月3日の改正（法律第16684号）で「特別管理地域」の条項ができ、2020年6月4日から施行されました。国家法令情報センターに載っている改正理由です。

> **受け入れ可能な範囲を超えた観光客の訪問によって**自然環境が損なわれたり、**住民の平穏な生活環境を害したりするおそれがあるため**、管理するために指定する地域

法律は2020年にできましたが、**実際に指定されたのは4年後の北村がはじめて**です。鍾路区が**2024年7月1日**に指定し、ソウル市も「全国初」と紹介しています。

### 区域は4種類です

| 区分 | 場所 | 内容 |
| --- | --- | --- |
| **レッドゾーン** | 北村路11キル一帯 約**34,000㎡** | **17:00〜翌10:00は観光客の訪問禁止**、過料10万ウォン |
| オレンジゾーン | 北村路5カキル（26,400㎡）・桂洞キル一帯（34,000㎡） | 2024年の発表当時は指導の重点区域 |
| イエローゾーン | 北村路12キル一帯 | 過料なし、10:00〜17:00の訪問を呼びかけ |
| **貸切バス通行制限区域** | 北村路・北村路5キル・北村路4キル・昌徳宮1キルなど約**2.3km** | 貸切バスは**常時**通行禁止 |

オレンジゾーンの面積は、2024年7月の指定当時の報道に出ていた数字です。**いまの鍾路区の公式案内ページにはレッドゾーン・イエローゾーン・貸切バス区域だけが載っていて、オレンジゾーンはありません。** 旅行者に過料がかかるのは**レッドゾーンだけ**です。

### レッドゾーンのルール

鍾路区の案内をまとめました。

- **訪問できる時間**：午前10時〜午後5時
- **制限時間**：午後5時〜翌朝10時
- **指導期間**：2024年11月1日〜2025年2月28日
- **過料の賦課開始**：**2025年3月1日**
- **過料**：10万ウォン（条例により半額の範囲内で減額できる）

例外は**住民、その家族・知人、店の利用客、商人、ただ通り抜けるだけの人**です。ただし条件がつきます。

> 写真や動画を撮影する行為、周囲を観察しながら滞在する行為、店の利用とは関係なく観光目的で通りを歩き回る行為などがこれにあたります。こうした行為は観光行為とみなされ、**例外の対象者であっても**規定違反と判断されるため、過料が科されることがあります。

つまり、**宿泊客であっても午後5時以降に路地で写真を撮れば対象になる**ということです。「ひと月暮らし」のような**長期滞在者も住民ではない**と明記されています。住民とは、住民登録証・外国人登録証の住所がレッドゾーン内にある人だけです。

**外国人にも同じように適用されます。** 旅券番号をもとにその場で事前通知書を発行し、その場で払うか、出国前に払うよう案内すると書かれています。

![日暮れどきの青い空の下、街灯がともった北村路11キル。瓦屋根と模様入りの塀が坂の上まで続いている](/images/bukchon-guide-2026-09/01.webp)

こうした**夕暮れの路地の写真は、いまはレッドゾーンでは撮れません**。10月は午後6時前後に日が沈むので、夕焼けはレッドゾーンの外でご覧ください。

### 貸切バスも入れません

| 項目 | 内容 |
| --- | --- |
| 区間 | 北村路、北村路5キル、北村路4キル、昌徳宮1キルなど約2.3km |
| 時間 | **常時**（土・日曜日、祝日を含む） |
| 指導期間 | 2025年7月1日〜12月31日 |
| 過料の開始 | **2026年1月1日** |
| 過料 | 1回目30万ウォン、2回目40万ウォン、3回目50万ウォン |
| 取り締まり | CCTVカメラ |

2024年の指定時に発表された区間は1.5kmでしたが、**実際に施行された区間は2.3kmに延びました。** 対象は**16人乗り以上の貸切バス**です。そのかわり、鍾路区は**半径1km以内に乗降場所を3か所**設けています。三清路（国立現代美術館前）、三一大路（タプコル公園西側）、敦化門路（昌徳宮の向かい）です。

**団体ツアーで来られる場合は、この3か所のどれかで降りて歩いて入ることになります。**

この措置に対して商人と貸切バスの運転手が訴訟を起こしましたが、**ソウル行政裁判所が2026年9月17日に棄却**しました。韓国日報の報道によると、裁判所は「必要かつ合理的な制限」と判断しています。

## わたしが間違えていたこと

この記事を準備するなかで、知っているつもりだったことが4つ間違っていました。

**ひとつめ、特別管理地域の指定日は2024年11月1日ではありません。** 指定は**2024年7月1日**で、11月1日は時間制限の指導期間が始まった日、**過料は2025年3月1日から**です。日付が3つあります。

**ふたつめ、特別管理地域とレッドゾーンは違います。** 特別管理地域は、三清洞・嘉会洞の一部を含む**北村地区単位計画区域の全体**（1,128,372.7㎡）と同じ範囲です。そのうち**時間制限がかかるレッドゾーンは34,000㎡、全体の約3%にすぎません**。三清洞キル、桂洞キル、正読図書館のあたりはレッドゾーンではありません。

**みっつめ、時間制限は2024年に突然できたものではありません。** 鍾路区の説明です。

> 鍾路区は**2018年から**北村路11キル一帯を対象に午前10時から午後5時までを村の訪問時間と定め、住民で構成された北村見守り隊を通じて案内活動を行ってきました。しかし**自主的な指導活動だけでは効果を上げることが難しく**

**同じ10時〜5時のルールが、6年間「お願い」だったあとで過料になりました。**

**よっつめ、北村の韓屋の大半は朝鮮時代の両班の家ではありません。** ソウル韓屋ポータルの説明です。

> 住宅経営会社が北村の大きな筆地や林野を買い取り、そこに中小規模の韓屋をまとめて建設したが、**現在韓屋が密集している嘉会洞11番地と31番地、三清洞35番地、桂洞135番地の韓屋住居地はいずれもこの時期に形成された。**

「この時期」とは**1930年前後**です。ガラス戸やトタンのひさしをつけた**分譲住宅**でした。代表的な人物が建陽社を興した**鄭世権**（チョン・セグォン、1888〜1965）で、嘉会洞には彼の活動の地を記したバス停があります。

## 北村はどこまでか

**北村は法定洞の名前ではありません。** 清渓川と鍾路の北側の町、という意味です。

2020年のソウル市の公告によると、**北村地区単位計画区域は11の法定洞**にまたがっています。

> 嘉会洞、桂洞、苑西洞、安国洞、斎洞、花洞、司諫洞、昭格洞、松峴洞、八判洞、三清洞

旅行者に必要な区別はこうです。

| 名前 | 実体 | 雰囲気 |
| --- | --- | --- |
| **北村韓屋村** | 嘉会洞11・31番地一帯、北村路11キル | 韓屋が密集した住宅地、**レッドゾーン** |
| **三清洞** | 法定洞。旅行者が言うのはたいてい**三清洞キル** | ギャラリー・カフェ・食堂の通り |
| **桂洞** | 法定洞。**桂洞キル** | 町の商店とカフェ、中央高校の前 |
| **嘉会洞** | 法定洞 | 韓屋密集地の大半がここ |

**「三清洞」は北村のなかにある町のひとつ**です。北村と三清洞を離れた別の場所と考えると、ルートがこんがらがります。

西村の記事で引用したソウル韓屋ポータルの一文があります。西村は「**北村の面積に比べると1/3ほどの規模**」だと。北村は西村のおよそ3倍です。

## 年表

| 時期 | 出来事 |
| --- | --- |
| 1930年前後 | 住宅経営会社が筆地を分けて韓屋を大量に分譲 |
| 1976年 | 京畿高校が移転（跡地は正読図書館）、**民俗景観地区の指定を議論** |
| **1983年** | **第4種美観地区に指定**、本格的な韓屋保存政策 |
| **1991年5月** | 高さ規制を1階 → 10m（3階）以下に緩和、多世帯住宅の新築が始まる |
| 1994年 | 景福宮周辺の高さ制限を10m → 16m、最大5階に |
| 1999年 | 住民組織「鍾路北村カクギ会」の求めで新しい政策を策定 |
| **2001年** | **北村カクギ（北村づくり）開始**、韓屋登録制・修繕支援 |
| 2018年 | 北村路11キルで村の訪問時間10時〜5時（自主的） |
| 2020年1月 | 地区単位計画の再整備、建築資産振興区域の指定を推進 |
| **2024年7月1日** | **特別管理地域に指定** |
| **2025年3月1日** | **レッドゾーンの過料開始** |
| **2026年1月1日** | **貸切バスの過料開始** |

1983年の保存について、ソウル韓屋ポータル自身がこう評価しています。

> 住民との議論や合意なしに行政主導で実施されたもので、韓屋を文化財のように厳しく規制するやり方であり、また**北村路を拡張舗装しながら多くの韓屋を撤去するなど、二重の行政運営**で住民の不満を招いた。

その反発で1991年に規制が緩められ、多世帯住宅が韓屋の跡を埋めていきました。**2001年の北村カクギは「強制的に縛らず、登録した家を支援する」へ方向を変えたもの**です。

なお、**北村の現在の韓屋の棟数はソウル韓屋ポータルの北村紹介に載っていない**ため、この記事には書いていません。ネットに出回っている数字は、出典も基準年もばらばらです。

### 次の規制は宿です

2026年6月、鍾路区が北村地区単位計画の整備に着手しました。時政日報の報道によると、**北村の韓屋密集地域の韓屋体験業は2020年の47か所から168か所へ3.5倍**に増えており、嘉会洞一帯で新たな宿泊業を制限する方向です。詳しくは[北村の宿](/ja/posts/bukchon-hotels-2026-09/)の記事にまとめました。

## ほかの町と並べると

| 町 | 処方 | 規制の対象 |
| --- | --- | --- |
| 乙支路 | 撤去の決定 | 建物 |
| 益善洞 | 2018年に整備区域を解除＋保全措置 | 建物 |
| 西村 | 1977年に高さ規制 → 2016年に保存計画 | 建物・業種 |
| 聖水洞 | 2015年に家賃抑制の条例 | 家賃 |
| 城北洞 | 2019年に保存 → 2026年に撤去へ反転 | 建物 |
| **北村** | **1983年に保存 → 1991年に緩和 → 2024年に訪問時間を制限** | **観光客** |

**ほかの5つの町はすべて建物かお金を扱いました。** 北村は建物の保存を40年やってきたあとで、**保存された町に人が来すぎるという2つめの問題**にぶつかった場所です。

**北村は北へ行くほど坂が急になります。** 上り坂がつらければ村バスに乗ってください。

- [[bus:village:01]] 鍾路01・[[bus:village:02]] 鍾路02 — 安国駅周辺から**嘉会洞住民センター**、**北村韓屋村入口**の停留所まで上がります。鍾路02は監査院を過ぎて成均館大学まで行きます。
- [[bus:village:11]] 鍾路11 — **三清公園**から三清洞キルを下り、景福宮・市庁を経て**ソウル駅**まで行きます。

空港からなら、**空港リムジン**[[bus:6011]]が昌徳宮と安国駅1番出口のそばに停まります。

## こう歩いてください

いちばん無理がないのは、**午前10時以降にレッドゾーンから**回ることです。

1. **午前** — 安国駅2番出口 → 北村路11キル（レッドゾーン）。人が少なく、制限時間でもありません。
2. **昼** — 桂洞キルか三清洞キルへ下りて食事。おすすめは[北村のグルメ](/ja/posts/bukchon-food-2026-09/)の記事にあります。
3. **午後** — 正読図書館、国立現代美術館ソウル館、三清洞キルのギャラリー。ここは**レッドゾーンではないので時間制限がありません。**
4. **午後5時前** — レッドゾーンから出る。

**景福宮や昌徳宮を組み合わせるなら**、韓服を着ると古宮の入場が無料になりますが、認められる基準が別にあります。[韓服で古宮無料観覧](/ja/posts/hanbok-palace-2026-09/)の記事をご覧ください。景福宮は火曜日、昌徳宮は月曜日が休みです。

見どころの一覧は[北村の見どころ](/ja/posts/bukchon-things-to-do-2026-09/)の記事に別にまとめました。

### 路地で守ること

鍾路区の基準で何が**観光行為**になるのかは上に書きました。そのほかに現地の案内が繰り返しているのは3つです。

- **ひそひそ声で**話す
- **門の前の階段に上ったり、かばんを置いたりしない**。住民の出入口です
- **門を開けたり、なかをのぞき込んだりしない**

## こんな方に向いています

**向いている方です。**

- 韓屋の路地を歩いてみたい方。**午前10時〜午後5時のあいだに**お越しください
- ふたつの古宮のあいだを歩いてつなぎたい方
- ギャラリーや美術館が好きな方（三清洞キル、国立現代美術館）
- 保存政策が40年のあいだにどう変わってきたのか気になる方

**向いていない方です。**

- **早朝や夕暮れの韓屋路地の写真**が目的なら、レッドゾーンでは撮れません
- 夜の散歩をしたいなら、レッドゾーンは外して三清洞キル・桂洞キルへ
- 坂がつらい方は村バスをぜひ
- 団体の貸切バスで来られる場合は、乗降場所から歩くことになります

## まとめ

- **北村は2024年7月1日、全国初の観光振興法「特別管理地域」になりました**。
- **レッドゾーン（北村路11キル一帯34,000㎡）は午後5時〜翌朝10時は観光客の訪問禁止**、2025年3月1日から**過料10万ウォン**です。
- **写真撮影や立ち止まることは観光行為**なので、宿泊客も対象です。外国人も同じです。
- **レッドゾーンは特別管理地域の約3%にすぎません**。三清洞キル・桂洞キル・正読図書館のあたりは時間制限がありません。
- **貸切バスは2026年1月1日から常時通行禁止**、過料は30万〜50万ウォンです。
- **北村の韓屋の大半は1930年前後の分譲住宅**です。朝鮮時代の両班の家ではありません。
- **安国駅2番は韓屋村、1番は正読図書館・三清洞、3番は昌徳宮。**

ひと言でまとめるとこうです。**北村は韓屋を守るのに40年かかり、そのあとは人が来る時間を決めなければならなかった町**です。
