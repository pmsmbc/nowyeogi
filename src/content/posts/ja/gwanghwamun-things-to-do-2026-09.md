光化門と市庁のあいだは「景福宮へ行く途中」として通り過ぎてしまいがちな場所です。ところがこの1kmほどの区間には、**夜9時まで開く王宮**、**休みの曜日が互いに逆になる2か所の守門将交代儀式**、そして**月曜も開く博物館**が集まっています。先に結論を言うと、景福宮が休む火曜も、徳寿宮が休む月曜も、この街で1日を埋められます。

景福宮・昌徳宮・宗廟は[鍾路の古宮と見どころ](/ja/posts/jongno-things-to-do-2026-09/)で、韓服の無料入場の基準は[韓服で古宮を無料観覧](/ja/posts/hanbok-palace-2026-09/)で扱ったので、ここでは繰り返しません。徳寿宮の石垣道の紅葉は[ソウルの紅葉スポット](/ja/posts/seoul-autumn-foliage-2026-09/)にあります。エリア全体の概要は[光化門・市庁まとめ](/ja/posts/gwanghwamun-guide-2026-09/)をご覧ください。時間と料金はすべて**2026年9月の執筆時点**のものです。

## 徳寿宮 — 夜9時まで開く王宮

![青空の下、緑とオレンジの丹青で彩られた軒が大きく反り上がる徳寿宮の光明門。光明門の扁額が掛かり、門の向こうを観覧客が歩いている](/images/gwanghwamun-things-to-do-2026-09/03.webp)

宮陵遺跡本部の観覧案内によると、徳寿宮は**1年を通して09:00〜21:00**（入場締切20:00）です。季節で時間が変わる景福宮と違い、**夜間が常時運営**なので、夕食のあとにも寄れます。

- 入場料**1,000ウォン**、韓服を着ていれば無料
- **毎週月曜休宮**
- 正門の大漢門は[[line:1]] [[line:2]] 市庁駅のすぐ前

外国語の宮殿解説もあります。公式の解説案内では**英語 10:45・13:30、日本語 09:30・16:00、中国語 10:00・14:30**（火〜日）、約45分です。**日本語解説は1日2回**なので、朝一番か夕方に合わせると使いやすいでしょう。

![高い所から見下ろした徳寿宮。手前に中和殿と広い石敷きの庭、左奥に白い列柱の石造殿と丸い噴水、その向こうに都心のビルが並ぶ](/images/gwanghwamun-things-to-do-2026-09/01.webp)

### 石造殿 大韓帝国歴史館 — 1週間前の午前10時

宮の奥にある西洋式の石造建築が**石造殿**です。中は大韓帝国歴史館になっていて、解説に付いて入る方式です。

| 項目 | 内容 |
| --- | --- |
| 運営 | 09:30〜17:30、最終解説16:30 |
| 予約 | 観覧日の**1週間前の午前10時**から、オンライン先着順 |
| 人数 | 1回につきオンライン15人、1人最大5枚 |
| 現地参加 | 1回5人、**満65歳以上と外国人のみ** |
| 所要 | 一般解説40〜45分、深化解説65〜70分 |
| 料金 | 徳寿宮の入場券以外は不要 |

- **解説開始の3分前から入場**、開始時刻を過ぎると入れません。
- 大漢門から石造殿まで**10〜15分**かかると案内されているので、余裕を持って。
- 宮陵遺跡本部の解説案内には、**英語解説の11:50・14:50は現地予約のみ**という記載があります。
- 取消・変更は前日23時まで

### 惇徳殿は10月25日まで観覧中止

宮陵遺跡本部の徳寿宮ページに、**2026年9月1日から10月25日まで惇徳殿（トンドクチョン）の観覧を中止する**というお知らせが出ています。展示に関するお知らせも並んでいます。10月末以降の新しい展示はお知らせで確認してください。

貞洞キル側の重明殿は、公式の観覧時間で**09:30〜17:30**（入場締切17:00）です。

### 国立現代美術館 徳寿宮館 — イ・デウォン回顧展

徳寿宮の中の美術館で、**イ・デウォン回顧展**「あなたを悲しませるものは何ひとつない（이대원: 당신을 슬프게 하는 것은 하나도 없다）」が**11月8日まで**開かれています。果樹園や山、野の風景を明るい色で描いた画家イ・デウォン（1921〜2005）の作品約120点と資料約100点を集めたと美術館は紹介しています。

- 観覧料**2,000ウォン**、徳寿宮入場料1,000ウォンは別
- **水・土曜は21時まで**、18〜21時は夜間無料
- 満24歳以下、満65歳以上などは無料
- 月曜休館

## 守門将交代儀式 — 2か所、休みの曜日が逆

このエリアでは守門将の行事が**2か所**で行われます。運営も休みの日も違います。

| | 徳寿宮 大漢門 | 景福宮 光化門 |
| --- | --- | --- |
| 交代儀式 | **11:00、14:00** | **10:00、14:00** |
| 所要 | 約20分 | 20分 |
| そのほか | 巡邏儀式 15:00〜16:00（場所は変動） | 光化門把守儀式 11:00・13:00、公開訓練 09:35・13:35 |
| 休み | **月曜** | **火曜など休宮日** |
| 運営 | ソウル市（王宮守門将交代儀式） | 国家遺産振興院 |

**月曜は光化門へ、火曜は大漢門へ**行けば、どの曜日でもどちらかは見られます。どちらも**雨や悪天候の日は中止**になることがあります。

景福宮側の**巡邏儀式**は3〜5月と9〜11月の土・日・祝日に行われます。国家遺産振興院の案内では、**土曜は景福宮の中、日曜は光化門から仁寺洞まで**歩きます。秋夕連休中の日程は[秋夕連休まとめ](/ja/posts/chuseok-2026-09/)にあります。

### 大漢門で参加する

王宮守門将交代儀式のサイトにある付帯行事です。

- **「私も守門将だ」** — 11:00・14:00の交代儀式に守門将として参加。**1回1人・先着順**、小学生以上、**1時間前に到着**（衣装と練習）
- **伝統衣装体験** — **土・日・祝日 10:30〜15:30**、無料、事前申込なしで現地参加
- 参加型行事の予約は**前月20日**に始まり、同じ月の重複予約はできません。

**土曜は大漢門前の集会のため付帯行事が中止になることがある**とサイトに書かれています。

### 光化門の月台 — 2023年に戻った「王の道」

光化門のすぐ前の広い石の基壇が**月台**（ウォルデ）です。京郷新聞の報道によると次のとおりです。

- **2023年10月15日**に復元記念行事
- 発掘で確認した大きさは**南北48.7m、東西29.7m**、中央に幅7mの御道
- 1866年3月に築いたという記録をもとに復元
- 失われていた**瑞獣像**1対は、故イ・ゴンヒ会長の遺族の寄贈で戻った
- 光化門の両脇にあった**ヘチ像**は月台の南端へ移設
- 光化門の扁額も**黒地に金文字**に変更

## 清渓広場と普信閣

![清渓川の石橋の欄干の向こう、清渓広場に紫と青のらせん模様がそびえるオブジェ「スプリング」が立ち、周りを人が歩いている](/images/gwanghwamun-things-to-do-2026-09/09.webp)

### 清渓広場

清渓川が始まる場所です。広場の巻貝のようなオブジェは、クレス・オルデンバーグとコーシャ・ヴァン・ブリュッゲンの作品「スプリング」で、高さ20m・直径6m、**夜は内側に照明**がともります。

韓国観光公社の案内によると、広場には三色の照明の**キャンドル噴水と高さ約4mの2段の滝**、全国八道の石で造った**八石潭**、清渓川全体を**1/100に縮めた模型**があります。

清渓川の散策は[明洞の見どころ](/ja/posts/myeongdong-things-to-do-2026-09/)で、鍾閣側の韓国観光公社ソウルセンターの行事は[HiKR Groundのピカチュウイベント](/ja/posts/hikr-ground-pikachu-2026-09/)で扱いました。

**2026 ソウル光の提灯祭り**（ソウルビッチョロン祭り）は、ソウル市の祭りページに「（予定）12月、清渓川一帯」とだけ載っています。詳細は確定していないので、ネットに出回っている日付は公式発表まで信じないほうが安全です。同じ一覧の**2026 ソウルライト光化門**は、**12月11日〜2027年1月3日、17:30〜22:00**に光化門広場で開かれるとあります。

### 普信閣 — 正午の鐘

[[line:1]] 鍾閣駅4番出口の前の鐘楼が**普信閣**です。ソウル文化ポータルによると、**月曜を除く毎日正午**に常設の打鐘があり、市民と観光客が参加できます。

- 申込資格の制限なし、**先着順**
- ソウル文化ポータルの**オンライン申請**か**現地申請**
- **火曜は外国人参加プログラム**
- いまの鐘は**1985年に新しく造った鐘**です。朝鮮時代の元の鐘（1468年）は国立中央博物館にあります。

## 時間帯別のルート

**午前 — まず守門将**
火曜でなければ10:00に光化門の交代儀式、月曜でなければ11:00に大漢門の交代儀式。曜日に合うほうを選んでください。

**昼ごろ — 光化門広場の地下**
世宗物語・忠武公物語（10:00〜18:30）。日差しが強い日や雨の日に使える無料の屋内スポットです。

**午後 — 貞洞キル**
徳寿宮の石造殿の予約時間（1週間前の午前10時に予約）に合わせ、石垣道に沿って西小門本館へ。

**夕方 — ソウル歴史博物館と慶熙宮**
慶熙宮は18時に閉まるので先に。博物館は21時まで（木曜を除く）。

**夜 — 夜の徳寿宮か光化門広場の照明**
徳寿宮は20時まで入場。水・土なら宮内の美術館も21時まで。光化門広場の「感謝の光23」の照明は20時からです。

**月曜なら**
徳寿宮と博物館の多くが休みです。**光化門の守門将交代儀式**と**大韓民国歴史博物館**、月曜に開く景福宮で埋めてください。景福宮は[鍾路の古宮と見どころ](/ja/posts/jongno-things-to-do-2026-09/)にまとめています。
